# academic-agent 0.4.0 本地发行范围

日期：2026-09-13。本文件描述候选内容和剩余门槛；0.4.0 尚未发布。

## 候选内容

- 从已复核原文及明确选择的领域依赖生成可追溯大纲与跨文献正文。
- 正文单元关联主张、文献、原文、证据、独立复核和冻结统计；宿主生成可见引用定位。
- 人工修改保存原始 bytes/hash，形成 pending 修订，变化文字重新划分并独立全文复核，旧版本保留。
- 原文、筛选、人工复核、领域包及选定可选依赖参与失效检查，提供可执行的恢复步骤。
- 数据型外部领域包改变字段、比较列及写作结构，无需改动安装内核。
- 只读检查、中文空格路径、Windows 长路径和新输出/预算边界保留；正文结构不合法时给出受控错误位置和类型。

用户明确授权的有界观察已完成领域提取、领域复核、正文和独立全文复核四阶段。最新正文/复核新增 2 次成功调用，累计 8 次实际尝试且旧失败保留，项目计数到 60/60。实际正文的数字、模拟条件、反例、原文 hash 和引用链已核验，14 单元复核为 13 supported/1 insufficient；最后一项涉及此前大纲复核记录，导出保留证据不足理由，不能写成全部学术内容可靠。独立产物复审确认 E14/E15 满足有界工程验收，成稿仍需人工编辑；没有新增模型调用计划。
