# 0.2.0：冻结语料趋势与可操作验证

这是已有架构上的有界扩展。Python >=3.11；Windows/Linux；沿用锁定依赖，不新增运行时依赖，不改变 0.1 数据库结构和既有 CLI 参数语义。数据输出默认中文说明、UTF-8 JSON/Markdown/CSV。

## 1. 可复现的描述性趋势

新增 `trends.py` 的版本化 Pydantic 契约和确定性函数，模型不计算数量。冻结输入包含当前 Work 全部字段（含筛选/来源/关系/出版检查）、活动文档 ID/哈希/层级、项目检索范围/限制、查询日志摘要及检索时间、人工年份/标签批注版本、计算截止年份和研究修订标识。读取前后快照必须一致，发表新成果时再次检查；冲突报错并保留以前成果。

计数集仅包含 `screening=include` 且未被标记撤稿的去重书目记录。报告候选总量、纳入/排除/待定/撤稿、年份缺失、未来年份、文档层级、arXiv ID 比例（只能称 arXiv 标识覆盖）、疑似关系记录。去重记录不是独立研究；不自动合并关系或把预印本和正式版当独立重复验证。当前年单列未结束；小样本（总量 <50 或任一实际比较年份 <10）提醒只做描述，任何样本量都不输出领域总体增长断言。

默认日期口径 `record_year`：元数据年份语义未统一，明显披露这一点。提供 `first_publication_year` 和 `formal_publication_year` 可选口径，只有具有人工来源说明的逐文献年份批注可使用；不得回退到混合元数据年份。年份缺失和非法年份单列，不参与年度分母。报告语料内占比及分母，不预测、聚类或输出显著性。方法标签由人工批注输入（版本、批注者、逐文献标签、理由），同一篇同一标签只计一次，允许多标签；总占比可大于 100%。标签定义固定于整个快照，不用未经复核的自由文本自动推断。

人工批注用严格 JSON 对象，所有文献 ID 必须在本库存在；版本与批注者非空，标签需非空去除首尾空格；年份约束 1000..9999 且不能为布尔；提供年份必须带非空来源说明。空批注也可生成未标注覆盖报告。示例：

```json
{"version":"1","annotator":"研究者","works":{"WORK_ID":{"year":2023,"year_source":"论文首页 Published 日期","labels":["图模型"],"rationale":"方法章节"}}}
```

计算结果 `ComputationRecord` 固定算法版本、输入哈希、参数、具体输入 ID、年度/标签数据、诊断和公式；可在无数据库、无网络、无模型情况下从 `corpus.json` 完全重算。输入哈希采用 UTF-8 规范 JSON（sort_keys=True, separators=(',', ':'), ensure_ascii=False）；运行时间不参与计算标识。输入与输出均有内容哈希。

`trends` 写入项目 `analyses/trends/<unique-version>/` 的 `corpus.json`、`computation.json`、`annual.csv`、`labels.csv`、`report.md`、`manifest.json`，成功后原子更新 `latest.json`。旧版本与人工改稿不覆盖。报告含所有查询范围/失败/截断/候选上限的限制；本地导入必须显示检索覆盖未知。`verify-trends DIRECTORY` 校验文件哈希及重算等价性，对损坏/篡改/缺文件返回非零；不访问论文网络或模型。

## 2. 操作指导与使用自检

新增 `guide`：输出人可读中文下一步、结构化建议动作 argv（不是执行的 shell 字符串）和阻塞原因。项目不存在时指导 init；无文献指导 search/import；有待筛选文献指导逐篇筛选；无可读文本指导 attach；未阅读/未复核指导 read/review；当前可用结果可 export/trends；失效时指向重算。指引本身不改研究内容或调用模型/网络，不能一键自动纳入所有文献。

新增 `self-test --output DIRECTORY`：只在全新隔离目录中执行自身包的 CLI 子进程；已有目录拒绝，所有输入是原创合成内容，子进程强制 UTF-8、使用当前 Python 和实际包入口。不依赖 pytest，不调用任何真实模型/检索。产出 `usage-report.json` 和可读报告，逐场景保存命令 argv、退出码、预期/实际、耗时；任一实际检查失败总体非零，报告不得仅检查进程成功。

覆盖：首次安装 demo 导出与证据数量；中文空格目录 RIS 导入并筛选、关联全文；预算中断后提高本地配置并恢复不重复已完成调用；人工改稿后生成新版本保留旧稿；文献变动使导出过期；年度/标签精确计数和重算；错误批注文献 ID 被拒绝；空语料指南不会调用模型。另外加入可读 PDF 文字层与无文字 PDF：前者保留物理页码证据，后者明确 needs_ocr 且不消耗模型调用，使用本地生成的原创 PDF。来源限流保持在已有模拟适配器回归和单独的真实探测层，不伪称离线测试访问了真实来源。

## 3. 发布与限制

CLI 增量兼容旧命令。README 列明新用户从 demo、guide 到真实研究的步骤。CI 六环境在已安装包入口运行 self-test，并保存失败报告。版本 0.2.0 同步 pyproject、CLI 和 lock。完成离线包测试后使用既有公开检索条件做一个有界真实元数据语料趋势冒烟，不调用付费 API。任何学术质量指标仍明确“未执行人工评测”。
