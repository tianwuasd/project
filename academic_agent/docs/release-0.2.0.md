## 审查决定

组件审查、整版审查和限定复审发现的问题均已处理。最终修复还暴露了忽略已提交 WAL 文献的回归；独立复现后改回正常只读连接，通过安装包实际操作核对当前文献、完整数据库内容及非辅助文件哈希。

三项开发裁定及代价保留如下：

1. 摘要可读性沿用现有 `Runner.prepare` 选择条件，报告准确说明当前描述统计能力。若规格理解有误，会影响下一步建议和功能范围表述；已对照既有流程并保留空白 PDF 与统计限制回归。
2. 只读禁止改变研究内容，允许 SQLite 的正常 WAL/SHM 协调文件。可能留下辅助文件是该选择的代价；不接受漏读已提交数据或新增数据库静止前提。
3. 在一次最终修复及限定复审之后，再针对已复现的 WAL 回归执行一次有界纠正，以独立安装验收和最终 CI 结束。增加的代价是少量返工时间，未扩大功能范围或重启整版审查。
