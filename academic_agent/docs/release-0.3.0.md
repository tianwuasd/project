## 功能与限制

- 从完整所选、已复核证据生成最多三个系统假设，独立检查其依据。
- 最多两轮反例查询，保存真实尝试、来源失败、保留文献及未筛选/未读/未复核缺口，支持中断恢复。
- 对新颖性线索、研究价值、可行性和证据强度作材料范围内评估，逐文本单元独立复核，保留可证伪方案及历史状态。
- 命令行指南处理第二轮恢复、预算和输入超限；普通 Windows 长路径读取修复已同步进入 0.2 正式版。

候选仍是待验证研究设想。评估完成可以同时证据不足；资料可用性不是学术质量或全球新颖性证明。实际跨文献段落与人工改稿闭环、领域包属于后续 0.4。
