## 公开来源实际探测

使用已实现适配器，经配置代理，每来源最多 2 条、单页、无自动重试，关键词 graph neural network。

| 来源 | 实际结果 | 解读 |
|---|---|---|
| OpenAlex | ok，2 条 | 该次小查询可用 |
| Semantic Scholar | HTTP 429，rate_limited，0 条 | 匿名接口限流，正确保留失败状态 |
| Crossref | ok，2 条 | 初版排序相关性不足；改书目查询及分数倒序后得到相关结果 |
| arXiv | ok，2 条 | 该次 Atom 查询可用 |

Crossref 单篇出版检查及 incoming updates 请求成功，返回 no_notice_found；其含义只是在该来源该次未发现通知，不证明结论有效。详情见 [探测摘要](validation/source-probes.json)。没有进行高频探测或尝试绕过限流。

## 真实 Codex 阅读与独立复核

使用既有 ChatGPT 登录，对一篇项目原创合成材料完成 1 次阅读、1 次独立复核，耗时约 35.56 秒。得到 6 类陈述，复核返回 6 项 supported，证据 ID 均能定位到同一不可变文档。金额/实际 token 用量未知，未将其记为零费用。

调用发生在正常用户进程中；受限工具进程缺少 Windows 用户资料令牌，不能直接判断为未登录。后端本身不提权，使用隔离工作目录、只读沙箱和禁用工具的子进程，独立 API key 不传入。

这是后端与流程连通测试，输入是原创的合成研究说明，**不是正式学术准确性评价**。记录见 [Codex 摘要](validation/codex-smoke.json)。

## 独立审查

组件首轮提出 10 项实质缺陷：3 项来源、4 项存储/导入、3 项工作流。修复后原审查者逐项复核，全部 ADDRESSED，并增加针对性回归。另修复 SQLite 显式关闭、到候选上限仍补全已知文献、问答题目过滤。

整体审查另发现 4 项跨模块问题；统一修复提交 9b8977f 关闭继承日志追踪、同步来源摘要、把配置纳入导出快照、使故障检索可恢复。45 项定向回归通过；其中 12 项追踪隔离矩阵使用本地假客户端与网络哨兵，四个核心回归在旧代码隔离副本中均按预期失败。没有为复现发送任何真实材料。

提交 `6722847` 的 [GitHub Actions](https://github.com/tianwuasd/testing_tools/actions/runs/34242504517) 已实际成功：Windows/Linux × Python 3.11/3.12/3.14，六组均通过测试、Ruff、构建和演示。后续发布提交的状态另在开发记录注明，不能把旧提交的结果当作新提交结果。

修复后的候选提交 `1fd7fc0` 的 [最终候选 CI](https://github.com/tianwuasd/testing_tools/actions/runs/34244701709) 同样六组全部成功。最终限定复核 F1–F4 全部 ADDRESSED，独立 45 项定向测试通过。
