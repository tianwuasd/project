# Changelog

## 0.4.0 — 2026-09-13

- 增加证据约束的大纲、跨文献正文、逐单元引用审计与独立全文复核。
- 人工修订保留原始 bytes/hash 和历史版本，变化文字重新划分、复核；支持显式领域重绑与依赖失效检查。
- 数据型领域包扩展提取字段、比较列和写作结构；新增写作状态、导出编辑及恢复指引。
- 修复 Windows 长路径与摘要来源定位边界、修订来源归属和多次 pending 导入；写作输出适配受支持的 union schema，拒绝时提供受控诊断。
- 本地完整安装旅程 17 场景/209 命令/299 断言通过，后续摘要定位安装定向 40 项及写作相关源测试 70 项通过，各范围分别保留。
- 限量真实 Codex 观察完成四个所需阶段；实际整稿 14 单元保留 13 supported/1 insufficient，数字、模拟条件与引用逐项核验。具体论文的学术质量仍需人工评测。

本记录在本地发行验收后冻结；最终包、正式分支/标签和六环境 CI 以发行收据与远端记录为准，详见[发行范围](docs/release-0.4.0.md)及[验收记录](docs/validation-v0.4.md)。

## 0.3.0 — 2026-09-09

- 冻结当前研究资料及引用依赖，生成最多三个明确标为系统假设的创新候选，并由独立调用复核依据。
- 增加最多两轮的有界反例检索，保存逐次请求、来源失败、实际保留文献和待筛选/阅读/复核缺口，支持中断恢复。
- 增加新颖性线索、研究价值、可行性和证据强度四维评估；保留材料范围、反证条件、最低验证方案及逐文本单元复核。
- 提供候选生成、反例检索、评估、历史状态和只读操作指引命令；离线自检扩展为 12 个精确场景。
- 修复 Windows 260 字符边界下已发布分析文件无法由普通路径读取的问题，统一公共验证和自检的长路径访问。
- 最终本地代码通过 445 项完整测试、Ruff、固定 0.2 趋势样本校验、wheel/sdist 检查及纯运行依赖隔离安装自检。

安装包 U09/语义协议验收、真实 Codex 与公开来源冒烟及整版独立审查已完成；复审修复了第二轮检索恢复指引和评估输入超限说明。最终安装环境自检及修复场景通过；本记录冻结时尚待正式分支/标签推送和远端 CI，见 [发行记录](docs/release-0.3.0.md)。工程测试不代表全球新颖性或人工学术质量评测。

## 0.2.0 — 2026-09-09

- 冻结纳入语料，生成年度计数、显式标签分布、缺失与检索范围说明；统计不依赖模型。
- 保存语料、计算记录、CSV、中文报告和哈希清单，支持脱离项目数据库重新计算及校验。
- 区分元数据年份、人工标注的首次发表年与正式发表年，披露当前年、未来年和未知年份。
- 增加固定原创产物兼容样本，保护后续版本对已有统计记录的读取与校验。
- 新增只读操作指南，展示逐篇筛选、补全文、阅读复核、预算和待输入事项。
- 新增可由安装包运行的离线使用自检，覆盖 11 个场景及中文路径、预算续跑、改稿保留、版本过期和 PDF 文字层。
- 源码包包含固定样本、锁文件和研发验收文档，便于复核测试依据。
- 修复 Windows 传统 `MAX_PATH` 边界下已原子发布趋势目录的读取；公开校验命令仍接收普通路径。

长路径修复回补经独立审查、291 项完整测试及安装包验收通过，用户确认后已随 0.2 正式发布。main `700c06c`、develop、release 和标签已核对，[正式提交的六环境 CI 全部通过](https://github.com/tianwuasd/testing_tools/actions/runs/34348922063)。[发行记录](docs/release-0.2.0.md)保留发布前冻结时的历史证据。
