目标：优化已有 blood 训练，允许旧检查点继续训练，并使用扩大范围的自动近端标签启用 init64/init128。

用户已要求直接实施与本地验证。采用已有命令、资源调度、精确源码兼容与检查点机制，保持原预处理、患者划分、模型参数结构、loss、batch、轮数及增强顺序。

## 实施

- [x] Blood 输入：逐病例的压缩数组读取会话、相同数组、并发和变动拒绝已验证。
- [x] Blood 计算：容量约束七帧分组、开发集特征复用及重计算开关，数值与 CUDA 对照已完成。
- [x] 自动近端：物理范围扩大 20%、七结构资格、未知值、独立保存与实际 CT 范围检查已完成。
- [x] 原任务扩展：保留原身份和跳过收据，新增两支与六路融合，覆盖冲突与冻结参数检查。
- [x] 兼容：完整精确源码映射、真实旧 encoder 检查点继续 sequence，原保护文件不变。
- [x] 验收：176 项回归中的 171 项通过、5 项条件跳过；8 项兼容测试通过；GPU 两支保存恢复、旧权重复用和融合通过。证据与范围见 docs/blood-auto-init.md。

## 验收边界

自动近端范围是本次授权的工程估计，独立记录方法与数值，不作为人工审核的解剖端面。性能结论只覆盖实测设备、尺寸和输入；不得把本机 RTX4060 的结果写成服务器 RTX3090 的实测结论。服务器原结果及权重不上传。
