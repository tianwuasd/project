# Dataset1282 独立预测

用户选择现有 dataset1282 CT，沿用原冻结方案的 source_test、target_primary（iCT 256）、target_secondary（Brilliance iCT）三组留出患者。来源训练和 development 保持训练及选模用途。按冻结名单中 included/index_scan 选择病例，保持患者互斥；默认全部三组，可选其中一组或该组病例。设备来源名称保留，不能自行等同医院中心。

现有 hu-marginal 只处理来源训练与 development。独立预测准备步骤读取同一 cohort、Excel、原件清单和政策；将训练时 nnUNetPlans/CTNormalization 参数应用于留出 CT，禁止重新拟合指纹、间距或强度统计。预测准备只访问图像；标签仅在预测提交后由独立评价入口读取。输出为 local_array_excel_mm 原生局部网格分割，不推断原始患者方位。

使用验证集选出的已完成模型。模式包括 four-way、blood、vessels（默认）。blood/vessels 要求完整血池训练；近端分支按来源任务已完成或有据可查的跳过记录处理。默认完整方法不能自动省略尚未完成的模型。

留出 CT 由冻结定位模型重新预测严格投票加 20% 框，拒绝空框和整图，复用四路/六路投票、血池修正和血管处理实现。模型加载保留训练身份；不读取真值体积，不启动训练。预测提交后逐组报告 Dice/HD95/ASD、监督有效分母和拒绝病例数量。

采用独立 prediction 包和薄 scripts/xu_predict.py，现有训练源码保持字节不变。新任务复制所需权重和来源身份到独立输出目录。按完整源码映射、来源阶段收据、权重摘要和输入摘要校验，来源记录不可修改。

v2 执行策略：管理进程不见 GPU，单个工作进程只见一张获准空闲卡，排除物理 0/1 和外部进程；按实测资源预算限制 CPU 线程和预取深度。资源变化释放本任务工作进程后等待重新准入。每病例产物原子写出、摘要验收，恢复跳过已提交病例。

验收包括真实短训练权重加载、真实压缩 CT 预测、原生几何写出、源权重不变、恢复产物不变、损坏输入/权重拒绝、未完成训练拒绝、ROI 非整图检查及已有 GPU 隔离回归。本地 CPU 验收与目标服务器 CUDA 性能分开报告。
