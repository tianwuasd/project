# CHD1282 MONAI Implementation Plan

**Goal:** 源文件只读、按需生成模型输入、保留旧模型兼容性，并提供可重跑的两例验收。

**Architecture:** 读取接口返回现有 CaseGeometry 和数组；在线适配器使用 MONAI 及已冻结的 nnU-Net 计划；有界内存缓存与现有资源事件衔接。

**Tech Stack:** Python、MONAI 1.5.2、cachetools 6.2.2、nnU-Net 2.8.1、PyTorch。

**Spec:** `monai-storage-design.md`。

## Global Constraints

- dataset1282_analysis 维护 MONAI 输入与 ImageCHD 适配；现有 Q 工程保留独立代码与运行身份。
- 不改变标签语义、患者划分、模型结构、损失、采样和训练参数。
- 保留旧预处理和检查点读取；紧凑结果无需原缓存数组。
- 验收上限两例、每网络两次更新；临时文件在已批准的专用目录，最后清理。
- 仅推送代码、公开文档和无患者数据的测试入口。

## Tasks

1. 添加真实数据验收入口，首先验证缺少在线接口时失败。
2. 添加 `input_source.py`、`online_input.py`、内存缓存和紧凑结果生成入口。接口提供 geometry/read_image/read_label/read_native_image/read_native_label/properties/verify_image。
3. 将 Xu、Blood、STU、SAM 和预测入口接入相同接口，保留旧数据合同；关闭在线模式中的磁盘输入缓存。
4. 验证两例数据等价、前景采样、模型更新与检查点重载，检查预算和异常路径；补充命令与依赖。
5. 复核源文件和发布边界，记录验收证据并清理副产物，提交到独立分支。

## Review Focus

来源变更、标签几何、训练/开发角色、原图和缓存坐标、缓存引用生命周期、并发预算重复计算、旧模型合同、预测输出空间及私人信息发布。

## Execution Record

- 基于 main f49102f9 创建分支；工作目录为已有隔离工作树。
- 临时依赖安装位置、两例验收范围和容量已获用户批准。
- 使用本文记录执行状态，避免另外生成计划工具的辅助目录。
- 已实现统一读取、紧凑元数据输出、内存缓存、三个模型和预测入口接入。
- 两例真实 CT：64³ 图像与标签、STU 前景块、SAM 提示块逐元素一致。
- Xu 四分支使用 smoke 配置；STU-Net-S 使用正式预训练骨干、32³ 块；SAM Turbo 使用正式权重。已完成有限更新、保存和重载后输出一致性检查。
- 四组完整源码兼容映射通过检查；未审核的源码摘要被拒绝；旧读取入口在不安装 MONAI/cachetools 时可用。
- 独立静态审查未发现重要新增缺陷。真实数据通过缓存驱逐、零保留缓存、内存不足资源事件、Blood 双线程切片读取与关闭检查。
- 留出集读取不提供标签，所得图像与旧输入逐元素一致，预测标签还原到原图空间一致。最后一次联合检查耗时 129.38 秒，进程内存峰值 4.35 GiB，未生成持久体积文件。
- Xu 短测显存峰值 1.06 GiB，STU-Net-S 为 0.28 GiB，SAM Turbo 为 1.60 GiB。训练更新与保存重载限定于上述模型；未执行 init、Blood 的训练更新或正式多卡训练。
- 这些结果证明两例范围内的读取与短流程功能，不推算整轮速度、完整数据容量或临床效果。
- ImageCHD 的两例真实 CT 完成冻结折读取，其中一例包含额外标签编号，按原工程的既定规则转为忽略区域；8 类 STU-Net-S 预训练骨干在 32³ 实际前景块完成有限 CPU 更新。
- Q 路线一现有工程通过来源校验后的输入接口读取同一例 Dataset1282 CT；旧缓存 64³ 和 MONAI 紧凑输入 32³ 均完成 11 类标签重排。该工程的冻结概率阶段仍需来源匹配的上游检查点。
- 本机在线冷读约 69–116 秒，旧缓存读取约 0.5–2.1 秒；单例内存命中约 0.03 秒。缓存上限与 Q 激活池预算已明确，整体训练吞吐尚未测量。
