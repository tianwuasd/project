# 预测运行与续跑

预测使用指定训练实验的最佳模型和预处理计划，不要求安装包版本文字、源码摘要或环境路径与历史记录完全相同。模型仍通过 PyTorch 严格加载参数，依赖缺失、模型结构不兼容和输入读取失败在实际调用时报告。

测试病例取自既定 cohort，仅允许 source_test、target_primary、target_secondary，检查患者与训练/开发集互斥。CT 空间采用 Excel 毫米间距及 nnU-Net 计划的轴排列、裁剪信息，输出还原到病例原数组形状。

预测目录已有 run.json 时，使用同一目录和 --resume。续跑保留原名单、模型快照及任务编号，不要求当前代码摘要相同；预处理结果、分支输出和最终病例记录逐病例复用。改变病例名单、训练目录或预测模式需要另建实验。

预测不重复扫描 CT、缓存、参考标签和模型文件的完整摘要。完成标记仍关联病例、任务和输出形式，模型/数组由正常读取验证。请勿在同一预测目录更换输入内容或权重。

`scripts/prediction_local_check.py --image PATH` 仅用一例真实 CT 验证读取、内存中技术模型保存/加载、前向计算及空间还原。零训练更新、零磁盘产物；不验证正式训练权重的精度、GPU 调度或完整测试集效果。
