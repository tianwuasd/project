# 原网格评价加速与接续

预测结果保持原样，evaluate只读取原始GT与已导出的原网格分割。几何尺寸和毫米间距来自已冻结的run.json，不需要打开预处理CT数组；NPY和B2ND均可继续供模型读取。Dice、HD95、ASD仍使用原来的逐体素交集及6邻域边界、双向最近表面体素中心距离和原毫米间距。

类别计数与交集分片累计；每个结构在自己的包围框内用连续数组提取表面，保留全图偏移坐标。原网格表面点的顺序与数值保持相同。病例可并行处理，默认最多4例，资源按v2的CPU/内存80%预算动态准入；内存按原尺寸保守估计，可用预算不足时等待。`evaluate --workers N`可指定并发上限，距离查询内部不再额外扩大线程数。

每个完成病例提交到evaluation-checkpoint.json，重新启动时核对任务、GT和预测文件的大小及修改时间，复用未变化的结果。旧版本没有检查点时，可从evaluation.log中的完整结构指标和病例完成记录恢复：必须具有全部10类记录且原件/分割不晚于完成时间；不完整或变化的病例重新计算。旧日志恢复在新日志追加前执行，末尾未完成行不作为结果。原预测任务及分割文件身份仍按原规则核对。

EvaluationLog继续提供结构阶段耗时，病例完成数为累计数；ETA仅使用本次新计算病例，复用数量另记reused_cases。评价结束写evaluation.json，检查点和少量日志保留。评价不运行模型或GPU，也不重新生成分割。

本地真实64³训练模型输出的Dice/HD95/ASD与旧实现完全一致，串行与双线程评价、旧日志恢复、检查点复用和变化文件拒绝复用通过。同一病例512×512×322原标签中非空心肌结构的100978个表面坐标完全一致，表面提取由3.9125秒降为1.2327秒，约3.17倍。该结果仅为单结构基准，不能外推整个服务器任务或四病例并发的固定倍数。完整Linux任务准入和服务器总体速度仍以实际日志为准。
