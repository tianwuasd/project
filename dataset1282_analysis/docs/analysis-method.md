# 分析方法与参照

本工程是描述性数据审计，不进行诊断或临床质量评级。检查项来自影像格式语义、可复算统计和显式数据合同。没有经过验证的 CT 质量阈值时只报告观测值，不用任意阈值自动删病例。

## 格式、数值与空间

NiBabel 的 [NIfTI说明](https://nipy.org/nibabel/nifti_images.html) 区分空间变换、qform/sform 和数值缩放。程序记录原始 dtype、shape、头间距、单位、选用 affine、qform/sform 及代理 slope/intercept；分别比较数组尺寸与空间头，并记录标签减影像的原点差。差值单位注明为 header units。

统计使用 `stored * slope + intercept` 后的值，同时由同一变换推回存储值范围。若缩放和原始 DICOM 转换流程缺少保真证据，不能称为 HU。Excel中的 PixelSpacing、SliceThickness、calc_zSpacing 作为来源记录单独统计；层厚不等于层间距，不能直接覆盖 NIfTI。

## 全体素统计与近似分位数

参考 [NiBabel代理及内存说明](https://nipy.org/nibabel/images_and_memory.html)，程序避免 `get_fdata()` 默认缓存整个 float64 体积。正式统计在顺序 gzip 解压中读取 z 块，读取到EOF以触发压缩校验，并同时计算压缩文件SHA256；支持3D单文件NIfTI代理的Fortran存储顺序。

体素总数、有限/非有限数、有限值最小/最大、均值、总体标准差和逐z切片统计使用全部体素。跨块采用合并均值与M2的稳定公式，标准差除以有限体素数N。无有限值时相关统计为空，不填0。

分位数使用全数组Fortran线性索引上的等距确定性样本，默认最多100,000个；去掉样本中的非有限值，保留实际样本数。固定输入和采样预算时与分块大小无关。它不是随机独立抽样，也不提供置信区间；可能遗漏局部极端值，不能用于证明无伪影。

## 标签统计

每个实际非零数值类分别计算体素数、占整卷比例、包围盒、触边和连通域。不把不同类别合并为同一个连通对象，不默默四舍五入非整数值。空标签、非有限和非整数值单独报告。

为防止把连续浮点影像误当分割标签后占满内存，max_label_values默认128，是资源边界而不是医学阈值。超过时仍完整读取、统计非有限/非整数和前景体素并保留文件SHA，但逐类统计和拓扑明确标为not_computed_cardinality_limit；不取整、不保留一个看似完整的前128类表。

[SciPy `ndimage.label`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.ndimage.label.html) 要求连接结构对称。默认使用3D一阶连接（六邻域），并明确记录该设置；类别包围盒内执行连通域分析、按平面累计大小。多连通域只是形态描述，不说明某标签必然错误；本轮不删小连通域或补画标签。

未知空间标定时仅输出体素计数，不输出毫升体积或毫米距离。Label 1等名称仅表示数值，不代表已确认的解剖名称；文件名class后缀不当作疾病类别。

## 元数据与可视复核

只用 `idx == source_key` 的一对一严格对应；重复键和不匹配分别保留。PatientID始终作为文本，不自动合并同ID记录。年龄为采集日期减出生日期除以365.2425；无效日期和负年龄标记，年龄不代替临床诊断。

借鉴 [MRIQC指标组织方式](https://mriqc.readthedocs.io/en/latest/measures.html)，把逐例指标、总体分布与人工可视复核分开。本工程没有运行MRIQC，也没有移植脑MRI专属SNR、组织掩膜、伪影分类或评分阈值。

QC图使用固定规则选样和三个正交数组切面，标注轴下标。叠加发生在数组索引空间；不重采样到物理空间，不认证标注对齐。抽样理由保存为JSON；小样本可视报告不能证明所有标注正确。
