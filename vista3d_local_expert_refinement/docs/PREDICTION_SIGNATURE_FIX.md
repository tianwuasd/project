# 0.7.1：固定batch训练结果可直接用于预测

0.7.0将用户选择的global batch写入训练签名，预测冻结仍按旧字段重建整个签名，导致合法的已完成训练被拒绝。本修复保留训练记录的selected_global_batch_size，不从预测默认值重新推断；非正整数、未知签名字段、计划/划分/环境不一致继续拒绝。

## 已有训练的使用

更新面板到0.7.1后，在3预测选择原0.7.0已完成的训练任务。保留原预处理、run.json和全部权重，不重训、不改签名。预测建立独立输入副本，沿用原模型选择、检查点和目标中心；原训练目录保持不变。

旧失败预测任务仍使用冻结0.7.0源码，直接“重启”不能验证新修复；新建预测并选择原训练任务。权重或输入在选择后发生变化，原SHA256校验仍会拒绝。没有完成的正式训练不会因修复变成可评价状态。

## 小修兼容规则

默认保留已完成训练的可用性；不能仅因面板/日志/预测入口小修就要求重新训练。兼容性按训练语义、数据协议、结构及产物身份判断，不能仅按版本号或删除签名字段。

当前06_configs/prediction_code_compatibility.json精确绑定已发布0.7.0到本次0.7.1的完整代码摘要映射。此次只有evaluation.py和面板版本变化；训练器、损失、优化器、预算、预处理和预测算法未改。其他未知代码差异继续拒绝。

审计记录追加保留，支持精确身份之间的累计兼容路径；后续小修维护者需验证受影响合同、添加旧→新审计及输入复用回归，不能用新记录覆盖旧路径。重大训练/结构/数据协议变化明确说明兼容边界。本次没有审计或承诺0.7.0之前更老版本的迁移。

运行时缺少/损坏审计文件或代码不在精确路径中，差异校验失败关闭。审计属于当前代码release并受任务源码清单保护，不读取旧训练工作区中可能存在的同名文件。

## 验收范围

回归覆盖固定和非默认batch、预测环境变量不覆盖训练选择、相同代码旧字段形状、精确升级/累计路径、未知代码与字段拒绝、计划/划分/环境/完成状态严格检查、run及权重字节保持、重复冻结与权重变化拒绝。

本机独立合成数据流程与最终检查结果见PREDICTION_SIGNATURE_VALIDATION.json。短训练夹具不是250轮正式实验；本地CUDA不代表目标Linux/NCCL、多卡或真实CT效果已验收。
