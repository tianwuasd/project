这里不保存病例或患者清单。首次“预处理”从显式指定的 Wholeheart_Train_Dataset 创建清单，写入独立结果目录的 `04_data/manifests/`。

CT 中心 A/B/G 各 20 个原始病例，沿用既有质控隔离 Case2009/Case2017。初始发现只读取影像摘要并检查标签文件存在，不打开标签。每个来源中心按固定 SHA256 顺序划分为 4 fit、2 cal、2 selector，其余为 U；来源标签只在 fit/cal 预处理时读取并冻结摘要。目标标签只在正式模型冻结后评价时读取。

已知限制：病例编号与影像摘要不能证明患者独立性。当前仍为探索性中心留出协议；取得患者关联后须按患者重新核实划分。不得将运行时清单或原始影像提交到代码仓库。
