# 全局老师与局部学生：测试时通过意见审查与点击修正实现协同分割

## 1. 按用户澄清后的研究问题

老师与学生学习同一批来源中心材料。老师关注整体解剖和全局分割，多个学生分别强化不同局部的学习。测试目标中心 CT 时，学生在各自擅长区域提出标注意见，老师结合图像和整体上下文审查；认可的意见通过正负点击驱动交互分支修正老师的分割。最终输出是老师吸收局部意见后的结果。

已确认的数据条件：来源中心有少量已标注 CT 和其他未标注 CT；目标中心未标注 CT 用于预测。当前方案在测试时冻结所有模型参数，仅更新分割和提示状态。这是面向跨中心泛化的协同推理，不是目标中心参数适配。

此前“纠错生成伪标签，最终只部署学生”的解释不符合用户想法，已撤回。本文取代早先备忘录的角色安排。辅助伪标签仍可用于训练，但不是研究主贡献。

**判断：思路值得做小规模验证，核心价值在于局部专家能纠正全局模型，而全局模型能过滤错误局部建议。创新与跨中心收益均尚待实验，不由组合模型本身自动成立。**

建议暂称“全局—局部专家的选择性提示协同分割”。“老师—学生”可以作为直观比喻；论文需说明部署时保留多个学生，避免被理解成传统知识蒸馏。

## 2. 两个方向的数据流

### 训练阶段

同一批来源中心材料 → 全局老师的整体学习 + 局部学生的专长学习。

来源中心有标注样本还用于生成“采纳建议前后”的实际质量变化，训练老师的审查能力。来源中心无标注样本用于自监督、跨增强一致性或经过筛选的伪监督；不能产生真实的纠错收益标签。

### 测试阶段

~~~mermaid
flowchart TD
    X[目标中心 CT] --> T[全局老师：初始分割]
    X --> S[多个局部学生：各自擅长区域的预测]
    T --> P[对比分歧，生成带类别和位置的局部建议]
    S --> P
    P --> G{老师审查建议的预期收益}
    X --> G
    G -->|认可| C[转为正负点击]
    C --> R[VISTA3D 交互分支局部修正]
    R --> M[更新老师的全局分割]
    M --> P
    G -->|没有可接受建议或预算耗尽| O[输出老师当前分割]
~~~

这里的“点击”是输入三维坐标、目标类别和正负标签，不需要操作图形界面，也不必先引入大语言模型。

DualClickMed 是 MedSegFM 2025 工作，所核对正式章节在2026年5月上线；SAM-REF所读v4为2025年4月版本；SAT3D为2026年论文。各论文的场景、提示来源与训练/推理角色不同，不能只凭“全局、局部、点击”三个词判断相同或不同。

### 值得提出的三个可证伪假设

1. **专长互补**：在老师出错的局部，专长学生比无分工的同等预算模型更常提供正确意见。
2. **异议审查**：老师能识别对自己有帮助的异议，降低有害修改，同时保留足够的有效修改。
3. **交互吸收**：通过点击让老师重新解释图像，比直接投票、平均概率或覆盖学生局部掩膜更有效，且跨中心仍保留收益。

这三点才是论文需要证明的内容。未检索到完全相同的闭环不等于证明首创。若简单加权融合同样好，点击机制的价值就不足；若局部学生只是多看了高分辨率图像，则要与等分辨率的单老师局部细化对照。

## 5. 推荐的第一版：一个老师、两个专长学生、一个轻量审查头

这是讨论中的建议，不是已批准实施方案。

### 5.1 如何实现“相同材料、不同专长”

不按医院划分学生，也不把每个学生锁死在少数患者上。各模型可访问同一批来源数据，通过不同目标结构、裁剪尺度、采样比例和损失权重形成专长。

例如在标签支持的前提下，可以让一个学生侧重较大结构的边界，另一个侧重细长结构与连接区域；最终分工应按实际分割标签确定。若只有心腔和大血管标签，不能凭空训练冠脉或缺损专家。

学生依然需要周围上下文，不建议按固定坐标把体积机械切成上、中、下区。异常解剖会改变结构位置。RoI 定位必须在测试时自动可得，且不能完全依赖老师已有前景：老师漏掉的区域若根本没被裁给学生，学生就无法纠正。可使用重叠窗口、扩大解剖区域或独立粗定位，并设置定位失败回退。

可选两条实现路线：

- **独立轻量学生**：容易形成不同误差模式，推理成本较高；适合先验证互补性。
- **共享编码器、多个专长头**：成本低，误差可能相关；适合作为公平对照或后续简化。

先保留两条的比较价值，第一版不必创建很多学生。也不应把学生所有位置都强制蒸馏成老师相同输出，否则会压掉用户希望保留的局部优势。

### 5.2 老师如何审查

原始 VISTA3D 不自带一个经过验证的“学生意见是否成立”接口。可给老师加入轻量的建议价值预测头，复用图像特征，不必增加另一个完整大模型。

建议输入：

- CT 原始局部影像与整体上下文特征；
- 老师当前分割、学生在其专长区域的分割、二者的分歧；
- 目标类别、学生身份、候选位置及正负方向；
- 经来源验证数据校准的可靠性信号；
- 已接受点击及轮次状态。

输出是建议的预期收益或接受概率，另有“不修改”选择。**不能把“学生和老师一致”作为主要接受标准，因为真正有价值的建议恰恰会反对老师当前结果。**

### 5.3 怎样得到审查监督

在来源中心有真值的数据上，先实际执行学生建议的点击，再比较修正前后结果。训练信号来自实际编辑效果，不仅是点击所在体素是否正确：

$$
\Delta(a)=Q(M_{\mathrm{after}(a)},Y)-Q(M_{\mathrm{before}},Y)-\lambda\,C(a).
$$

Q 是预先定义的分割质量，可综合整体与目标局部的表现；C 惩罚破坏原本正确区域、引入错误连接或不必要的调用。第一版可先用简洁的区域误差与全局损害定义，避免堆积未经验证的指标。

以 Δ 超过小正阈值作为可接受建议，或直接回归 Δ 并排序。要采到有益、无效、有害三种建议。真值只用于来源中心训练监督；目标中心推理时由审查头预测收益。

尽量用患者级折外预测或独立开发病例产生错误状态；不要只在老师与学生已经记住的训练病例上学习审查。还要加入实际多轮纠错产生的状态、模糊与重采样等受约束扰动，减少训练仅见单步干净状态而测试面对累积误差的差距。

**第一版推荐离线监督学习，而非立刻强化学习。** 它更容易定位失败来自学生、提示转换还是老师。若之后发现单步有益决策不能形成好的序列，才有理由引入长期奖励。

### 5.4 源中心无标注数据怎样用

可以对老师和各学生做对应视图的一致性训练，或先做结构表征学习。需把几何增强后的预测映射回同一坐标再比较。若使用伪标签，对不可靠区域忽略或降权；不把师生共识当成真值。

来源无标注样本不能直接提供 Δ 的真实监督。审查头不能用自己或老师产生的“好坏标签”自我循环后声称已学到真实质量。

若以 VISTA3D 预训练权重开始，同一材料是指本任务的来源中心适配材料，并不意味着老师此前没有额外预训练数据；所有基线要记录并公平使用这些预训练资源。少标签下先保留交互分支，微调自动分支或少量适配参数，并检查其交互能力有无下降。

## 6. 如何把学生意见变为点击

以一个目标类别为例，在学生专长区域对比学生预测 S_k 与老师当前分割 M_t：

- 学生认为应属于目标、老师没有的区域：候选正点击，表示“这里可能漏分”。
- 老师认为属于目标、学生认为不属于的区域：候选负点击，表示“这里可能多分”。

这些只是疑似错误区域，在目标中心不能称为已知假阳性/假阴性。对分歧连通区域选内部、稳定且离边界较远的代表点，并记录目标类别和物理坐标。小区域、歧义边界和缺失类别需单独处理。

老师审查候选后，每轮先接受最有把握的一条，再调用交互分支；更新分歧后再决定下一条。避免一批相互冲突的建议同时生效。多类别场景需检查新增区域是否侵占另一结构，以及正负点击是否指向同一目标类别。

停止条件可先用：没有预测收益足够的建议、达到固定预算、重复修改同一区域或出现往返振荡。测试时停止不依赖真值。可额外记录修改前后审查分数作为回退实验，但这仍是预测判断，不保证每例必然改善。

VISTA3D 原生类别、提示格式、坐标变换和局部合并代码尚未在本轮接入或运行；实施前须核对。没有相应自动类别时，要在来源标签上建立自动分支映射，不能把不支持类别的测试种子从真值生成。

## 7. 怎样对应跨中心问题

同一来源中心训练的全局老师与局部学生可能一起出错，也可能局部高分辨率学生更依赖本院纹理。因此“专长协作”与“跨中心鲁棒性”是两个需要分别检验的命题。

训练中可使用合理的噪声、模糊、层厚/重采样及强度扰动，检验专长和审查决策是否稳定。不能把增强期相、病理差别都当作可随意改变的风格。对于先心病，要保留真实异常连接，不能用固定健康拓扑否定学生。

如果有多个来源中心，用来源内部留一中心训练/验证审查头。若只有一个来源中心，模拟域变化只能帮助训练，不能充当真实外部中心验证。

目标中心只用于固定模型预测。要报告跨中心 Dice、表面误差或连接错误，仍需独立保留的专家评价/标注子集；这些标签不用于训练或阈值选择。未见中心的收益尚无本项目实验支持。

## 8. 最便宜的验证顺序

### 第一关：学生有没有可利用的局部优势

先让老师和两个学生独立预测来源验证数据。统计“老师错误、学生正确”的区域比例、能覆盖的错误种类，以及误差相关性。若几乎没有这种区域，先调整专长学习，不训练复杂审查器。

同时比较无专长的同容量学生，以及老师自己以同样高分辨率看局部的结果，分清专长、分辨率与模型数量各自的作用。

### 第二关：这些意见能否通过点击转成改善

把学生建议逐个转为点击，实际运行老师交互分支。分析真实质量变化。用真值只在分析中选择有益点击，得到“真值辅助接受”上界。

这一步分清两个瓶颈：学生意见正确但点击表达不够；或者老师即使得到正确提示也无法完成局部修正。该上界只用于可行性分析，不能冒充可部署方法。

若单步上界弱，不足以证明所有多步路径无效，但应先检查少量短序列的互补点击，避免把长期收益漏掉；第一版不应直接跳到大规模强化学习。

### 第三关：老师能否学会选择

比较全部接受、简单学生置信度、提示扰动一致性、学习收益审查、真值辅助上界。不能只报告有害修改率，因为全拒绝也会显得安全；同时报告有效修改覆盖率、净收益和最终分割质量。

### 第四关：是否值得保留这套协作

至少比较：

| 对照 | 排除的替代解释 |
|---|---|
| 老师单独自动预测 | 基础水平 |
| 各局部学生独立预测 | 是否只是某个学生更好 |
| 老师与学生概率融合/局部覆盖 | 点击重新分割是否必要 |
| 老师＋无专长学生，匹配模型数/计算预算 | 专长分工是否必要 |
| 老师自有局部高分辨率细化 | 学生价值是否仅来自看得更清楚 |
| 老师＋专长学生＋全部接受点击 | 审查是否必要 |
| 老师＋专长学生＋简单筛选 | 学习审查是否优于便宜规则 |
| 完整协作框架 | 目标方案 |
| 仅分析的真值辅助点击上界 | 还有多少可用空间 |

主要评价最终老师分割，逐患者、逐结构、逐中心报告。记录每轮质量曲线、最差病例、关键连接错误、自动点击数、时延和显存。跨中心评估所有方案使用相同患者划分、标签预算与预训练条件。人工点击和自动点击应分别报告。

## 9. 我的建议

先选一个清晰分割任务和两种可解释的局部专长，做“互补性→实际点击收益→审查能力”三个小实验。只有三关都有空间，再扩大到更多结构和外部中心。

论文主张可暂写成：
