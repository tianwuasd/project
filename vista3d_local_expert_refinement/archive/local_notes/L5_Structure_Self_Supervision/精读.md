## 摘要
> **来源**：Abstract，PDF p.1。

S²DC 面向三维医学自监督学习，假设同一结构内 patch 应有语义一致性，不同结构 patch 应有差异。先通过跨增强视图的可靠匹配区分 patch，再根据邻域相似度分布进行结构内软正则。实验覆盖10个数据集、4类任务、CT／MRI／PET三种模态。这里的结构感知由无标签特征关系形成，并非已获得人工器官类别或真实连接图。

## 1. Introduction
> **来源**：Section 1，PDF p.1–2。

固定 patch 切分忽略器官的位置、尺度、形态变化；局部特征既可能混淆不同器官，也可能把同器官不同位置分开。作者以肝脏等大实质器官和细小复杂静脉说明差别，提出结构内一致、结构间差异两原则。单独把所有 patch 拉远会损伤结构一致性，单独拉近又会混合器官，因此需要两个约束配合。

## 2. Related work
> **来源**：Section 2，PDF p.2–3。

比较对比式、重建式 SSL、几何对应和多尺度特征。已有方法利用增强不变性、位置先验、重建缺失内容或多尺度上下文，但固定块和均匀贡献未必反映解剖语义。本文的增量不是新分割头，而是预训练阶段如何定义局部对应与关系正则。

## 3. Methods
> **来源**：Sections 3.1–3.4，PDF p.3–5，Eqs.(1)–(9)、Figs.2–3。

### 3.1 Preliminaries

采用 MoCo 式教师—学生、历史特征队列及 InfoNCE 全局损失 $\mathcal L_g$。从体积裁子体积，增强得到两个视图；教师和学生输出用作正对应。几何等变性假设输入的仿射变化也应体现在 token 特征空间，token 对应输入 patch，以建立稠密局部监督。增强强度过大、裁剪出视野或插值误差可能破坏对应可靠性，需实现层面处理。

### 3.2 Patch-to-patch discrepancy

利用已知仿射变换 $H$，检查 $H(c_i)$ 是否落在另一 patch 中，并反向检查 $H^{-1}(c_j)$ 是否落回原 patch，双向满足才给 $M_{gt}(i,j)=1$。这是由增强生成的几何真值，未用人工器官标注。

医学图像重复纹理让原始特征相似度 $M_t$ 产生歧义。作者讨论熵正则最优传输 Sinkhorn，但主实现为高效 dual-softmax：

$$\hat M_t(i,j)=\operatorname{softmax}(M_t(i,\cdot))_j\,\operatorname{softmax}(M_t(\cdot,j))_i,$$

$$\mathcal L_{p2p}=-\frac1{|M_{gt}|}\sum_{i,j}M_{gt}(i,j)\log\hat M_t(i,j).$$

双向归一化提高互近邻的一致性，把不同位置 patch 当不同对象，增强区分能力。文中以最优传输视角解释，不应误写成全部实验都用完整 Sinkhorn 求解。

### 3.3 Patch-to-structure consistency

对锚 patch $t_n$，计算与另一视图全部 patch 的相似度向量 $D_n$。同结构存在多个相似 patch 时分布有多个峰；独特结构可能只有增强对应的单峰。用简化 Sharpe 比率

$$sr_{V_i}^n=\frac{\max(D_n)-\frac1N\sum_{m=1}^ND_n(m)}{\sigma_{D_n}}$$

表征分散程度；低比率对应多个类似语义的 patch。以各视图内 $sr$ 的 softmax 权重平均后调节每一对的 $\mathcal L_{p2p}(n,m)$，再对 $N^2$ 个位置平均得 $\mathcal L_{p2s}$：

$$l_{n,m}=\frac{[\operatorname{softmax}(sr_{V_i})_n+\operatorname{softmax}(sr_{V_i'})_m]\mathcal L_{p2p}(n,m)}2,\qquad\mathcal L_{p2s}=\frac{\sum_{n,m}l_{n,m}}{N^2}.$$

因此不对具有多个相似同结构 patch 的区域施加强烈一对一区分，兼顾结构内一致。注意原文公式分母写 $\sigma_{D_n}$，紧随正文称其为 variance（方差），与通常标准差符号习惯不同；本笔记保持原文，具体实现需查代码，未擅自纠正。

### 3.4 Overall loss function

$$\mathcal L=\mathcal L_g+\mathcal L_{p2p}+\mathcal L_{p2s}.$$

三项等系数相加。软权重建立在当前模型特征上，属于结构语义近似；并没有严格保证相似性必然等于同一器官。

## 4. Experiments
> **来源**：Sections 4.1–4.3，PDF p.5–8，Tables 1–8。

### 4.1 Datasets and implementation details

BTCV 任务按 VoCo 设置使用 BTCV 与 TCIA COVID-19 约1k CT 预训练，其他 CT 分割用10k CT；另有6,605例 OASIS3 MRI 和3,519例 UDPET／ADNI PET。各模态分别预训练，不能理解成单个跨模态统一模型。默认 Swin-B，100k 迭代、$96^3$ 子体积；分割、图像转换、重建用 Swin-UNETR，分类用 Swin-B。数据划分及完整训练配置被引用到未附的 Appendix，本地11页仅正文及参考文献，病例级比例本轮未核对。

下游分割：BTCV、MSD-Liver／Lung／Spleen、BraTS21、AUTOPET；分类：CC-CCII 和 ADNI-cls；重建：UDPET；图像转换：BraTS23。指标分别为 Dice、准确率、PSNR／SSIM（及转换 NMSE）。多数 BTCV 对照从既有论文引入，而其他多模态对照重新训练，证据强度需区分。

### 4.2 Results on downstream tasks

BTCV 平均 Dice：从零 Swin-UNETR 80.53%，VoCo83.85%，S²DC84.14%；并非每个器官最佳，例如静脉75.22%低于VoCo78.19%。多任务分割 Table 3：S²DC 肝83.43%、肺64.40%、脾95.73%、AUTOPET46.47%、BraTS21三肿瘤区平均87.09%，总平均75.47%，从零71.15%、VoCo74.66%。正文p.6 把75.47%放在BTCV叙述附近易混淆，这里按表格明确它是Table 3总平均。

分类 Table 4：CC-CCII95.34%、ADNI56.72%、均值76.03%；从零对应88.04%、56.17%、72.10%。ADNI 增幅很小，不能用总体均值遮盖困难任务。Table 4 图注称“6k MRI预训练”，但任务表标CT和PET、设置按模态说明，存在图注与设置不一致，需代码／作者版本核对。

BraTS23 的 T1→T2：S²DC PSNR25.96、NMSE0.1161、SSIM0.8839，而从零PSNR26.57更高，故并非所有指标都优；T1→T1ce为32.65／0.041／0.9412。UDPET用1/50剂量重建，全模型SSIM都接近0.99917；S²DC PSNR58.4649高于从零58.4100，但增益小，不夸大为显著临床差别。作者报告跨任务综合分数81.43%对从零77.93%，这依赖其归一化汇总，不当成通用准确率。

### 4.3 Ablation study

仅全局损失的BTCV／AUTOPET Dice83.43%／45.72%；加p2p为83.98%／45.85%，加p2s为84.02%／46.23%，两者共同为84.14%／46.47%。t-SNE、轮廓系数、PCA特征图支持结构间更分离、结构内更紧凑，但这些可视化不是因果证明。CC-CCII用10%、50%、100%数据时，S²DC准确率88.29%、93.89%、95.34%；标签效率结论以该任务为限。

## 5. Conclusion
> **来源**：Section 5，PDF p.8；References，p.9–11。

两步结构关系约束可改善多模态下游迁移，未来考虑更大数据和跨模态泛化。正文未单列系统局限：相似纹理不一定代表相同解剖，异常连接可能违背结构一致假设；不同骨干／增强及预训练规模的适用性仍需检验。本地PDF未附Appendix，额外匹配算法及训练细节未核对。

## 对先心病 CT 的潜在迁移（推断）

若有未标注CT，可在严格排除最终测试患者后做结构自监督，再迁移分割／患者级分类。保持同骨干、相同预训练数据及预算，比较随机初始化、普通对比学习、S²DC，并测10%、25%、100%标签和多随机种子。异常短交通支、间隔缺损边缘可能被一致性正则弱化，必须单独评价病理连接召回，不能把正常结构相似性当硬约束。本文一般医学任务没有直接验证CHD。下一步先核对权重和代码，避免小样本从零复刻大规模预训练后将预算差异误认作方法收益。
