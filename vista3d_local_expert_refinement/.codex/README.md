# 项目交接入口

接手时先读 [HANDOFF.md](HANDOFF.md)，然后按需要查看：

- [STATE.json](STATE.json)：当前状态、已确认条件、建议、缺口和数量。
- [DECISIONS.md](DECISIONS.md)：用户确认与研究建议的区别，以及历史冲突处理。
- [NEXT_STEPS.md](NEXT_STEPS.md)：尚未执行的后续工作。
- [ENVIRONMENT.md](ENVIRONMENT.md)：正确学术 Agent 的位置、环境和快照恢复方式。
- [GITHUB_SYNC.md](GITHUB_SYNC.md)：本次 GitHub 同步授权、位置与范围。
- [ARCHIVE_MANIFEST.json](ARCHIVE_MANIFEST.json)：原始来源、文件映射与哈希。
- [ARCHIVE_VALIDATION.json](ARCHIVE_VALIDATION.json)：归档完整性及链接检查结果。
- [RESUME_PROMPT.md](RESUME_PROMPT.md)：下次继续研究时可直接使用的提示。

当前阶段是文献与框架准备完成。尚无模型实现、训练或跨中心性能结果。
