# 来源、版本与使用说明

本资料集包括三种材料：本地项目的精选源文件、对书籍与课程的原创整理、从官方仓库补充的源码快照。

## 逐文件溯源

- 本地项目以 `projects/` 下的清单为准，记录原始位置、导出位置、许可和 SHA-256。`code_project/` 等路径是来源根目录的逻辑名称。
- 官方补充以 [upstream/sources.json](upstream/sources.json) 为准，每个项目记录 Git commit，每个文件记录固定版本 URL、原件 SHA-256、导出 SHA-256、字节数及改动。
- 书籍和课程在各自目录中记录书名、章节、PDF 物理页码或原始笔记位置。书籍路径的 `ebooks/` 代表原电子书根目录，绝对路径仅保存在本地记录中。物理页码与印刷页码不可混用。
- 清理过的 notebook 保留代码、说明与出处，删除输出、执行计数、附件及无关元数据，并添加改动说明。清理后哈希与原件不同是预期行为。

## 许可边界

上游文件保留各项目许可证及原有版权声明。各子目录的许可证只覆盖相应上游材料；此资料集不为全部内容重新套用一个统一许可证。用户项目的精选代码依据用户本次整合与上传请求纳入，没有擅自为它们附加开源许可。书籍购买或本地保存不等同于获得公开再分发权，因此书籍原文、课程原始课件和许可不明确的第三方源码仅汇集于本地。

公开版不含患者影像、病例表、训练权重或运行日志。示例源码可能定义 DICOM 字段名或演示匿名化步骤；字段定义本身不是实际患者数据。任何脱敏工具都需结合实际影像的像素内容、私有标签及保留字段重新审核，不能仅凭脚本名称断言完成脱敏。

## 复现范围

源码快照的目标是阅读和对照。复制某个框架文件不会自动带入其依赖包、其余模块、数据与环境。来源项目、版本和调用上下文应一起核对。图像处理方案在目标任务上的适用性需要独立验证，本次整理不提供临床有效性结论。
