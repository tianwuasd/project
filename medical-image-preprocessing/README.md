## 建议学习顺序

1. 先理解灰度、直方图、卷积、采样和插值，再看课程中的图像恢复、形态学与配准。
2. 用书籍页码索引核对方法的假设：噪声模型是什么、强度是否有物理意义、图像是二维照片还是有空间坐标的三维体数据。
3. 读 nnU-Net 的 `default_preprocessor.py`，串起裁剪、归一化、重采样和前景采样。
4. 在 MONAI 中对照数组变换与字典变换，理解图像、标签和元数据如何一起流经流水线。
5. 用 SimpleITK 教程检查物理空间、变换方向和配准；用 TorchIO 源码比较强度变换和空间变换。
6. 用 pydicom 核对 DICOM 像素解码、强度缩放和显示窗口的区别，再回到官方教程串联输入检查、空间变换、归一化、训练采样和预测还原。

## 文件范围

`projects/`、`upstream/`、`books/`、`knowledge/` 是可上传目录。代码是**学习用精选快照**，并不构成可直接安装的完整框架。运行某个原项目应使用其完整仓库及对应版本环境；本次整理没有运行训练、下载影像数据或安装这些大型框架。

本地同名资料集还包含 `local-only/`：保存书籍定向提取文字、原始课程资料、课程代码片段和整理工作记录。该目录由 `.gitignore` 排除，并且不会复制到 GitHub 上传目录。公开版本的电子书内容是原创整理与页码索引，整本电子书不在此仓库中。

项目来源统一以官方仓库、固定 commit 和逐文件哈希记录。学习笔记是对原理与源码的整理，框架行为以对应版本的官方实现为准。
