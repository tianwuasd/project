## 如何使用

1. 从几何和强度的输入契约开始，避免仅看数组形状。
2. 每加入一种处理，先写预期改变的量和应保持的不变量。
3. 使用合成小数组定位算法/轴顺序问题，再进入受控影像实验。
4. 用独立的几何、强度和下游评价验证处理；“更好看”只能作为观察。

本轮没有执行原始课程代码、下载课程数据或训练模型。医学场景的映射是从课程原理作出的工程推论；参数范围和实际收益仍需在具体任务的数据划分与评价方案中验证。
