## 使用边界

- K053 是 CNN 基础教学 Notebook：KB001–KB013 涵盖卷积、CIFAR-10 输入、模型、训练和可视化，其中部分单元是 TODO 或依赖其他单元。`convolve2d`（KB002）未翻转核，语义为互相关。
- K054 是图像数据预处理 Notebook：KB014–KB023 包含目录/图片处理、`ImageFolder`、统计与增广，默认示例路径及固定尺寸假设不适合作为医学体数据通用函数。
- KB024–KB035 来自 D2L 笔记内的局部演示，KB036 来自优化笔记的 MATLAB 算例。这些片段只说明局部公式或教学数据通路；使用前应确认依赖、形状、坐标、标签和数据来源。
- 医学影像实验应另行建立合成数组测试和固定的数据划分。任何下载、安装、覆盖文件、模型训练或真实数据处理都未在本轮发生。
