# CT 缺失切片补全的方法与文献

检索日期：2026-10-16。这里讨论已经重建为 DICOM 图像的 CT 序列中，少数切片像素缺失时，如何利用其余切片估计缺失图像。重点是数学插值、配准插值和可复现的学习方法。

这个问题已有长期研究。2004 年的工作已经把非刚性配准与灰度插值结合起来，随后发展出多分辨率配准、切片合成网络及跨视图重建。对内部缺少 1～2 张、两侧参考完整的情况，值得先做受控实验；生成的切片应记录为估计结果，不能据此宣称找回了原始像素。[Registration-based interpolation](https://pubmed.ncbi.nlm.nih.gov/15250644/)

## 先区分任务

| 情况 | 对应任务 | 处理依据 |
| --- | --- | --- |
| 文件仍在，像素字段缺失或为空，但前后切片完整 | 缺失切片插值或补全 | 已知切片、物理位置和结构连续性 |
| 有完整像素，但切片间距较大 | 层间超分辨率或切片合成 | 稀疏体数据与先验；许多论文属于这一类 |
| 图像完整，仅分割标签缺少几层 | 标签插值 | 已有图像及标注；不能当成恢复 CT 灰度 |
| 像素完整，但噪声大、对比度差 | 去噪或增强 | 已观测的图像信号 |
| 投影角度不足或原始投影缺失 | 投影域重建 | 扫描器原始投影及采集几何；普通 DICOM 切片不等于这些数据 |
| 已登记序列的首尾缺片 | 外推或部分覆盖输出 | 缺少一侧参考，不能直接套用两侧插值 |

连续缺片的几何问题与均匀稀疏采样相近，但文件损坏、缺片位置不规则和心动期相混杂并不是所有论文都验证过的条件。

| [CFFNet，Self-supervised medical slice interpolation network using controllable feature flow，ESWA 2024](https://doi.org/10.1016/j.eswa.2023.121943) | 用位置参数控制特征流，合成中间切片；两阶段自监督学习减少对完整高质量训练对的依赖 | 有肝血管相关评价、作者代码和权重；两张缺片的位置和测试入口依赖需适配 |
| [I³Net，TMI 2024](https://arxiv.org/abs/2405.02857) | 联合层内、层间与跨视图信息进行切片合成 | CT 实验涵盖肝、结肠、肝血管，另有肾脏泛化与脑 MRI；代码及结肠 ×2、×4、×6 权重已核实 |
| [ACVTT，2025 预印本，TMI 2026 年卷期](https://arxiv.org/abs/2509.20242) | 将层内高分辨率纹理转移到层间视图；包含真实厚薄层配对及模拟稀疏采样评价 | 代码明确列出 ×2、×3、×4、×5，×3 与连续缺两张的几何位置相符；尚未在所查仓库中确认预训练权重 |

## 数学方法如何使用相邻切片

线性插值先作为基线。在两侧切片位置分别为 z0、z1，待补位置为 z 时，按实际距离计算权重 t=(z-z0)/(z1-z0)，估计图像为 (1-t)I0+tI1。两张图像的灰度必须处于一致的物理解释下；CT 应正确处理各自的 RescaleSlope 和 RescaleIntercept。

配准插值进一步估计相邻切片之间的结构对应关系，把两侧结构变换到待补位置后再融合。它利用了形状连续性，但结构在层间出现、消失或分叉时，对应关系可能不唯一。现有配准库可以用于构建基线；只有按原文实现并核对细节后，才能称为复现某篇论文。[多分辨率配准插值](https://doi.org/10.1016/j.camwa.2013.04.026)

不能把截图或独立拉伸后的 8 位图片当成保持 HU 的输入。为模型归一化时，应记录变换和截断范围；已被截断的信息无法通过反归一化恢复。正常切片应保持原样，只对明确缺失的位置输出估计值。

| [SAGCNet](https://github.com/JK-Liu7/SAGCNet) | 当前所查树只有 README，写明代码待上传 | 论文中给出代码地址，不等于当前已有可执行实现；而且对象是心脏 MRI |

**连续缺两张尤其需要核对采样位置。** 假设两侧正常片之间应放入两张等间距切片，位置是 1/3、2/3。CFFNet 本次检查的测试脚本在 `N_ot==2` 分支写的是 1/4、3/4；不能只把数量改为 2 就当成正确的等间距补全。应使用真实物理坐标生成位置参数，再检验模型在这些位置的表现。[作者测试入口](https://github.com/lpcccc-cv/CFFNet/blob/55646bab3a89fec260bbc157a348f5e1b01872b7/test_multi_frame_psnr.py)

单片缺失对应局部 ×2、连续两片缺失对应局部 ×3，只是几何对应关系，不保证某个以整卷均匀降采样训练的模型能直接处理不规则缺片。

## 建议的最小对照实验

以下是拟议实验，不是已完成的修复结果。

1. **确定候选。** 只选空间位置明确、两侧像素可解码、方向与网格一致、期相可确认的内部缺口。首尾缺片单独处理；其他期相的切片不直接作为同相位原片替换。
2. **在完整资料副本上模拟缺失。** 分别隐藏 1 张和连续 2 张，按真实缺口的物理间距与解剖位置选择样本。被隐藏的图像只用于评价，不得成为模型输入。若训练或调参，按患者分开开发与独立测试。
3. **先比较数学基线。** 使用按物理距离加权的线性插值，以及有正则约束的配准插值。不要预先假定配准一定更好。
4. **增加一个学习方法对照。** 单片场景优先核对 I³Net ×2 或适配后的 CFFNet ×2；两片场景先做好位置参数和 ×3 能力验证，ACVTT 可作为后续候选。这个顺序是工程建议，尚无本地性能结论。
5. **同时看灰度与结构。** 报告 HU 误差、PSNR、结构相似度，并检查缺片附近冠脉边界、分叉、中心线及三维连续性。若有可靠标注，可增加表面距离和连通性指标；全图平均相似度不能代替血管局部检查。
6. **比较失败例。** 分开记录单片、两片、分叉附近、明显运动或钙化等情形。测试不能支持某类缺口时，保留失败，不用“图像更平滑”替代验证。
7. **单独输出派生结果。** 保留原片、缺失位置掩码、方法与参数、输入来源及质量评价。估计补全不自动计入原始数据完整恢复，正式分类口径需与部分覆盖输出区分。

最值得先验证的路线是“线性插值作为基线 → 配准插值 → 一个有权重的学习方法”。现有的相关研究让这条路线有据可依，最终选择仍由目标资料上的对照结果决定。
