# Dougherty《Digital Image Processing for Medical Applications》导读

Geoff Dougherty，Cambridge University Press，2009，ISBN 978-0-521-86085-7。它以医学影像为场景讲数字图像处理基础，是三书中最适合建立预处理概念的一本。这里重点读第 4.3、5、6.3、7.7.4、8、9、10 章/节；未把全书临床成像章节写成已精读。

第 4.3 节讨论的是配准的任务定义和应用，第 8.6 节着重畸变/变形校正；它们不是一套现成的医学配准求解器。§7.7.4 讨论同态滤波与 MRI 强度不均匀的关联，不能等同于 N4 偏场校正。正文的灰度直方图标准化与深度学习训练时的强度标准化也不是同一个操作，应看目标模态、掩膜和训练统计量再决定做法。

**工程转译。** SimpleITK 的图像物理空间、`ResampleImageFilter`、`ImageRegistrationMethod` 可承接几何章节；偏场实验可对照 `N4BiasFieldCorrectionImageFilter`，但应标为现代方法而非本书算法。MONAI 的 `Orientationd`、`Spacingd` 和强度变换可组成可追踪流水线。nnU-Net 需要核对其当前 plans、预处理器和数据指纹后再比较目标间距、重采样与归一化；不能把书中的二维灰度示例当作 nnU-Net 的固定参数。
