## 组合建议

1. **选题到论文**：WenyuChiou AI Research Skills 或 ARS-Codex 负责研究问题与证据边界，Claude Scholar 管理文献，PaperSpine 或 Research Paper Writing Skills 负责稿件。
2. **AI/ML 实验论文**：AI Research Skills 负责工程与训练，Scientific Agent Skills 负责科学计算/数据库，ARS-Codex 或 ARIS 做研究流程与审查，最后用 PaperSpine 组织投稿材料。
3. **社科实证论文**：Auto-Empirical Research Skills 负责 Python/Stata/R 估计与稳健性，Claude Scholar 管理文献，PaperSpine 或 Research Paper Writing Skills 负责写作。
4. **工科汇报**：Codex Claude Academic Skills 负责 MATLAB/Python 和 Office，Paper Craft Skills 负责方法图与 deck，Nature Skills 可用于英文润色。
5. **无人值守改稿**：ARIS 适合自动推进，但早晨必须逐条检查其引用、数据和改写；可以再用 ARS-Codex 的证据/引用流程做人工复核。

## 使用前共同检查

- Skill 是会影响 Agent 行为的可执行提示与脚本集合；安装前应阅读对应仓库的 `SKILL.md`、脚本、MCP 和网络依赖。
- 任何论文引用、数据、统计结果、图表和投稿政策都应回到原始来源核验；“支持引用验证”不等于可以跳过人工审查。
- 文章中的星数、版本数和评价会随仓库更新而变化；本索引记录的是文章描述与当前克隆仓库 README 的交叉整理。
- 这里的仓库是源码快照，不代表已经安装到 Claude Code、Codex 或其他宿主；实际安装应遵循各仓库当前说明。
