# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 顶层结构

```text
auto-empirical/
  SKILL.md                       # 根路由器
  skills/                        # 多来源实证/写作 skill
  plugins/                       # Python/Stata/R 等插件源
  agents/                        # 宿主 agent 配置
  scripts/                       # quickstart、构建和检查脚本
  aers_score/                    # AER 任务评分器
  catalog/                       # skill 清单
  benchmark/ evals/ eval-harness/
  docs/ tools/ tests/
  demo-notebooks/ demo-StatsPAI-skill/
  Makefile pyproject.toml requirements.txt
```

## 2. 入口和路由

根 `SKILL.md` 将请求导向相应子流程。核心入口包括：

- `skills/00-Full-empirical-analysis-skill_StatsPAI/SKILL.md`；
- `skills/00.1-Full-empirical-analysis-skill_Python/SKILL.md`；
- `skills/00.2-Full-empirical-analysis-skill_Stata/SKILL.md`；
- `skills/00.3-Full-empirical-analysis-skill_R/SKILL.md`；
- `skills/50-brycewang-aer-skills/skills/aer-workflow/SKILL.md`；
- `plugins/empirical-analysis-python/skills/pipeline/SKILL.md`、Stata/R 对应插件入口。

## 3. 构建方式

skill 主要通过 Markdown 加载，没有统一编译二进制。三语言插件由 `plugins/build_plugins.py` 从 `skills/00.x` 生成，不应手改生成物。仓库提供 `Makefile`、`scripts/quickstart.py`、`make validate`/`make check` 和 `python -m aers_score tasks` 等开发/验证入口。

`make setup` 会创建环境、安装 requirements 并处理子模块；这属于完整环境操作，不是本地只读试用的必要步骤。`69-Paper-WorkFlow` 当前未初始化，相关目录和入口不存在，必须在文档中标明。

## 4. 依赖和平台

评分器和部分工具偏标准库，但完整验证可能需要 numpy、pandas、matplotlib、statsmodels、linearmodels；三套语言还分别依赖 Python 科学栈、Stata ado、R/Quarto。`pyproject.toml` 的 Python 下限与新版本 linearmodels 的实际要求可能不一致。Makefile 含 `source`、`rsync`、`find`、`rm` 等 Unix 命令，Windows 需要额外适配；quickstart 默认编码在 Windows 可能触发 GBK 输出错误。
