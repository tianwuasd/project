# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只读取当前项目的 `skills/auto-empirical/` 源码快照，不执行完整安装、子模块初始化、依赖安装、远程部署或外部 webhook。

## 1. 准备隔离目录

```text
local-empirical/
  question.md
  data/
  codebook/
  scripts/
  output/
  constraints.md
```

只使用数据副本和脱敏材料；原始数据、凭据和已有论文结果不要放入 skill 源码目录。

## 2. 只读取根路由

```text
请先读取 skills/auto-empirical/SKILL.md。
只根据 local-empirical/question.md 和 codebook/ 生成研究设计审计。
只写 local-empirical/output/design-audit.md。
不要安装依赖、初始化子模块、调用外部 API、发送 webhook 或运行估计。
```

确认主语言后，再明确读取对应入口，例如：

```text
请读取 skills/auto-empirical/skills/00.1-Full-empirical-analysis-skill_Python/SKILL.md。
在人工批准后，只分析 local-empirical/data/，脚本和表格写入 local-empirical/output/。
保留实际命令、软件版本和失败日志，不覆盖原始文件。
```

## 3. 受限验证

如果只需检查入口，可在人工确认后读取或运行 `python -m aers_score tasks`；不自动执行 `make setup`、`make validate`、`make check`，因为它们可能改变环境或需要科学依赖。Windows 下尤其先确认 shell、编码和命令兼容性。

## 4. 本地边界

- 只读取当前项目 `skills/auto-empirical/` 和明确的 `local-empirical/` 输入；
- 只写 `local-empirical/output/`；
- 不初始化 `69-Paper-WorkFlow` 子模块；
- 不自动安装 Python/Stata/R/Quarto 依赖；
- 不联网、上传数据或调用飞书/webhook；
- 每阶段人工确认后再进入下一阶段。
