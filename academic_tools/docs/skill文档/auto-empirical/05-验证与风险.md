## 已知失败和处理

| 现象 | 处理 |
|---|---|
| 69-Paper-WorkFlow 入口缺失 | 记录子模块未初始化，不用空目录假装流程可用。 |
| catalog 与实树数量不同 | 以当前实树和版本记录为准，保留差异说明。 |
| Windows Makefile 失败 | 先记录 Unix 命令不兼容，不为方便而修改全局 shell。 |
| quickstart 编码错误 | 明确设置 UTF-8 后再测试，保留原始错误日志。 |
| 软件估计不一致 | 对齐版本、默认参数、缺失值和标准误实现，再比较结果。 |
| 外部 API/webhook 触发 | 停止运行，确认数据、域名、凭据和发送内容。 |

## 风险边界

实证 skill 可以规范流程，但不能替研究者证明识别假设或因果关系。外部数据、pipe-to-shell 安装命令、可选 webhook、Stata/R 环境和大规模运行都具有额外副作用；默认使用最小权限、脱敏副本和有限预算。
