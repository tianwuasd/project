# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 设定实证问题

先把研究问题、因果对象、样本、结果变量、处理变量、识别假设和停止条件写入 `local-empirical/question.md`。不要从“跑回归”开始；先决定估计对象和证据标准。

```text
请读取 skills/auto-empirical/SKILL.md，先只做研究设计审计。
读取 local-empirical/question.md、codebook/ 和 data/ 的说明文件。
输出识别假设、变量映射、潜在混淆、缺失信息和下一步清单到 local-empirical/output/design-audit.md。
不要运行估计、联网、安装依赖或修改原始数据。
```

## 2. 选择语言与子流程

- Python：`00.1-Full-empirical-analysis-skill_Python/SKILL.md`；
- Stata：`00.2-Full-empirical-analysis-skill_Stata/SKILL.md`；
- R：`00.3-Full-empirical-analysis-skill_R/SKILL.md`；
- 综合 StatsPAI：`00-Full-empirical-analysis-skill_StatsPAI/SKILL.md`；
- 投稿和复现：`50-brycewang-aer-skills/skills/aer-workflow/SKILL.md`。

先选一个主语言，避免同一阶段由不同软件静默改变缺失值、固定效应或标准误定义。

## 3. 九阶段主线

按仓库已有流程依次完成：研究设计、数据理解、清洗与构造、描述统计、基准估计、诊断/识别检验、稳健性与异质性、结果解释、论文/投稿输出。每一阶段保存输入、脚本、参数、日志和人工决定；没有通过当前阶段的检查时不进入下一阶段。

## 4. AER 复现与投稿链

使用 AER 子套件时，先阅读其入口和 Gate A-E 要求，按顺序完成复现包骨架、代码运行、结果比对、文档和投稿检查。`69-Paper-WorkFlow` 当前是未初始化子模块，不能把它当作可用入口。

## 5. 输出契约

```text
local-empirical/
  question.md
  data/ codebook/ scripts/
  output/
    design-audit.md
    tables/ figures/ logs/ report.md
  constraints.md
```

结果报告要列出样本变化、变量定义、模型式、固定效应、聚类层级、缺失处理、实际软件版本、失败运行和未识别局限。

## 6. 人工检查点

- 确认识别假设不是由模型自动补齐；
- 从原始数据重算样本数和关键表格；
- 比较不同规格时只改变一个已记录的因素；
- 检查标准误、权重、固定效应和多重检验；
- 不把相关性改写成因果性；
- 论文中的每个数字都有脚本和输出文件定位。
