# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 顶层结构

ARS-Codex README 展示的核心结构：

```text
skills/academic-research-skills-codex/
  skills/academic-research-suite/
    SKILL.md
    manifest.json
    agents/openai.yaml
    codex/
      full-runtime-manifest.json
      agents/
      hooks/
      scripts/
    ars/
      deep-research/
      academic-paper/
      academic-paper-reviewer/
      academic-pipeline/
      experiment-agent/
      commands/
      hooks/
      docs/
      tests/
      shared/
  plugins/ars-codex/
    .codex-plugin/plugin.json
    skills/academic-research-suite/  # 插件实体副本
  README.md
```

根目录的 `skills/academic-research-suite/` 是可直接读取的 Codex skill 快照；
`plugins/ars-codex/skills/academic-research-suite/` 是插件分发使用的实体副本。两者都应以当前仓库版本为准。
## 2. 加载关系

1. Codex plugin marketplace 发现 `plugins/ars-codex/`；
2. 插件 materialize 单一 `academic-research-suite` skill；
3. `SKILL.md` 读取 router、模式和 vendored workflow；
4. `ars/` 保存与 Claude ARS 对应的内容、references、tests 和 shared contract；
5. Codex 专属 `codex/` 提供可选 runtime、agent 模板、hooks 和脚本；
6. `ars-*` command 文件是 prompt recipe，由 router 解释，不自动注册为 Claude 原生命令。

## 3. 构建方式

核心 skill 没有传统编译器构建。正常使用是插件打包/安装或直接把 `skills/academic-research-suite/` 作为一个 Codex skill 加载。版本由根目录 `VERSION`、skill metadata 和 `manifest.json` 适配版本共同记录，vendored ARS 来源 commit 记录在 manifest。

可选质量验证由仓库脚本和测试完成，例如：

```bash
python3 skills/academic-research-skills-codex/skills/academic-research-suite/codex/scripts/ars_codex_quality_gates.py all --json
```

脚本是否可运行取决于 Python、依赖和当前仓库版本；它不是安装步骤的一部分。

## 4. Codex 与 Claude 的边界

- Codex 不会自动运行所有 vendored Claude hooks；
- agent 文件是角色/阶段提示，默认不等于自动分派后台 agent；
- cross-model verification 只有在显式配置和同意后才发生；
- 普通浏览和程序化引用 gate 是不同路径；
- 缓存/stale advisory 不是当前来源证明；
- 如果要开发或修改本仓库，应同时阅读 `skills/academic-research-skills-codex/skills/academic-research-suite/ars/docs/SETUP.md`、`ARCHITECTURE.md` 和 quality gate 说明。
