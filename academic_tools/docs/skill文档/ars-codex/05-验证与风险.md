- [ ] 引用、数据、claim 和实验 provenance 有明确来源或未验证状态。
- [ ] 每个 pipeline checkpoint 有人工确认和阶段产物。
- [ ] 跨模型、API、脚本、写文件和联网调用在批准范围内。

## 常见失败

| 现象 | 处理 |
|---|---|
| 路由不正确 | 显式写 `$academic-research-suite` 和 workflow/mode，不照搬 Claude slash command。 |
| Citation gate 结果为空 | 区分离线无法验证与文献不存在，检查来源条件。 |
| Codex hooks 不生效 | 按适配说明确认 hooks 是否仅用于追溯，不把它们当作已执行的安全控制。 |
| cross-model 被拒绝 | 检查 provider、数据范围、费用和用户同意，不伪造 reviewer 结果。 |
| 脚本失败 | 保存错误、Python/依赖/commit，回到人工检查，不跳过 gate。 |
| 输出越过 checkpoint | 删除未批准的 downstream 草稿，回到最近一个已确认阶段。 |

## 风险边界

ARS-Codex 能约束工作流和报告证据，但不能证明原始数据真实、实验实际执行、引用支持 claim 或论文可以投稿。Codex router、vendored prompt、缓存和外部 reviewer 都需要按实际运行结果和来源复核。
