# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本文件只指导当前项目内的本地读取，不执行 Codex 插件注册、全局安装、依赖安装或仓库更新。

## 1. 本地入口

- 仓库：`skills/academic-research-skills-codex/`
- Codex 入口：`skills/academic-research-skills-codex/skills/academic-research-suite/SKILL.md`
- workflow：同目录下 `ars/deep-research/`、`academic-paper/`、`academic-paper-reviewer/`、`academic-pipeline/`、`experiment-agent/`

## 2. 最小本地调用

```text
请使用当前项目本地的 ARS-Codex。
先读取 skills/academic-research-skills-codex/skills/academic-research-suite/SKILL.md，
再使用其中的 deep-research 路由处理 local-run/question.md。
只读取 local-run/materials/，只写 local-run/output/，本轮完成后停止。
不要安装插件、修改全局配置或调用外部 API。
```

论文规划：

```text
先读取 skills/academic-research-skills-codex/skills/academic-research-suite/SKILL.md。
使用 academic-paper 的 plan 模式，读取 local-run/question.md 和 materials/。
只生成 local-run/output/blueprint.md，不写完整正文。
```

## 3. 本地输入/输出

```text
local-run/
  question.md
  materials/
  results/
  output/
```

让 Agent 把 blueprint、引用检查、审稿报告和日志写入 `local-run/output/`，不要写回 `skills/` 源码。

## 4. 本地引用检查

```text
Use the local ARS-Codex skill at:
skills/academic-research-skills-codex/skills/academic-research-suite/SKILL.md

Check only local-run/manuscript.md.
Write the report to local-run/output/citation-check.md.
Do not browse or call external services in this turn.
```

离线结果应明确标记哪些条目无法验证。

## 5. 本地运行边界

- 只读取当前项目的真实入口和必要 references；
- 只写 `local-run/output/`；
- 默认不运行 hooks、脚本、插件安装和外部调用；
- 需要联网、程序化引用检查、MCP 或跨模型时，先列出数据和权限，再单独批准；
- 每轮结束保存 prompt、产物、日志和未验证项。

## 6. 版本注意

本地读取的是 clone 时的快照，不会自动跟随上游更新。需要更新时另行执行 git 操作并重新检查 manifest、版本和质量 gate；本指南本身不执行更新。
