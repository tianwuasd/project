# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 载入和输入

```text
question.md
materials/       # PDF、笔记、引用和目标要求
results/         # 真实结果/日志
constraints.md   # 语言、格式、权限、停止点
```

每次写明路由、模式、当前阶段、允许读写位置和必须人工确认的节点。

## 2. Socratic 研究问题

```text
Use $academic-research-suite.
I want to study generative AI in higher-education quality assurance,
but my research question is not clear.
Use deep-research in Socratic mode. Ask narrowing questions first.
Do not write an outline. Stop after 2–3 candidate questions and feasibility concerns.
```

确认候选问题前检查数据可得性、范围、因果目标和研究时间。

## 3. 论文蓝图

```text
Use $academic-research-suite.
Route: academic-paper, mode: plan.
Materials: question.md, materials/, results/.
Output an IMRaD blueprint, claim-evidence matrix, and missing-evidence checklist.
Do not write full prose until I approve the blueprint.
```

确认蓝图后只写一个章节，并保留证据状态和用户待确认句子。

## 4. 引用检查

```text
Use $academic-research-suite: ars-citation-check.
Check manuscript.md section by section.
For each reference report metadata, source availability, locator, and exact claim support.
Mark failures unverified; do not substitute similar papers.
```

检查文献存在性、主题相关性和句子支持性三层，不要混为一谈。

## 5. 同行评审

```text
Use $academic-research-suite: ars-reviewer.
Focus on contribution, methodology, statistics, citation integrity, and venue fit.
Return evidence-anchored reports and an editorial decision letter.
State when the manuscript does not provide enough evidence.
```

修改后使用 re-review，只比较版本差异和 reviewer concern，不推断未提供的实验。

## 6. 分阶段 pipeline

```text
Use $academic-research-suite to start an academic-pipeline run.
Begin with Stage 0 intake and stop after the pipeline dashboard.
Show inputs, missing materials, permissions, and the next checkpoint.
```

每次只推进一个 checkpoint；保留 dashboard、Material Passport、日志和人工决定。

## 7. 常用别名

- `ars-plan`：论文 plan；
- `ars-outline`：大纲；
- `ars-abstract`：摘要；
- `ars-lit-review`：综述；
- `ars-citation-check`：引用检查；
- `ars-reviewer`：同行评审；
- `ars-full`：完整 pipeline；
- `ars-revision`：论文修订。

## 8. 预期产物

问题简报、检索/筛选记录、引用支持表、论文蓝图、reviewer reports、rebuttal、pipeline dashboard、Material Passport 和审计报告。没有来源、实验或用户确认的内容应保持未验证。
