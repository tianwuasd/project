# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 重要限制

当前 `skills/WenyuChiou-ai-research-skills/` 没有 `SKILL.md`，因此不能像其他已展开仓库那样直接让 Agent 读取并执行。本指南不执行 registry 安装、上游 clone、全局配置修改或远程部署。

## 1. 仅做 registry 审计

```text
请只读取 skills/WenyuChiou-ai-research-skills/catalog/、docs/、schema/、scripts/ 和 fixtures/。
检查插件、上游仓库、版本/ref、入口、许可证和权限。
只写 local-wenyu/output/registry-audit.md。
不要安装、联网、调用 API、修改 skills/ 或写入全局目录。
```

## 2. 上游使用前的安全流程

如需实际使用，先由人工选择一个插件和固定 ref，再在隔离目录获取上游源码。读取其真实 `SKILL.md` 后，沿用对应上游的本地使用指南；所有输出写入 `local-wenyu/output/` 或上游明确批准的副本。记录下载来源、commit、依赖、权限和删除方式。

## 3. 本地边界

- 不把 registry 描述当成可执行 skill；
- 不使用 `~/.claude/skills`、`~/.codex/skills` 等全局安装目标；
- 不自动执行安装脚本、CLI、MCP、网络请求或 API；
- 不让同名上游 skill 静默覆盖；
- 不覆盖 registry、schema、catalog 和审计输入；
- 缺少入口或 ref 时只输出阻塞报告。

当前能可靠完成的是来源和可用性审计，而不是本地研究工作流运行。
