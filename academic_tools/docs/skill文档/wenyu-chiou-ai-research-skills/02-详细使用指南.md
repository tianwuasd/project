# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 先做本地可用性审计

```text
请检查 skills/WenyuChiou-ai-research-skills/。
确认是否存在 SKILL.md、插件 manifest、schema、上游仓库地址和版本/ref。
只写 local-wenyu/output/registry-audit.md，不安装、不联网、不修改 registry。
如果没有 SKILL.md，请明确标记“当前快照不可直接加载”。
```

## 2. 阅读 registry 资料

```text
local-wenyu/
  question.md
  output/
  constraints.md
```

审计输出应列出插件名称、上游仓库、版本/ref、预计入口、权限、网络和缺失项。不要把 registry 中的描述自动转成研究笔记或论文 claim。

## 3. 上游加载前的检查

只有在人工确认后，才可以按 registry 指向的上游仓库分别读取真实 `SKILL.md`。每个上游项目单独记录来源、commit、许可证、安装目标、脚本和写入范围；不要一次加载所有插件，也不要让同名 skill 静默覆盖。

## 4. 验收上游产物

对每个实际加载的 skill 验证：入口存在、frontmatter 完整、引用文件存在、来源版本固定、输出目录正确、网络和 API 权限最小。若仓库中使用 manifest 或 Evidence Record，保留原始状态和核查日志。

## 5. 停止条件

以下情况直接停止：本地没有入口、上游 ref 不固定、registry 与实树冲突、同名 skill 无法区分、需要未批准 API/CLI/网络或会写全局路径。先输出缺口报告，不用模型补齐源码功能。
