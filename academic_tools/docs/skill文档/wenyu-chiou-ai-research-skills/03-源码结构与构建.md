# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 当前快照结构

```text
WenyuChiou-ai-research-skills/
  catalog/                  # 插件/skill 清单
  docs/                     # 使用和适配说明
  schema/                   # registry 数据结构
  scripts/                  # 安装、校验和 drift 扫描
  tests/
  fixtures/
```

当前目录没有 `SKILL.md`，也没有把 5 个插件和 17 个上游 skill 展开为本地源码。

## 2. 加载关系

registry 记录上游插件的来源和安装信息；实际宿主入口由各上游仓库提供。安装器/脚本负责获取、校验或检测漂移，不能替代上游 skill 的内容。Codex/Gemini 等适配只在对应上游和宿主配置存在时生效。

## 3. 构建方式

本目录没有传统编译步骤。它的“构建”是 registry schema 校验、来源解析、插件安装/同步和 drift 扫描。当前没有本地可执行的统一 `SKILL.md` 构建产物；需要安装时必须固定上游仓库、ref、许可证和目标路径。

## 4. 验证限制

schema/marketplace 校验可证明 registry 格式，但不能证明上游 skill 功能。当前环境缺少 pytest 时，不能宣称测试通过；上游源码、依赖、CLI 和网络行为仍需分别审查。
