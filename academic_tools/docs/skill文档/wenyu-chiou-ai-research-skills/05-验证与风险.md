# 验证与风险

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 本地状态检查

```bash
test -d skills/WenyuChiou-ai-research-skills/catalog
test -d skills/WenyuChiou-ai-research-skills/schema
test -d skills/WenyuChiou-ai-research-skills/scripts
test ! -f skills/WenyuChiou-ai-research-skills/SKILL.md
```

最后一项是当前快照的预期事实：根目录没有统一入口；同时应检查 `skills/` 下没有被误认为本项目源码的 `SKILL.md`。

## Registry 核查

- [ ] 每个插件有明确上游仓库和固定 ref；
- [ ] 上游入口、manifest、schema 和引用路径真实存在；
- [ ] 许可证、网络、API、CLI 和写入权限已记录；
- [ ] 同名 skill 的优先级和加载路径明确；
- [ ] 安装/校验脚本的输出和副作用可追溯；
- [ ] pytest 未运行时没有宣称测试通过；
- [ ] 实际研究输出来自已审查的上游源码，而非 registry 描述。

## 常见失败

| 现象 | 处理 |
|---|---|
| Agent 找不到 skill | 这是当前快照的预期结果，先做 registry 审计。 |
| 上游 ref 使用 main/master | 固定 commit 或明确记录可变引用风险。 |
| 同名 skill 冲突 | 分离安装目录，显式指定入口，不静默覆盖。 |
| schema 通过但功能不可用 | 分别验证上游源码、依赖和宿主加载。 |
| 安装脚本有外部副作用 | 审查网络、凭据、目标路径和写入日志后再批准。 |

## 风险边界

registry 只能描述和分发上游 skill，不能证明其安全、质量或科学正确性。可变上游引用、网络/CLI/API、同名冲突和自动同步可能导致供应链、权限和版本风险；当前本地目录不可直接加载，必须如实保留这一限制。
