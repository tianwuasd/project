# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只读取当前项目的 Nature Skills 源码和本地副本，不执行全局安装、自动更新、MCP 配置、依赖安装、联网下载或远程部署。

## 1. 准备目录

```text
local-nature/
  paper.pdf
  notes/
  results/
  figures/
  reviewer-comments.md
  output/
  constraints.md
```

只放脱敏副本和获准使用的材料；凭据、浏览器登录态和未公开数据不应写入源码目录。

## 2. 显式读取入口

写作：

```text
请读取 skills/nature-skills/skills/nature-writing/SKILL.md。
只读取 local-nature/notes/、results/ 和 constraints.md。
先将结构与证据审查写到 local-nature/output/，不要联网、更新或修改全局配置。
```

检索和图表分别指定 `skills/nature-skills/skills/nature-academic-search/SKILL.md`、`nature-image2ppt/SKILL.md`。先生成计划，再人工确认脚本、MCP、CDP 或外部 API。

## 3. 本地边界

- 只读取指定 `SKILL.md`、references/static 和 `local-nature/`；
- 只写 `local-nature/output/`；
- 不运行自动更新器、安装器、批量下载或 SessionStart hook；
- 不调用 PubMed/Elsevier/OpenAI 等外部服务；
- 不下载模型、字体、浏览器或素材；
- 需要渲染 PPT/PDF 时先单独检查工具和许可。

正式安装、Codex 同步、MCP 和浏览器登录态配置请另行阅读上游 README；本地指南只提供隔离读取和受限草稿流程。
