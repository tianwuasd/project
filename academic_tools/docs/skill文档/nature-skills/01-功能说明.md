# 功能说明

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 定位

Nature Skills 是面向科研写作、论文检索、数据处理、审稿回复和科研图表的多 skill 集合。当前仓库有 20 个 skill 目录，其中 19 个可触发技能，`nature-shared` 作为支持包。

## 主要功能

- Nature 风格英文摘要、正文润色和结构改写；
- 学术检索、文献下载、论文阅读和引用辅助；
- 数据处理、科研图表和 Image2PPT；
- 审稿意见、response letter、投稿准备；
- 可组合的 static/reference 资料和运行型脚本。

代表运行入口包括学术检索 MCP、`nature-downloader` 的批量下载脚本、`nature-image2ppt` 的 CLI；其他目录多为按需加载的指令路由。

## 输入输出

**输入**：论文、研究笔记、真实结果、目标期刊要求、审稿意见、图表和受众约束。

**输出**：润色稿、检索日志、文献包、审稿回复、科研图和 PPTX/PDF。任何语言润色都不能改变结果、证据强度和不确定性。

## 边界与评价

仓库明确不是 Nature 官方工具，也不能保证投稿或内容正确。第二篇知乎文章称其“顶级”，属于作者体验性判断；实际效果取决于具体 skill、MCP、Node/Python、浏览器登录态和外部服务。
