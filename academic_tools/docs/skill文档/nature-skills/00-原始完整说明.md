# Nature Skills 详细使用文档

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 0. 文档范围

本指南对应 [Yuan1z0825/nature-skills](https://github.com/Yuan1z0825/nature-skills)。它是一组围绕学术阅读、发表风格英文、科研绘图、审稿和汇报的 `SKILL.md` 技能，不是 Nature 期刊的官方投稿工具。

- **本地源码**：[`skills/nature-skills`](../../../skills/nature-skills/)
- **README 当前标注**：19 个 skill；`nature-shared` 是共享支持包
- **文章评价**：第二篇知乎文章评为“顶级”，称赞其整段学术表达和科研绘图；这是体验性评价

## 1. 能解决什么问题

主要技能方向包括：

- `nature-reader`：论文图文对应阅读、中英文 Markdown reader 和来源整理；
- `nature-writing`：摘要、引言、讨论和论文段落的学术表达；
- `nature-polishing`：在保持科学含义的前提下改善发表风格英文；
- `nature-reviewer`：从目标期刊/审稿人角度做预投稿评估；
- `nature-response`：逐点回复和 cover letter 草稿；
- `nature-figure`：方法图、科研图和论文示意图规划；
- `nature-paper2ppt`：论文到中文组会/汇报 PPT；
- 文献与引用辅助：整理 DOI、引用和引用者画像，但动态数据必须回到原始来源核验。

仓库的技能索引、依赖和真实目录以本地 `skills/` 下的内容为准；不要只凭名字推断功能。

## 2. 前置条件

- Claude Code、Codex、OpenClaw、OpenCode、Hermes 或其他兼容宿主；
- 论文 PDF/HTML、真实图表、实验结果、参考文献和目标期刊要求；
- 如果生成 PPT，需要可用的图片、字体和 PPTX/PDF 导出环境；
- 如果读取外部论文或动态引用数据，需要网络权限；
- 必须保留原稿、原始数据和图表源文件，以便对照检查。

## 3. 安装

### 3.1 查看可安装技能

```bash
npx skills add Yuan1z0825/nature-skills --list
```

### 3.2 安装全部技能

```bash
npx skills add Yuan1z0825/nature-skills --global --agent codex --skill '*' --yes --copy
```

### 3.3 安装单个技能与共享包

```bash
npx skills add Yuan1z0825/nature-skills --global --agent codex \
  --skill nature-reader --skill nature-shared --yes --copy
```

例如只装科研图：

```bash
npx skills add Yuan1z0825/nature-skills --agent codex --skill nature-figure --yes --copy
```

### 3.4 更新

```bash
npx skills list --global --agent codex --json
npx skills update --global --yes
```

### 3.5 Claude Code 使用

仓库建议保留稳定 clone，并通过 subagent 或 slash wrapper 指向实际 `SKILL.md`。例如：

```bash
mkdir -p ~/ai-skills
git clone https://github.com/Yuan1z0825/nature-skills.git ~/ai-skills/nature-skills
```

随后让宿主读取：

```text
请使用 nature-reader，先读取 ~/ai-skills/nature-skills/skills/nature-reader/SKILL.md，
再把这篇论文做成中英文对照 Markdown reader。
```

如使用 Claude Code wrapper，按仓库 README 让 wrapper 同时读取 `nature-shared`，避免单独复制 skill 后丢失共享参考资料。

## 4. 输入准备

润色前：

```text
manuscript/
  draft.md                 # 原始段落
  claims.md                # 句子级 claim 和证据
  references.bib           # 引用
  figures/                 # 真实图表与图注
  results/                 # 数据和实验日志
  venue-guide.md           # 目标期刊指南
```

提示词中指定：

- 语言、目标期刊/读者和期望文体；
- 不能改变的数字、变量、术语、限定词和因果方向；
- 是否允许访问网络、检索文献或读取 GitHub 源码；
- 是只做建议、生成 diff，还是写新文件；
- 生成图是示意图还是基于真实数据的最终图表。

## 5. 典型使用示例

### 5.1 论文阅读

```text
请使用 nature-reader。
读取 paper.pdf，生成图文对应的中英文 Markdown reader。
每个方法、结果和图表都注明原文页码/图号；论文没有说明的内容标记为未说明。
本轮只生成阅读器，不写综述、不新增引用。
```

**检查点**：确认图号、页码、术语、公式和结果没有被摘要过程改写。

### 5.2 发表风格英文润色

```text
请使用 nature-polishing 处理 manuscript/paragraph.md。
保持所有数字、变量、限定词、因果方向和科学含义不变。
输出：原句、修改句、修改理由、可能改变含义的风险。
不要新增文献、结果或“首次/显著/最佳”等强断言。
```

**预期产物**：逐句/逐段修改、理由和风险清单。

**检查点**：对照原稿和 claim-evidence 表；防止把“可能”“相关”润色成“证明”“导致”。

### 5.3 摘要和引言

```text
请使用 nature-writing。
根据 claims.md、results/ 和 references.bib 起草摘要和引言。
先给出信息结构和段落功能，等待确认后再写正文。
每个主要 claim 标注证据来源，不编造数据、DOI、样本或 novelty。
```

### 5.4 预投稿审稿

```text
请使用 nature-reviewer 审查 manuscript/draft.pdf。
参考 venue-guide.md 和真实结果文件，关注贡献、方法、统计、图表、引用和可重复性。
只根据材料判断；不能从材料判断时明确写出。
输出主要问题、次要问题、必须修改项和需要补证据的 claim。
```

**检查点**：审稿意见必须能定位到稿件、图表或材料；不要把模拟审稿当成真实期刊决定。

### 5.5 审稿回复

```text
请使用 nature-response。
读取 reviewer_comments.md、manuscript_v1.pdf、manuscript_v2.pdf 和 change-log.md。
为每条意见生成 concern、回应、实际修改位置、证据来源和待作者确认项。
不承诺尚未完成的实验，不虚构页码或行号。
```

### 5.6 科研图与 PPT

```text
请使用 nature-figure 根据 methods.md、results/ 和真实 figures/ 规划一张论文示意图。
先输出图中元素、箭头、标签、数据来源和可能误读点，等待确认后生成草稿。
示意内容与真实实验图分开标记，不生成不存在的数值。
```

```text
请使用 nature-paper2ppt 把 paper.pdf 做成中文组会汇报大纲。
每页一个核心结论，保留关键真实图件、图号和来源。
先输出逐页大纲与素材计划，不直接导出最终 PPT。
```

## 6. 结果核查

### 语言

- [ ] 修改没有改变数字、术语、限定词、因果关系或 claim 强度。
- [ ] “首次”“显著”“证明”“最佳”等断言有明确证据。
- [ ] 英文风格符合目标期刊指南，而不是只追求更像 Nature。
- [ ] 原文、修改稿、diff 和作者确认记录均保留。

### 图表与 PPT

- [ ] 图表中的数据、单位、箭头、图例、坐标轴、误差线和图号正确。
- [ ] 示意图与真实实验图清楚区分。
- [ ] 每页 PPT 有一个结论式标题，且来源和限制可见。
- [ ] PDF/PPTX 导出后字体、比例、颜色和公式可读。

### 文献与动态事实

- [ ] DOI、引用数、他引、作者身份和期刊政策回到权威来源核验。
- [ ] reader 的摘要与原文页面/图表一致。
- [ ] 不把 skill 的风格建议当作投稿保证。

## 7. 失败与风险处理

| 现象 | 处理 |
|---|---|
| 润色后语气过强 | 对照原句和证据，恢复限定词并重新检查 claim。 |
| reader 补写论文没有的内容 | 标为未说明，删除推断或要求原文定位。 |
| 生成图结构错误 | 回到 methods/results 和源码，逐元素确认箭头、关系和标签。 |
| PPT 缺少来源 | 回到真实图件和论文图号，补来源，不用生成图替代。 |
| 期刊要求与文体冲突 | 以最新作者指南为准，保留作者的科学含义。 |
| 需要外部检索/上传 | 先确认网络、隐私、版权和费用，必要时只提供本地材料。 |

## 8. 与其他 skill 的衔接

- **Claude Scholar / ARS**：先整理和核验文献、claim 与证据，再用 Nature Skills 做表达。
- **Scientific Agent Skills / AERS / AI Research Skills**：提供真实结果、统计表和图源文件。
- **PaperSpine**：先锁定 contribution、Results 映射和 reviewer audit，再进行英文风格处理。
- **Paper Craft**：负责完整方法图、HTML 解读和 deck 视觉叙事；Nature Skills 负责英文图注和期刊风格。

## 9. 责任边界

Nature Skills 改善的是论文理解、表达和视觉呈现，不证明内容正确、引用真实、实验有效或稿件会被 Nature/其他期刊接受。任何可能改变科学含义的修改都必须由作者逐句确认。
