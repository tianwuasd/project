## 内容核查

- [ ] 每个润色断言、数字、引用和期刊要求可回源；
- [ ] 语言修改没有扩大因果或证据强度；
- [ ] 检索记录包含查询式、来源、时间、标识符和失败项；
- [ ] 下载材料的许可、来源和版本已记录；
- [ ] 图表和 PPTX/PDF 逐页检查字体、布局、图例和信息保真；
- [ ] MCP/API/CDP 的权限和数据范围经过人工批准；
- [ ] 最终稿不把 Nature Skills 或文章评价当作 Nature 官方背书。

## 常见失败

| 现象 | 处理 |
|---|---|
| 宿主找不到入口 | 从 `skills/` 实树重新选择 `SKILL.md`，不要猜路径。 |
| 检索结果不完整 | 区分限流、权限、来源缺失和无结果，保留日志。 |
| PDF/PPT 排版错误 | 在副本重渲染，检查字体、LibreOffice/Playwright 版本。 |
| API 或浏览器登录失效 | 停止调用，确认凭据、域名和登录态后再试。 |
| 自动更新改变源码 | 恢复到已审查快照，审查上游变更再决定。 |

## 风险边界

依赖范围未完全锁定，外部检索、下载、浏览器和自动更新会引入隐私、成本和供应链风险。该仓库不是 Nature 官方工具，也不能验证科研结论、投稿成功或引用真实性；正式发布前需要作者和领域专家复核。
