# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 准备项目

```text
local-nature/
  paper.pdf
  notes/
  results/
  figures/
  reviewer-comments.md
  venue-guidelines.md
  output/
  constraints.md
```

先记录目标期刊、语言、读者、允许联网范围和不可改变的数字/结论。原始数据与正式稿件只提供只读副本。

## 2. 写作与润色

```text
请读取 skills/nature-skills/skills/nature-writing/SKILL.md。
只读取 local-nature/notes/、results/ 和 venue-guidelines.md。
先输出 local-nature/output/claim-style-audit.md，再生成润色建议。
保持数字、引用、因果强度和不确定性不变；只写 output/。
```

对 `nature-polishing`、`nature-response` 等入口也要先显式读取对应 `SKILL.md`，不要把“Nature 风格”当作官方审稿或录用预测。

## 3. 检索与下载

需要检索时先使用 `nature-academic-search` 入口，记录查询式、来源、时间、DOI/accession、下载许可和失败项。批量下载前确认域名、`PUBMED_EMAIL`/Elsevier 等凭据、请求频率和输出目录；摘要不能代替原文。

## 4. 图表与汇报

```text
请读取 skills/nature-skills/skills/nature-image2ppt/SKILL.md。
根据 local-nature/figures/ 和 notes/ 设计汇报结构，只写 output/deck-plan.md。
先不要运行 CLI、调用图像服务或上传文件；每页标出证据和许可来源。
```

确认计划后才渲染 PPTX/PDF，并逐页复核字体、图例、数字、引用和版式。

## 5. 人工检查点

- 文本修改没有扩大结论；
- 引用、DOI 和来源可回溯；
- API/浏览器返回的内容没有被误当成完整论文；
- 图表保留不确定性和负结果；
- 目标期刊政策、AI disclosure 和最终格式由作者确认。
