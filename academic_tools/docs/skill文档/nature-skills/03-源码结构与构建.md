# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 源码布局

```text
nature-skills/
  skills/                         # 20 个技能目录
    nature-writing/
    nature-academic-search/
    nature-downloader/
    nature-image2ppt/
    nature-shared/
    其他技能目录/
  scripts/                        # 同步、更新、清单和校验
  tests/                          # Python 校验与测试
  docs/
  requirements.txt
  README.md
```

每个技能目录通常包含 `SKILL.md`、README、README_EN、`manifest.yaml` 和 `agents/openai.yaml`；运行型技能还可能包含 `static/`、`references/`、`scripts/`、`src/` 或 `tests/`。

## 2. 加载关系

兼容宿主扫描 `skills/<name>/SKILL.md` 并按任务加载；根目录没有统一 `SKILL.md`。仓库支持 npx skills、Codex 同步脚本和可选 Claude wrapper；SessionStart 自动更新属于高副作用配置，不是本地试用要求。

## 3. 构建和验证

技能本身是 Markdown/配置加载，没有统一二进制构建。检索 MCP、下载 Node 脚本和 Image2PPT CLI 是按需运行层。仓库提供清单校验、README/metadata/index/workflow/repo 校验、shell 语法检查和 Python 测试；当前审计中四个主校验、README 镜像校验及 104 项 Python 测试通过。

## 4. 依赖

可能涉及 Node 18/22、Python、uv、MCP、Playwright/Chromium、LibreOffice、API token、浏览器 CDP 登录态和外部学术服务。requirements 多为范围约束而非锁定版本；自动更新还会执行上游脚本，须按供应链风险处理。
