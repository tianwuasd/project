## 产物核查

- [ ] spine 中每个核心 claim 都有证据文件和定位；
- [ ] 贡献没有夸大相对已有工作的差异；
- [ ] 正文数字、引用、图表和实验描述可回源；
- [ ] 方法、结果、局限和未完成项没有被写作流畅度掩盖；
- [ ] 审稿意见与实际修改位置逐条对应；
- [ ] 最终稿和过程产物版本清晰，未覆盖原始材料。

## 常见失败

| 现象 | 处理 |
|---|---|
| 只有漂亮大纲没有证据 | 回退到 spine 阶段，列出缺口，不继续扩写。 |
| claim 强度超过结果 | 降低措辞或补充真实实验，不能由 Agent 推断。 |
| PDF 构建失败 | 检查 Pandoc/LaTeX 版本和日志，不自动改稿件内容。 |
| 阶段状态混乱 | 保存输入清单和版本，逐阶段恢复，不覆盖已有结果。 |
| 自动同步越权 | 停止安装器，审查目标路径和备份，再决定是否执行。 |

## 风险边界

PaperSpine 能组织研究产物，不能验证科学真伪、引用真实性或期刊录用概率。安装脚本、写文件、LaTeX/Pandoc 和外部网络均需最小权限；任何对外稿件都必须由作者逐项复核。
