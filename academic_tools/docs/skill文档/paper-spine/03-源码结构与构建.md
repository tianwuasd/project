# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 源码布局

```text
PaperSpine/
  src/
    skill/
      SKILL.md              # 主入口
      agents/               # 阶段角色
      references/              # 工作流、写作和审计资料
  src/adapters/              # Claude/Codex/Hermes 适配
  src/scripts/               # 校验、同步和辅助脚本
  plugins/                   # 宿主插件适配
  install.ps1
  install.sh
  README.md
```

实际子目录以当前 clone 为准；`src/skill/SKILL.md` 是文档和兼容宿主应优先读取的入口。

## 2. 加载关系

主 `SKILL.md` 规定阶段路由，agents 提供阶段角色提示，references 提供规则和检查材料，scripts 承担可重复的辅助操作。插件或安装脚本把 skill 同步到宿主发现路径；本地源码阅读不需要执行安装器。

## 3. 构建和安装

PaperSpine 没有传统编译产物。源码“构建”主要是 Markdown 资源组织、插件打包和 `sync_local_installs.py` 的本地同步；`install.ps1`/`install.sh` 负责完整安装。目标为 PDF/LaTeX 时可能需要 Pandoc、LaTeX 和 Python 工具，但这些不是每次 Markdown 使用的统一依赖。

## 4. 验证方式

验证以阶段关卡和产物审计为主：确认 spine、证据台账、章节产物、引用和审稿修改链完整；若运行脚本，应保留命令、版本和日志。仓库资料未说明一个可替代全部工作流的统一测试命令，不应虚构 build/test 结论。
