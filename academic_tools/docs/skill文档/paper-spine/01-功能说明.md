# 功能说明

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 定位

PaperSpine 是贡献优先的端到端论文/报告生产 skill。它先固定研究贡献、结果和证据，再推进结构、正文、审计、审稿模拟和投稿产物，避免从空白文档直接生成流畅但没有证据的论文。

## 主要功能

- 研究问题、贡献和论文主线梳理；
- 结果/证据台账与章节结构；
- 摘要、引言、相关工作、方法、实验和结论起草；
- 引用、claim、图表和数字的审计；
- 审稿人视角检查、修改路线和最终输出；
- 阶段产物、状态和可追溯性管理。

## 输入输出

**输入**：研究问题、真实结果、代码/实验日志、文献矩阵、图表、目标 venue 要求和已有草稿。

**输出**：贡献说明、论文骨架、章节草稿、证据/引用清单、审计报告、审稿意见、修改计划和投稿文件。

## 不适用

没有真实结果时不能让它生成实验结论；没有原文时不能让它证明引用；没有明确 venue 时不能假定格式和政策。文章资料对 PaperSpine 未给出明确分档，本文只记录源码和原有介绍中的观察。
