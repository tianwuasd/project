# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只读取当前项目的 PaperSpine 源码，不执行完整安装、插件注册、依赖安装、远程部署或全局同步。

## 1. 本地目录

```text
local-spine/
  question.md
  contribution.md
  papers/
  results/
  figures/
  output/
  manuscript/
```

把脱敏的论文、结果和草稿副本放入 `local-spine/`；原始数据和正式稿件保留在受控位置。

## 2. 读取入口

```text
请读取 skills/PaperSpine/src/skill/SKILL.md。
只读取 local-spine/question.md、contribution.md、papers/ 和 results/。
先生成 local-spine/output/spine.md，不要生成完整论文、执行安装器或修改 skills/。
所有输出只写 local-spine/output/。
```

确认贡献与证据后，再逐节允许写入 `local-spine/manuscript/`。如需脚本，先说明脚本路径、输入、输出和副作用。

## 3. 本地边界

- 不运行 `install.ps1`、`install.sh` 或 `sync_local_installs.py`；
- 不复制到用户级 skills 路径或注册插件；
- 不自动安装 Pandoc、LaTeX、Python 包；
- 不联网检索或上传稿件；
- 不覆盖原始结果、论文和已有版本；
- 每轮保留 prompt、输入清单、输出和人工决定。

需要生成 PDF 时，只在确认工具和文件范围后按上游说明单独检查环境。
