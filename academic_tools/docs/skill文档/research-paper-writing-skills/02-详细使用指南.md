# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 输入准备

```text
local-writing/
  question.md
  manuscript/
  evidence/
  figures/
  references.bib
  venue-guidelines.md
  output/
  constraints.md
```

先整理真实结果、实验设置、引用和目标 venue；没有这些材料时只让 Agent生成结构和缺口，不让它补写事实。

## 2. 先做反向提纲

```text
请读取 skills/Research-Paper-Writing-Skills/research-paper-writing/SKILL.md。
读取 local-writing/question.md、manuscript/ 和 evidence/。
先输出 local-writing/output/reverse-outline.md：每段的目的、claim、证据、缺口和不能声称的内容。
不要新增引用、数字或实验结论。
```

逐段检查“主张—证据—限定语”后再进入正文。

## 3. 章节写作

按照 Abstract、Introduction、Related Work、Method、Experiments、Conclusion 的职责分段。每次只处理一个章节，保留原草稿和改写版本；对 Methods/Experiments 仅使用实际代码、日志和图表中存在的信息。

```text
根据 reverse-outline.md 起草 manuscript/introduction-v2.md。
每段先列 claim 和 evidence/ 的文件定位，再写正文。
保持术语、数字和引用不变；无法证实的句子放入 output/open-items.md。
```

## 4. 自审和图表

要求 Agent 生成反向提纲、术语表、claim-evidence 表和可读性问题清单。图表建议只能描述如何改善表达，不得修改真实数据或隐藏不利结果。

## 5. 审阅后的修改

把 reviewer comments、当前稿件和 change log 一起提供；输出逐条回应和实际修改位置。区分“已完成修改”“需要新实验”和“作者决定不采纳”，不要承诺未执行的实验。

## 6. 人工检查点

- 原文引用和 DOI 由作者回到来源核验；
- 每个数字都能回到结果文件；
- 章节没有把相关性写成因果；
- 术语和符号在全文一致；
- 目标 venue 的格式和 AI disclosure 由作者确认；
- 最终稿保留修改记录并通过人工通读。
