# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 源码布局

```text
Research-Paper-Writing-Skills/
  research-paper-writing/
    SKILL.md                 # 唯一 skill 入口
    agents/openai.yaml       # 宿主显示名、简介和默认提示
    references/              # 章节写作、审查、模板和案例
  README.md
  README_zh.md
```

仓库没有发现脚本、测试套件、包管理文件或锁文件；不能把它描述成需要编译的应用。

## 2. 加载关系

兼容宿主读取整个 `research-paper-writing/` 目录，并发现其中的 `SKILL.md`。`agents/openai.yaml` 只提供宿主元信息，不是独立的研究 agent 实现；references 和 examples 由主 skill 按需引用。

## 3. 构建方式

没有统一 build 命令。源码构建实质是 Markdown skill 的目录复制/宿主发现。README 描述可将目录放到 Codex、Claude Code 或 Gemini 的 skills 路径；本地试用时可直接指定当前项目入口，不必复制到全局目录。

LaTeX/Overleaf 只在用户目标是 LaTeX 稿件时作为外部工具考虑，不是该仓库的固定依赖。

## 4. 质量限制

源码的验证依赖反向提纲、逐条证据核对和 paper-review 清单；未发现自动测试能证明引用或学术结论正确。加载遗漏 `SKILL.md`、引用材料缺失和目标章节超出指南范围时，输出应标记为草稿并人工复核。
