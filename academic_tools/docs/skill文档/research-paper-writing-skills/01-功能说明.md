# 功能说明

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 定位

Research Paper Writing Skills 是面向 ML/CV/NLP 论文的结构化写作辅助。它把章节职责、段落流、术语一致性、claim-evidence、自审和图表表达写成宿主可读取的 Markdown 规则。

## 主要功能

- Abstract、Introduction、Related Work、Method、Experiments、Conclusion 起草和重写；
- 贡献与 claim 的证据对应；
- 段落结构、转承、术语和学术语气检查；
- 图表说明、方法表达和论文自审；
- 提供 examples 和 references 中的模板、流程与案例。

源码 frontmatter 提到的章节不包括独立的 Discussion 指南；现有总说明若将 Discussion 列为能力，应理解为组合写作场景，而不是一个已确认的源码入口。

## 输入与输出

**输入**：研究问题、真实实验、图表、引用、已有草稿、目标会议/期刊要求。

**输出**：章节草稿、改写版本、反向提纲、claim-evidence 清单、写作审查意见和待补材料清单。

## 文章评价与边界

现有文档记录第二篇文章将其评为“NPC”，认为规则和公开写作笔记有帮助但不会自动适配全部情境。该评价是主观体验，不是源码质量证明；skill 也不替代研究设计、实验和引用核查。
