# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只使用当前项目的 Markdown 源码，不执行全局安装、插件注册、依赖安装、联网或远程部署。

## 1. 准备项目

```text
local-writing/
  question.md
  manuscript/
  evidence/
  figures/
  references.bib
  output/
  constraints.md
```

输入应为脱敏副本；原始论文、数据和正式稿件留在受控目录。

## 2. 显式读取入口

```text
请读取 skills/Research-Paper-Writing-Skills/research-paper-writing/SKILL.md。
只读取 local-writing/question.md、manuscript/、evidence/ 和 references.bib。
先输出 local-writing/output/reverse-outline.md。
只写 local-writing/output/，不要安装 skill、修改全局配置或新增引用。
```

确认反向提纲后，逐节允许写入 `local-writing/manuscript/`。如果要处理 Discussion、实验运行或文献数据库，先确认该仓库没有对应独立入口，再选择其他 skill。

## 3. 本地边界

- 不复制到 `~/.claude/skills`、`~/.codex/skills` 或其他全局路径；
- 不运行不存在的构建/测试命令；
- 不自动调用 LaTeX、Overleaf、网络或外部 API；
- 不覆盖原始草稿、结果和引用库；
- 每次保存 prompt、输入文件、输出版本和人工决定。

完整宿主安装方式请阅读上游 README；本地指南只保证隔离的源码读取和受限写作试用。
