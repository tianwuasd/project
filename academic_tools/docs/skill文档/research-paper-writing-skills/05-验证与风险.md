## 写作核查

- [ ] 反向提纲覆盖每个段落的目的和 claim；
- [ ] 每个数字、方法和结论都有证据定位；
- [ ] 引用回到原文核验，未由标题或模型补齐；
- [ ] 术语、符号、数据集和基线名称一致；
- [ ] 相关性、预测性和因果性没有混写；
- [ ] 目标 venue 格式、投稿政策和 AI disclosure 已人工确认；
- [ ] reviewer response 与实际改动位置一致。

## 常见失败

| 现象 | 处理 |
|---|---|
| 文本流畅但没有证据 | 回退到反向提纲，删掉无法定位的断言。 |
| 引用不存在或不匹配 | 暂停写作，回到原文/引用库逐条核验。 |
| 要求 Discussion 但无对应指南 | 以现有章节能力为限，或改用其他专门 skill。 |
| 章节结构不适配 venue | 读取目标 venue 要求，由作者确认后再改。 |
| 只生成建议未运行实验 | 把建议标为待执行，不写成已完成结果。 |

## 风险边界

该 skill 是写作辅助，不证明研究设计、实验、引用或投稿结果正确。其源码没有自动测试和构建系统；缺少输入、加载错误或版本漂移时，所有输出都应保持草稿状态并由作者逐项审查。
