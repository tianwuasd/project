# 功能说明

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 定位

Scientific Agent Skills 是面向科学计算、科研检索和实验分析的 Agent Skills 集合，同时提供插件打包和逐 skill 的依赖隔离。当前仓库实树包含 163 个 skill 目录；README 的不同章节仍有 161/163 的历史计数差异，因此数量应以本地 `skills/` 扫描为准。

## 主要功能族

- 单细胞与空间组学：以 Scanpy 等工具处理细胞矩阵、聚类、注释和可视化；
- 生物信息学与药物发现：BioPython、RDKit、分子性质、序列和结构分析；
- 组学与统计：差异表达、富集、可重复分析和结果解释；
- 科学数据库与文献：`database-lookup`、`paper-lookup` 等检索入口；
- 实验和工作流自动化：Nextflow、实验协议、数据处理和报告；
- 科学写作、临床报告与科研可视化。

每个 skill 通常由一个 `SKILL.md` 定义触发范围、输入约束、工具建议和输出要求，并可附 `references/`、`scripts/` 或 `assets/`。

## 输入与输出

**输入**：研究问题、数据字典、表格/矩阵、样本元数据、论文或数据库查询条件、分析环境和目标图表/报告格式。

**输出**：检索记录、分析脚本、统计表、图形、实验记录、方法说明和科学报告。输出中的数值、样本量和生物学结论必须回到原始数据与领域依据核对。

## 适用边界

适合把成熟科学包的使用步骤、参数检查和报告结构交给 Agent 辅助；不适合在没有数据、数据字典或领域判断时让 Agent 自行补齐实验结论。仓库的安全扫描报告也明确，扫描不是对每个 skill 的安全审计或功能保证。

## 文章评价

现有介绍文档记录第二篇文章将其评价为“夯”。这是文章作者的体验性评价，不是本地独立实测；实际效果取决于具体 skill、科学包版本、数据质量、网络和凭据权限。
