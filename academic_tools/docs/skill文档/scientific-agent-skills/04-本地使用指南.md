# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只读取当前项目的源码快照，不执行全局安装、插件注册、依赖安装、远程部署或批量运行。

## 1. 准备本地工作区

```text
local-scientific/
  question.md
  data/
  references/
  output/
  constraints.md
```

先复制允许分析的数据和文献到 `local-scientific/`，不要把个人隐私、凭据或原始数据直接放进仓库源码目录。

## 2. 读取具体入口

单细胞任务：

```text
请先读取 skills/scientific-agent-skills/skills/scanpy/SKILL.md。
只读取 local-scientific/data/，先做数据审计。
只写 local-scientific/output/，不要安装包、修改全局环境或覆盖原始数据。
```

检索任务：

```text
请先读取 skills/scientific-agent-skills/skills/paper-lookup/SKILL.md。
处理 local-scientific/question.md，输出到 local-scientific/output/search-log.md。
默认不联网；如需网络或 API，先列出域名、凭据、请求范围和预期副作用。
```

数据库任务可将入口替换为 `skills/scientific-agent-skills/skills/database-lookup/SKILL.md`。若目录在当前版本不存在，以 `skills/` 实际清单为准。

## 3. 本地运行边界

- 只读取 `skills/scientific-agent-skills/` 中明确指定的 `SKILL.md`、references 和脚本；
- 只写 `local-scientific/output/`；
- 默认不运行 `uv sync`、`pytest`、科学脚本或外部 API；
- 缺少依赖时只记录检查结果，不自动安装；
- 对 GPU、JDK、MATLAB、网络、API key 和大文件先取得人工确认；
- 通过副本和小样本验证后再扩大分析。

## 4. 环境检查提示

如果确实要验证仓库，可在人工确认后，按上游文档为指定 skill 运行 `skills-ref validate` 或隔离测试。Windows、Python 版本和科学包兼容性可能与上游示例不同；本地试用不应因为验证方便而重构全局环境。
