## 本地路径检查

```bash
test -f skills/scientific-agent-skills/skills/scanpy/SKILL.md
test -f skills/scientific-agent-skills/skills/database-lookup/SKILL.md
test -f skills/scientific-agent-skills/skills/paper-lookup/SKILL.md
```

若某个入口在未来版本移动，应先重新扫描 `skills/`，不要凭文档猜路径。

## 分析结果检查

- [ ] 输入矩阵、元数据、样本量、单位和排除规则相互一致；
- [ ] 记录 Python/科学包版本、参数、随机种子和运行日志；
- [ ] 关键统计量可由原始结果重算；
- [ ] 图表标题、分组、误差线和显著性标记有真实依据；
- [ ] 文献、数据库、accession、DOI 和外部 API 结果可追溯；
- [ ] 失败运行和缺失数据没有被静默删除；
- [ ] 输出通过领域研究者审查后才进入论文或临床/实验决策。

## 常见失败

| 现象 | 处理 |
|---|---|
| 宿主找不到 skill | 直接指定具体 `SKILL.md`，检查目录大小写和元数据。 |
| 科学包导入失败 | 记录 Python/包/CUDA/JDK 等版本，先不要自动升级或混装。 |
| 数据字段缺失 | 停止分析，补齐数据字典或标记不可完成的阶段。 |
| 网络检索为空 | 区分无结果、权限失败、限流和来源不可用，不用模型补造论文。 |
| 运行时间或内存过大 | 用副本和小样本复现，确认资源预算后再扩大。 |
| 安全扫描有发现 | 逐项阅读脚本、网络和写入行为；扫描报告不是安全审计结论。 |

## 风险边界

仓库包含大量可执行提示、脚本和可选外部工具，权限面随具体 skill 变化。不要把整个集合一次性授予写入、网络、凭据或执行权限；尤其谨慎处理下载数据、shell 命令、远程数据库、临床材料和 GPU 训练。
