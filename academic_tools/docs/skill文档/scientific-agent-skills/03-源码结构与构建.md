# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 仓库布局

当前源码根目录 `skills/scientific-agent-skills/` 主要包括：

```text
scientific-agent-skills/
  skills/                 # 163 个具体 skill 目录，每个通常有 SKILL.md
  docs/                   # skill 清单、示例和安全报告
  tests/                  # 元数据、隔离运行和仓库测试
  .github/                # CI 配置
  plugin.json             # 插件描述
  pyproject.toml          # 仓库工具依赖
  scan_skills.py          # skill 扫描
  scan_pr_skills.py       # 变更扫描
```

具体 skill 可能额外包含 `references/`、`scripts/` 和 `assets/`；这些目录不是每个 skill 都具备。

## 2. 加载关系

1. 兼容宿主扫描 `skills/*/SKILL.md`；
2. 根据任务描述选择一个或多个具体 skill；
3. `SKILL.md` 引导 Agent 使用科学包、脚本和 references；
4. 输出写入宿主指定的项目目录，而非自动回写仓库；
5. `plugin.json` 支持把集合作为插件分发，但插件安装不是本地试用的必要条件。

仓库根目录没有统一入口 `SKILL.md`，因此必须指定具体路径。

## 3. 依赖与构建

这里没有把所有科学包打成一个统一二进制。仓库工具层使用 `pyproject.toml` 管理扫描、测试和环境辅助依赖；具体科学依赖按 skill/测试隔离，可能涉及 Python 科学栈、CUDA、JDK、MATLAB、网络服务或 API key。

上游提供的验证方式包括：

```bash
uv sync
uv run skills-ref validate skills/<skill-name>
pytest tests/_meta
python tests/run_all.py --isolated
```

这些命令用于源码仓库验证，不能视为已为所有 163 个 skill 安装依赖。执行前应确认 Python/uv 版本、网络、磁盘和目标 skill 的许可要求。

## 4. 事实与版本风险

本地审计显示 README 存在 161/163 的计数漂移，且当前快照没有 `uv.lock`；安全报告记录 988 项扫描发现（含 critical/high 分类），但仓库的安全说明明确扫描不等于人工审计。文档、清单和实树不一致时，以当前文件和实际扫描结果为准。
