# 验证与风险

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 验证清单

- [ ] 入口 `SKILL.md`、references 和 agents 文件真实存在。
- [ ] 研究问题、引用、数据、实验和图表均有来源或明确未验证状态。
- [ ] claim 的存在性、来源支持性和研究者解释没有混为一谈。
- [ ] 运行产物、版本、参数、日志和人工决定已保存。
- [ ] 任何外部联网、API、MCP、脚本和文件写入均在批准范围内。
- [ ] 最终论文由作者逐段审阅，不把审查报告当作投稿保证。

## 常见失败

| 现象 | 处理 |
|---|---|
| Skill 未触发 | 在提示词中写明本地 `SKILL.md` 路径和目标模式。 |
| 引用找不到 | 保持 unverified，检查标识符和原文，不用相似论文替代。 |
| 生成不存在的数据 | 停止写作，回到结果文件和日志，删除无来源内容。 |
| Windows hook 报错 | 先不启用可选 hook，阅读 `docs/SETUP.md` 后再决定是否配置 Git Bash/Python。 |
| pipeline 越过 checkpoint | 回到最近阶段产物，核对人工确认记录，不手写缺失文件。 |
| 外部调用不明确 | 停止并列出 provider、数据范围、费用和权限，等待用户确认。 |

## 风险边界

ARS 的检查覆盖报告中的引用、claim-source 关系、方法描述、实验声明和图表/文档一致性；它不能证明原始数据真实、实验实际执行或结果必然可复现。AI 生成内容、跨模型审查和联网检索都必须经过研究者复核。
