# 功能说明

## 定位

Academic Research Skills（ARS）是面向 Claude Code 的学术研究工作流套件，强调“AI 是副驾驶，不是主驾驶”。它把检索、写作、同行评审、完整性检查和实验衔接拆成多个可复用阶段。

## 主要功能

### Deep Research

- 研究问题澄清和 Socratic 对话；
- 普通文献综述、系统综述和 PRISMA 风格筛选；
- 元分析、事实核查、三路扫描和研究质量审查；
- 通过数据库/来源核对候选文献，并保存证据状态。

### Academic Paper

- 论文蓝图、章节职责和 claim-evidence 规划；
- 摘要、引言、相关工作、方法、实验、讨论和结论起草；
- 引用格式转换、AI 使用披露、修订路线和 rebuttal 审计；
- 风格校准、写作质量检查、LaTeX 加固和图表/引用一致性检查。

### Academic Paper Reviewer

- Journal-Fit Reviewer、多个动态 reviewer 和 Devil's Advocate 视角；
- 方法、贡献、统计、引用完整性和可复现性审查；
- 结构化报告、编辑决定信、修改优先级和复审；
- 只读约束，不能把审稿建议直接当成事实。

### Academic Pipeline

- 以 Material Passport 携带研究问题、素材、claim、实验 provenance 和输出；
- 多阶段执行，支持中间 checkpoint、完整性门禁和最终过程摘要；
- 可从新研究、已有论文或审稿意见等不同入口继续。

### 实验衔接

ARS 记录实验 provenance 和“结果是否与实验声明一致”，但不替用户执行实验，也不证明实验实际发生。需要运行 Python/R 或人类研究协议时，应使用独立实验工具后再把真实产物交回 ARS。

## 输入与输出

**输入**：研究问题、PDF/网页、BibTeX、代码/实验日志、图表、审稿意见、目标期刊要求和用户确认的约束。

**输出**：检索协议、阅读笔记、引用/证据表、论文蓝图、章节草稿、reviewer reports、rebuttal、Material Passport、完整性报告和过程记录。

## 不适用场景

- 只需要普通语法纠错；
- 期待 Agent 自己决定研究问题、方法和最终论断；
- 没有原始数据/论文却要求补全具体数字和引用；
- 把完整性检查误当作原始数据真实性或实验复现证明。

## 文章评价
