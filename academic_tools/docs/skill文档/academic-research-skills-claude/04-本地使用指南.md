# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只使用当前项目中的源码快照，不做全局安装、插件注册、依赖安装或远程部署。

## 1. 本地路径

- 仓库根目录：`skills/academic-research-skills/`
- 主工作流目录：`skills/academic-research-skills/deep-research/`、`academic-paper/`、`academic-paper-reviewer/`、`academic-pipeline/`
- 入口文件：各工作流目录下的 `SKILL.md`

## 2. 让 Agent 读取本地 skill

在当前项目的新会话中明确指向本地文件：

```text
请使用本项目本地的 Academic Research Skills Claude 版。
先读取 skills/academic-research-skills/deep-research/SKILL.md，
再按其中的 Socratic 模式处理 question.md。
只读取 materials/ 和 results/，只写 docs/local-ars-run/；本轮完成后停止。
```

论文写作：

```text
先读取 skills/academic-research-skills/academic-paper/SKILL.md 及其需要的 references。
根据 materials/ 和 results/ 生成论文蓝图，不做全局安装，不修改原始文件。
```

## 3. 本地输入/输出

```text
local-ars-run/
  question.md
  materials/
  results/
  output/
```

要求 Agent 把报告、引用表、蓝图和审查结果写到 `local-ars-run/output/`，不要覆盖仓库源码或原始数据。

## 4. 本地引用核验

```text
请读取 skills/academic-research-skills/academic-paper/SKILL.md。
只检查 local-ars-run/manuscript.md 中已有引用。
输出到 local-ars-run/output/citation-check.md；不能验证的引用标记 unverified。
不要联网，除非我下一步明确批准。
```

## 5. 本地运行前检查

- 确认 `SKILL.md` 路径存在且属于 Claude 版仓库；
- 先让 Agent 输出将读取和写入的文件清单；
- 默认不允许安装包、调用 API、运行 hooks 或修改 `.claude/`；
- 需要脚本时先人工阅读脚本，再单独批准执行；
- 运行结束后检查 diff、日志和未验证项。

## 6. 与全局安装的区别

本地使用不会执行 `/plugin marketplace add`、复制到 `~/.claude/skills`、修改全局 `settings.json` 或启用仓库 hooks。它适合阅读源码、试用一个 workflow 和生成项目内报告；需要完整自动发现、slash command 或跨项目使用时，另行阅读上游 `docs/SETUP.md`。
