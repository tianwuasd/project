## 定位

ARIS（Auto-Research-In-Sleep）是一个可持久推进研究任务的 skill 集合，强调阶段边界、证据/诚信 gate、运行记录、resume 和跨模型审查。它是研究自动化框架，不是无人监督的科学家。

## 主要功能

- idea discovery、研究问题和项目计划；
- experiment bridge、GPU/代码实验和结果收集；
- auto-review-loop、论文审查和可选 paper-writing；
- Research Wiki、HTML 报告、状态恢复和通知；
- Claude、Codex、Gemini 或人工参与的交叉审查。

仓库当前有 82 个 Markdown skill；`skills/skills-codex/` 保存 Codex 镜像。端到端主线是 `research-pipeline`，其他技能按需组合。

## 输入与输出

**输入**：研究目标、材料、实验代码/结果、venue、预算、允许工具和停止条件。

**输出**：计划、运行记录、实验结果、审查报告、研究 wiki、论文草稿和过程状态。

## 边界与评价

ARIS 可以自动读取/写入文件、调用工具、使用 GPU 或跨模型，因此必须明确 run 边界。第二篇文章称其“人上人”，属于作者体验性评价；源码和运行结果不能证明无人值守输出正确。
