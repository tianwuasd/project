# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 仓库布局

```text
Auto-claude-code-research-in-sleep/
  skills/                  # 82 个可组合 Markdown skill
  skills/skills-codex/     # Codex 镜像
  tools/                   # 安装器、状态、watchdog、验证和 wiki 工具
  mcp-servers/             # 可选 MCP 服务
  templates/
  tests/                   # 56 个 Python 测试文件
  docs/
  README.md
```

仓库没有根级 `SKILL.md`，也没有 Cargo/package/pyproject 形式的统一应用构建；ARIS-Code CLI 在文档中指向另一个分支/发行版，不在当前副本中构建。

## 2. 加载关系

宿主原生发现 `skills/<name>/SKILL.md`；`research-pipeline/SKILL.md` 串联 idea、实验、审查和写作。`skills/skills-codex/` 提供 Codex 镜像。`tools/install_aris.sh`/`.ps1` 可将技能链接或复制到项目 `.claude/skills/` 并写安装状态；这是完整安装行为。

## 3. 验证和运行层

`tools/check_skills_inventory.py` 检查清单，仓库还有 56 个测试文件及多种 `verify_*` 工具。pytest 在当前环境缺失时不能宣称测试通过；CI 的平台覆盖也不等于 Windows 本地验证。MCP 服务和工具脚本是可选运行层，不是 Markdown 构建器。

## 4. 依赖和版本风险

可能依赖 Claude Code/Codex/Git/npm、Python、LaTeX/latexmk、pdfinfo、SSH/GPU/screen/tmux、httpx、lark-oapi、Gemini/Exa/DeepXiv 等。README 的 venue 默认值与最新 pipeline 的 VENUE unset 规则存在漂移，应以实际入口和当前任务配置为准。
