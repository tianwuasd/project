# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只读取当前项目的 ARIS 源码快照，不执行安装器、MCP 配置、GPU/SSH 运行、跨模型调用、联网或远程部署。

## 1. 准备隔离目录

```text
local-aris/
  question.md
  materials/
  experiments/
  output/
  state/
  constraints.md
```

把脱敏材料和实验副本放在 `local-aris/`，限制输出目录、迭代次数、运行时间和资源费用。

## 2. 显式读取入口

```text
请读取 skills/Auto-claude-code-research-in-sleep/skills/research-pipeline/SKILL.md。
只读取 local-aris/question.md、materials/ 和 constraints.md。
先写 local-aris/output/plan.md 和 state/run-boundary.md。
本轮不要运行实验、联网、调用 MCP/跨模型或修改 skills/。
```

人工批准后，再按阶段放行实验或审查；每次只写 `local-aris/output/` 和明确的 `state/` 副本。

## 3. 本地边界

- 不运行 `tools/install_aris.sh`、`install_aris.ps1`、smart update 或 watchdog；
- 不写 `.claude/skills/`、用户配置、正式代码仓库或外部 wiki；
- 不初始化 GPU/SSH/screen/tmux 任务；
- 不提供 API key、浏览器登录态或 webhook；
- 不自动设置 `AUTO_PROCEED=true`；
- 保留 prompt、输入、状态、日志和失败运行。

完整安装和无人值守流程请另行阅读上游文档；本地指南只用于读取真实 `SKILL.md` 和生成受限计划。
