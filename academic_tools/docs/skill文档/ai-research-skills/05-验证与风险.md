## 实验核查

- [ ] 任务、数据、基线和停止条件明确；
- [ ] 数据切分和预处理没有泄漏；
- [ ] 训练/推理实际执行，并保存命令、配置、环境、随机种子和日志；
- [ ] 指标由原始评测文件重算，报告没有只挑最好的一次运行；
- [ ] 失败运行、异常和未完成项被保留；
- [ ] 模型、数据、代码和第三方服务许可证已确认；
- [ ] 任何研究结论经过人工和领域复核。

## 常见失败

| 现象 | 处理 |
|---|---|
| CLI 或 skill 未被发现 | 直接指定本地 `SKILL.md`，检查编号目录和元数据。 |
| 依赖/GPU 不匹配 | 记录 Node/Python/PyTorch/CUDA 版本，先停止，不自动升级环境。 |
| 训练指标异常好 | 检查泄漏、数据切分、基线和日志，不能直接归因于模型改进。 |
| 自动循环持续写入 | 立即停止，审查命令和文件变更，收紧输出目录与实验次数。 |
| 参考链接失效 | 回到仓库实树核对，不能由模型补造 references。 |
| 测试显示 0 项 | 将其视为空测试集，不把“无失败”解释为功能验证。 |

## 风险边界

自主研究技能可能读写代码、启动训练、下载模型、调用外部服务并消耗 GPU/云资源。默认使用最小权限、隔离目录和人工批准门；不授予全局凭据、生产目录或无限循环权限。
