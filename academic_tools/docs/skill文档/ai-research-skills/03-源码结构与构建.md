# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 顶层结构

```text
AI-Research-SKILLs/
  0-autoresearch-skill/       # 持续研究入口示例
  <编号分类>/                  # 其余技能目录，共 98 个 SKILL.md
  packages/
    ai-research-skills/
      bin/cli.js
      src/index.js
      src/installer.js
  scripts/                    # 清单和辅助检查
  docs/
  README.md
  WELCOME.md
  CLAUDE.md
  package.json
```

实际分类名称和数量随版本变化；某些 skill 有 references 或脚本，不能从目录编号推断全部能力。

## 2. 加载关系

- 兼容宿主可扫描各编号目录下的 `SKILL.md`；
- `packages/ai-research-skills/bin/cli.js` 提供安装器 CLI；
- `src/index.js`、`src/installer.js` 负责包内 CLI/安装逻辑；
- `scripts/check-inventory.sh` 检查 skill 数量、分类和元数据；
- `0-autoresearch-skill` 不是整个仓库的唯一 router，而是一个具体入口。

## 3. 构建与安装方式

技能本身是 Markdown 加载，不需要把 `SKILL.md` 编译为二进制。CLI 包使用 Node.js，README 要求 Node.js 18 或更高，依赖包含 chalk、inquirer 和 ora。CLI 默认安装到用户级目录并建立链接，Windows 可能回退为复制；这属于完整安装行为，本地试用不需要执行。

可验证的仓库检查包括：

```bash
bash scripts/check-inventory.sh
node packages/ai-research-skills/bin/cli.js --help
```

`npm test` 当前包测试可能是空测试集，不能据此证明技能逻辑或训练结果正确；顶层包与 `packages/` 子包的脚本也可能不同，运行前先阅读对应 `package.json`。

## 4. 一致性与运行风险

本地审计发现 README/WELCOME/包 README 有计数和分类漂移，且部分 references 链接缺失。训练类技能还依赖 Python、PyTorch、CUDA/GPU、模型下载和外部服务账号；这些依赖由具体 skill 决定，不应在文档中假设统一环境。
