# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本文件只使用当前项目的源码快照，不执行全局安装、npm 安装、插件注册、模型下载、远程部署或自动研究循环。

## 1. 准备输入和输出

```text
local-ai/
  question.md
  data/
  baselines/
  output/
  constraints.md
```

只把获准使用的副本放入 `local-ai/`，把输出、日志和配置版本化保存于 `local-ai/output/`；不要让 Agent 直接写 `skills/AI-Research-SKILLs/`。

## 2. 读取本地入口

```text
请先读取 skills/AI-Research-SKILLs/0-autoresearch-skill/SKILL.md。
根据 local-ai/question.md 设计一个有限实验计划。
只读取 local-ai/data/ 和 local-ai/baselines/，只写 local-ai/output/plan.md。
不要安装 npm/Python 依赖、下载模型、联网、提交或推送。
```

如果任务对应其他编号 skill，先从 `skills/AI-Research-SKILLs/` 找到实际目录，再将其 `SKILL.md` 路径写入提示词，不要猜目录名称。

## 3. 分阶段试用

先只生成计划和实验矩阵；人工确认后，再允许执行单个小实验。每次运行保存：实际命令、配置、代码版本、数据摘要、随机种子、硬件、日志、指标和失败原因。需要 GPU、模型下载、API 或写入代码仓库时，先单独确认权限和预算。

## 4. 本地边界

- 只读取 `skills/AI-Research-SKILLs/` 中明确指定的源码和 `local-ai/` 输入；
- 只写 `local-ai/output/`；
- 不运行 CLI 安装器，不修改 `~/.orchestra/skills` 或其他全局路径；
- 不自动执行 autoresearch 持续循环；
- 不提交、推送、发布模型或发送外部 webhook；
- 缺少依赖时只记录检查结果，不自动安装。

完整 CLI 安装和模型/训练环境配置请另行阅读上游文档；本指南的目标是隔离的源码阅读和受限本地试用。
