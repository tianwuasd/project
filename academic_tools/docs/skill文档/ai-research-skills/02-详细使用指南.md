# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 先选择技能和停止条件

先读取目标 `SKILL.md`，把任务限制为一个实验或一个工程阶段。不要直接要求“自动完成整个研究”。至少明确：数据范围、允许修改的文件、预算、最大运行时间、评测指标、失败处理和停止条件。

```text
研究目标：比较两个模型在 local-ai/data/ 上的分类性能。
允许读取：local-ai/data/、local-ai/baselines/。
只写：local-ai/output/；不得修改原始数据和仓库配置。
预算：单次运行不超过 30 分钟，最多 3 个配置。
请先读取 skills/AI-Research-SKILLs/0-autoresearch-skill/SKILL.md，
先输出实验计划和评测表，不要启动训练。
```

## 2. 输入准备

```text
local-ai/
  question.md
  data/                 # 数据副本和数据字典
  baselines/            # 已确认基线
  configs/              # 允许读取的配置
  output/
    plans/
    runs/
    reports/
  constraints.md
```

`constraints.md` 记录 Python/PyTorch/CUDA、GPU 数量、网络和模型下载权限，以及隐私、许可证和成本限制。

## 3. 研究工程流程

1. 读取与任务最接近的 `SKILL.md`；
2. 审计数据、标签、切分和泄漏风险；
3. 固定基线和评测指标；
4. 先生成配置与实验矩阵，等待人工确认；
5. 在副本上运行单个小实验；
6. 保存环境、命令、随机种子、日志和失败信息；
7. 扩大到有限实验矩阵；
8. 生成报告并对指标做独立复核。

## 4. 持续研究入口的谨慎用法

`0-autoresearch-skill/SKILL.md` 面向持续/自主研究循环。使用时应显式限制循环次数、文件范围和资源预算：

```text
只读取 skills/AI-Research-SKILLs/0-autoresearch-skill/SKILL.md。
本轮最多提出 3 个实验，不自动提交、推送、发布或修改全局配置。
每个实验先写 local-ai/output/plans/，经我确认后才运行。
所有结果写 local-ai/output/runs/，保留失败日志和实际命令。
```

## 5. 结果与论文衔接

报告应区分预注册假设、探索性发现、实际测得指标和模型生成的解释。不要把训练日志中的单次最好值写成稳健结论；至少比较基线、重复运行、置信区间或适合任务的误差指标，并记录未完成实验。

## 6. 人工检查点

- 数据切分没有训练/测试泄漏；
- 模型、数据和代码许可证允许当前用途；
- 下载模型、外部 API 和 GPU 费用已批准；
- 训练确实执行而不是只生成脚本；
- 报告数字可从日志和评测文件重算；
- 自动循环没有修改范围外文件或执行未批准命令。
