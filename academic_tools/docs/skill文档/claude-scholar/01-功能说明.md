# 功能说明

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 定位

Claude Scholar 是面向计算机科学、AI 和软件型研究的半自动研究助理。它连接研究构思、文献、实验、分析、报告、论文和项目知识库，强调人类保留关键判断。

## 主要功能

### 研究与文献

- `research-ideation`：从主题形成研究问题、方向和初步计划；
- Zotero 导入、集合管理、去重、全文读取和引用导出；
- 论文分组、结构化阅读笔记、核心贡献和方法差异；
- `obsidian-literature-workflow`：以 `Sources/Papers/`、`Knowledge/`、`Writing/` 和 `Maps/literature.canvas` 组织项目级文献综述；

### 项目知识与实验

- Obsidian vault-first 知识管理；
- `Sources/Papers`、`Knowledge`、`Experiments`、`Results`、`Writing` 等分区；
- 实验线、run history、findings、next actions 和报告；
- `results-analysis` 生成统计/图表分析，`results-report` 生成决策导向报告。

### 写作与发布

- ML paper writing、related work、摘要、论文结构和审稿回复；
- publication-grade figure/table、LaTeX 模板、PPT/poster；
- writing-anti-ai、paper self-review、review-response 和 post-acceptance。

### 软件研究辅助

- architecture-design、daily-coding、bug-detective 和 git workflow；
- hooks、rules、agents、commands 和项目配置。

## 输入输出

**输入**：研究主题、PDF、DOI/arXiv、Zotero 集合、代码、实验结果、审稿意见、Obsidian vault 和目标 venue 要求。

**输出**：论文笔记、文献综合、gap 分析、实验报告、分析图表、论文段落、reviewer response 和项目知识条目。

## 不适用

- 将半自动流程当成全自动科学家；
- 没有原文/数据却要求生成准确摘要、数字或引用；
- 在未审查权限时批量修改 Obsidian/Zotero 或全局配置；
- 把知识库条目或 Agent 报告当作已验证的科学结论。

## 文章评价

第二篇知乎文章评为“顶级”，主要称赞批量文献导入、结构化笔记、方法差异和引用关系整理。该评价是体验性参考，实际效果取决于 Zotero/MCP、PDF 可读性和人工抽查。
