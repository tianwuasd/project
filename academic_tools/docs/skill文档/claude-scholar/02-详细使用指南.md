# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 输入准备

```text
project/
  Sources/Papers/       # 原始论文和笔记
  Knowledge/            # 已确认知识
  Experiments/          # 配置、run、日志
  Results/              # 原始结果和报告
  Writing/              # 稿件和回复
  question.md
  constraints.md
```

开始任务时写清目标、停止点、允许读写目录、Zotero/Obsidian 是否可用以及是否允许联网/MCP。

## 2. 新建研究主题

```text
请使用 Claude Scholar 的研究流程。
主题：brain foundation models。
输出：研究问题候选、文献方向、主要开放问题和下一步计划。
只读取当前项目文件，先不要访问外部来源，也不要写论文。
```

**检查**：研究者确认问题和范围后，再进入文献搜索或项目计划。

## 3. Zotero 文献集合

```text
请复查我的 Zotero 集合“brain foundation models”。
输出主题分组、每篇论文的核心贡献、数据/方法差异、研究缺口和原文定位。
检查 DOI、重复条目、预印本/正式版本；无法确认的内容标为待核验。
```

**检查**：核对导入、去重、PDF 附件和集合归属，不让 Agent 用标题相似度补齐缺失论文。

## 4. 结构化阅读笔记

```text
请把 Sources/Papers/ 中的 10 篇论文做成结构化笔记。
每篇包含研究问题、数据/样本、方法、结果、局限、方法差异、可支持 claim、原文定位和未解决问题。
原始笔记保留在 Sources/Papers/，不要覆盖已有文件。
```

人工确认后再把稳定内容提升到 `Knowledge/`。

## 5. 分析实验结果

```text
请分析 Experiments/exp-03/ 和 Results/ 中的真实结果。
比较每个 run 的配置、指标、异常和失败，输出结果报告与下一步建议。
只使用文件中存在的数字；缺日志、基线或数据字典时明确说明。
```

**检查**：核对样本、脚本、环境、随机种子、基线和数据切分。

## 6. 写作与审稿回复

```text
请根据 Sources/Papers/、Knowledge/ 和 Results/ 起草 related work。
每个段落先列 claim、证据来源和待补材料，再写正文；不要新增引用或扩大结论。
```

```text
请根据 reviewer_comments.md、manuscript_v2.pdf 和 change-log.md 生成逐点回复。
每条包含意见、回应、实际修改位置、证据来源和待确认行动，不承诺未完成实验。
```

## 7. 本轮输出

建议每次只完成一个目标：3 篇笔记、一个集合去重、一个实验报告或一个论文小节。保存 prompt、输入文件、输出、人工决定和未验证项，避免“帮我处理全部研究”导致范围失控。
