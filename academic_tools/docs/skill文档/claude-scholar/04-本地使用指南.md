# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本文件只使用当前项目的源码快照，不执行全局安装、插件注册、依赖安装、Zotero/Obsidian 配置或远程部署。

## 1. 本地入口

- 仓库：`skills/claude-scholar/`
- 研究 skill：`skills/claude-scholar/skills/`
- 说明文档：`skills/claude-scholar/README.md`
- 配置参考：`skills/claude-scholar/settings.json.template`

## 2. 让 Agent 读取本地 skill

```text
请使用当前项目本地的 Claude Scholar。
先读取 skills/claude-scholar/skills/research-ideation/SKILL.md，
再处理 local-scholar/question.md。
只读取 local-scholar/materials/，只写 local-scholar/output/；
不要安装插件、修改全局配置或调用 Zotero/MCP。
```

文献笔记：

```text
先读取 skills/claude-scholar/skills/obsidian-literature-workflow/SKILL.md，
只分析 local-scholar/papers/ 中的 3 篇 PDF，输出到 local-scholar/output/notes/。
每条结论保留原文定位；无法确认的内容标记待核验。
```

## 3. 本地项目布局

```text
local-scholar/
  question.md
  papers/
  experiments/
  output/
    notes/
    reports/
  constraints.md
```

如果你已有 Obsidian vault 或 Zotero，不要在本地试用时让 Agent直接写入；先导出/复制只读材料到 `local-scholar/`。

## 4. 本地分析

```text
请先读取 skills/claude-scholar/skills/results-analysis/SKILL.md。
读取 local-scholar/experiments/exp-01/，只写 local-scholar/output/reports/exp-01.md。
不要调用 Python、MCP 或外部 API；缺少日志和数据字典时停止并列出缺失项。
```

## 5. 本地写作

```text
请读取 skills/claude-scholar/skills/ml-paper-writing/SKILL.md。
根据 local-scholar/output/notes/ 和 reports/ 起草一个 related work 草稿。
只写 local-scholar/output/draft.md，保留证据状态，不新增引用。
```

## 6. 本地边界

- 只读取当前项目的 `skills/claude-scholar/` 和明确输入目录；
- 只写 `local-scholar/output/`；
- 默认不运行 hooks、scripts、MCP、Zotero、Obsidian 和网络请求；
- 需要外部集成时先输出权限、数据范围、写入位置和副作用；
- 保留输入、输出、prompt、日志和人工确认，不覆盖原始论文/结果。

完整安装、插件市场、Zotero MCP 和 Obsidian 配置请另行阅读上游 `docs/`；本指南不执行那些操作。
