# 详细使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 准备内容包

```text
local-craft/
  paper.pdf
  verified-notes.md
  figures/
  method-outline.md
  audience.md
  output/
  constraints.md
```

`verified-notes.md` 记录原文页码、图表编号、方法步骤、数字和不确定项。先确定产物类型：方法图、论文分析 HTML 或演示 deck。

## 2. 方法图/漫画

```text
请读取 skills/paper-craft-skills/skills/paper-comic/SKILL.md。
只读取 local-craft/paper.pdf、verified-notes.md 和 method-outline.md。
先输出 local-craft/output/visual-plan.md，列出每个画面对应的原文证据。
不要生成虚构实验、人物、数字或未经许可的外部素材。
```

确认视觉草图后再生成图像；对生成图片逐项检查标签、箭头、单位、顺序和方法含义。

## 3. 论文分析 HTML

```text
请读取 skills/paper-craft-skills/skills/paper-analyzer/SKILL.md。
根据 local-craft/paper.pdf 和 verified-notes.md 生成阅读分析计划。
只写 local-craft/output/，保留页码定位、术语表、主张和待核验项。
```

HTML 适合组织阅读和链接，但不是论文原文的替代品。

## 4. 汇报 deck

```text
请读取 skills/paper-craft-skills/skills/paper-deck/SKILL.md。
根据 verified-notes.md 和 audience.md 设计 8 页汇报结构。
只输出 local-craft/output/deck-plan.md；先不要生成 PPTX/PDF。
每页列出原文证据和需要人工确认的图表。
```

确认结构后再生成 deck；逐页检查字体、溢出、图表分辨率、引用和讲述逻辑。

## 5. 人工检查点

- 图解步骤与论文方法一致；
- 颜色、箭头和图例不改变统计或因果含义；
- 每个数字、图表和结论能回到页码/文件；
- 生成图、字体、图标和 PDF 素材许可证明确；
- 最终 PPTX/PDF 在目标设备和投影比例下复核。
