# 本地使用指南

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

本指南只使用当前项目的 Paper Craft 源码和本地副本，不执行完整安装、依赖安装、联网生图、外部 CDN、远程部署或全局配置修改。

## 1. 准备目录

```text
local-craft/
  paper.pdf
  verified-notes.md
  figures/
  method-outline.md
  audience.md
  output/
  constraints.md
```

只使用获准的脱敏论文和素材；正式论文、未公开数据和凭据不应复制到 skill 目录。

## 2. 显式读取入口

方法图：

```text
请读取 skills/paper-craft-skills/skills/paper-comic/SKILL.md。
只读取 local-craft/paper.pdf、verified-notes.md 和 method-outline.md。
只写 local-craft/output/visual-plan.md；不要联网、生图、安装依赖或修改原始文件。
```

论文分析和 deck 分别将入口替换为 `skills/paper-craft-skills/skills/paper-analyzer/SKILL.md` 与 `skills/paper-craft-skills/skills/paper-deck/SKILL.md`。先生成计划，再人工批准渲染或脚本执行。

## 3. 本地边界

- 只读取指定的本地 `SKILL.md`、references 和输入副本；
- 只写 `local-craft/output/`；
- 默认不运行 `skills/paper-craft-skills/skills/paper-deck/scripts/merge_deck.py`、图像后端或 PDF 转换；
- 不下载字体、图标、图片或模型；
- 不上传论文、调用外部 API 或写入正式项目；
- 保留原始素材、生成版本、prompt、日志和许可证记录。

需要真实渲染时，先检查 Pillow/python-pptx/PDF 工具和输出权限，再按单个产物批准执行。
