## 内容与视觉核查

- [ ] 每个图形元素都能回到论文页码、图表或 verified notes；
- [ ] 方法顺序、方向、变量、单位和因果关系没有被视觉化改写；
- [ ] HTML/PPTX/PDF 没有溢出、裁切、字体替换或低分辨率；
- [ ] 图表、引用、图例和页码完整；
- [ ] 生成素材的来源、许可和费用有记录；
- [ ] 视觉稿与原文、数据和最终论文由作者逐项比对。

## 常见失败

| 现象 | 处理 |
|---|---|
| 论文内容被过度简化 | 回到 verified notes，增加限定语和证据定位。 |
| 图中标签或箭头错误 | 停止发布，逐元素对照原文重做。 |
| 生成图后端不可用 | 保留 visual plan，改用本地已有素材，不自动绕过限制。 |
| PPTX/PDF 排版错位 | 检查字体、比例和脚本日志，先在副本重渲染。 |
| 外部素材许可不明 | 不发布、不嵌入，替换为已获许可素材。 |

## 风险边界

视觉表达可能制造比原文更强的确定感，且生图、CDN、字体、PDF 和 PPTX 工具具有许可、隐私和供应链风险。Paper Craft 不能证明论文结论或实验正确；正式发布前必须保留人工审核和来源记录。
