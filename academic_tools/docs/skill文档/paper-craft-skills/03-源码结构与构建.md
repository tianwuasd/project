# 源码结构与构建

> 版本说明（2026-10-19）：源码已更新；正文保留此前整理的指南，功能与安装入口以当前上游 README 为准。见[本次更新记录](../../../UPDATE-2026-10-19.md)。

## 1. 源码布局

```text
paper-craft-skills/
  skills/
    paper-comic/
      SKILL.md
      references/
    paper-analyzer/
      SKILL.md
      styles/
      prompts/
      scripts/
    paper-deck/
      SKILL.md
      scripts/merge_deck.py
  README.md
```

三个目录分别承担图解、论文分析和 deck；以当前 clone 的目录和 frontmatter 为准。

## 2. 加载关系

兼容宿主分别加载 `skills/paper-comic/SKILL.md`、`skills/paper-analyzer/SKILL.md` 或 `skills/paper-deck/SKILL.md`。主 skill 决定任务分解和输出格式，analyzer 的样式/提示词/脚本与 deck 的 `scripts/merge_deck.py` 是可选运行层，不会自动证明内容正确。

## 3. 构建方式

没有统一的项目编译步骤。上游可通过兼容宿主的 skill 安装/发现机制加载 Markdown；deck 合并脚本和图像/PDF 生成工具只在具体产物需要时运行。可能依赖 Pillow、python-pptx、PDF 解析工具、生图后端、GitHub/CDN 或其他外部服务，版本和许可必须单独核对。

## 4. 验证方式

验证以人工视觉与内容检查为主：页面渲染、字体、箭头、图例、引用、页码、输出尺寸和信息保真度。仓库资料未说明一个可代替逐页审查的统一测试套件。
