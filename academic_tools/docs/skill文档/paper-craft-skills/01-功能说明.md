# 功能说明

## 定位

Paper Craft Skills 是论文视觉沟通工具包，包含论文方法/概念图解、论文内容分析以及演示文稿生成，目标是把已核验的研究内容转成读者可理解的图和 deck。

## 主要功能

- `comic`：将方法、流程或概念设计成漫画/方法图；
- `analyzer`：分析论文并生成结构化 HTML 长文或阅读产物；
- `deck`：生成或整理 PPTX/PDF 汇报；
- 参考资料、视觉提示、模板和合并脚本支持上述流程。

## 输入与输出

**输入**：论文 PDF/文本、方法流程、真实图表、受众和演示目标。

**输出**：图解草稿、HTML 分析页、PPTX/PDF deck、页面素材和修改清单。视觉产物必须保持原始方法、数字和不确定性，不得用设计效果掩盖证据缺口。

## 适用边界

适合论文解读、教学、组会和投稿配图；不适合由图形自动推导科学结论，或把生成图当作实验数据。文章资料对其未给出明确分档，现有介绍只作为选型参考。
