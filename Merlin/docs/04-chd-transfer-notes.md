# Merlin 对先心 CT 研究的迁移思考

下面是依据论文和源码提出的研究思路。Merlin 的主要预训练背景是成人腹部 CT，不能把它在腹部任务上的结果直接当成儿童先心 CTA 的有效性证据。

## 先明确任务

| 目标 | 可以借鉴的部分 | 主要缺口 |
| --- | --- | --- |
| 病例级病种分类 | 2048 维冻结表征、少样本分类协议 | 全局池化是否保留异常连接信息 |
| 报告与影像匹配 | 512 维图文空间、正负描述组织 | 中文报告、先心术语和当前预训练文本分布的差异 |
| 心脏与大血管分割 | 预训练编码器、独立 nnU-Net 适配代码 | 解剖类别、细小结构、空间分辨率和解码器适配 |
| 异常拓扑识别 | 用表征辅助病例筛查或融合其他特征 | 原模型没有显式的心腔与血管连接图约束 |

第一步建议选一个明确的目标，例如“固定病种集合的病例级分类”，并写清一个患者可否有多个标签。不要把表型分类、病种诊断、分割和报告生成混成同一个评价任务。

## 可检验的第一个问题

**在相同患者划分和标签预算下，Merlin 冻结特征是否比简单的对照表征更有用？**

建议先做以下对照，而不是立即端到端微调整个模型：

| 组别 | 输入与方法 | 能回答什么 |
| --- | --- | --- |
| A | 简单临床／结构化特征，加相同类型的分类器 | 现有低成本信息能做到什么程度 |
| B | ImageNet 膨胀三维编码器的特征 | 与通用视觉初始化相比如何 |
| C | Merlin 冻结 2048 维特征 | 医学多模态预训练是否带来增益 |
| D，后续 | Merlin＋心脏局部输入 | 视野选择是否改善目标病种表现 |

B、C 的输入预处理、分类器、调参预算和划分需要尽量匹配。局部输入会改变输入分布，应作为单独对照记录，不能悄悄替换后仍声称完全沿用官方协议。

## 最先检查的三件事

### 图像与标签能否一一对应

以患者为划分单位，同一患者的不同检查、重建或时相不要分散到训练集和测试集。确认标签来自哪次检查、是否包含术后病例、是否存在同一病例多个病种以及历史诊断与当前影像不一致的问题。

先列出样本清单与各类别数量，再确定指标。少见类别和多标签任务不能只报告总体准确率。

### 官方预处理是否保留目标结构

标准代码采用 `1.5×1.5×3 mm` 重采样和 `224×224×160` 中心裁剪。对于细小血管、冠脉开口和异常连接，沿层间方向的细节可能受到影响。

先人工检查一小组不同病种的处理前后图像，记录心脏覆盖、左右方向和目标结构是否可见。保留原始高分辨率数据；改变体素间距时，同时考虑计算量和与预训练分布的差异。

### 表征是否靠其他线索完成任务

扫描中心、增强时相、年龄、设备和术后改变可能与病种相关。模型也许学到这些替代线索，而不是想要的异常解剖关系。

因此，要按中心、年龄和扫描条件查看结果；有条件时使用外部中心测试。对于判错或特别高置信度的病例，回到图像与标签核查，而不是只看一个平均 AUROC。

## 建议阅读与实验目标

- [ ] 阅读 `ImageTransforms`，画出输入的形状和空间变化。
- [ ] 追踪 `ImageEmbedding=True`，能解释 2048 维输出来自何处。
- [ ] 运行一例特征提取，确认 `(2048,)` 且数值有限。
- [ ] 固定患者级划分，保存每个集合的病例清单。
- [ ] 完成一种轻量分类器的验证选模，测试集保持独立。
- [ ] 对比至少一个合理基线，再决定是否进行全量微调。
- [ ] 若目标涉及异常连接，加入相应结构或拓扑评价。

前两项是读代码目标，后五项是后续实验目标，本次整理没有代替这些实验。

## 什么时候转向分割仓库

如果目标是心腔或大血管分割，应进一步阅读 [Merlin-nnUNet](https://github.com/ashwinkumargb/Merlin-nnUNet)，关注多尺度特征如何送入解码器、类别数如何定义、权重怎样加载以及训练配置。

对照应包括从头训练的 nnU-Net 和相同数据预算下的预训练初始化方案。除了 Dice，还要根据研究问题检查细小结构漏检、连通性或异常连接是否被错误“修正”为正常结构。具体指标必须由目标结构和标注规范决定。

## 论文中值得保留的启发

论文关于少标签迁移、报告粒度和跨中心验证的讨论，比单一总分更值得借鉴。精读笔记同时记录了报告拆分对分类与检索的不同影响，以及全量分割标注时并非所有设置都优于 nnU-Net。

参见[论文精读笔记](05-paper-notes.md)的 Results 2.1、2.3、2.6，以及 Methods 与外部验证部分。把这些结果转化为本地对照设计，比直接假定“基础模型必然更好”更有研究价值。
