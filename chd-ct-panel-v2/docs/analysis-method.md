# 只读数据分析方法

1. 实际目录发现影像/标签，单列缺标签与孤立标签；冻结描述只是来源证据，不决定本轮选择。
2. 前后各计算压缩源文件SHA256。影像像素另计算同shape/dtype的字节摘要，分别报告压缩文件重复和解码像素重复，不据此自动合并患者。
3. 在每例一次解码的数组上检查维数、shape、affine、单位、标签整数/范围、有限值；网格不一致时不声称能计算正确的标签内影像灰度。
4. 计数、均值、标准差和整数类内众数使用完整数据；超过20万体素的百分位为固定种子均匀采样，JSON/报告注明。
5. 参考标签0背景、1LV、2RV、3LA、4RA、5MYO、6AO、7PA。额外编号仅记录，不映射背景，不改真值。
6. 某结构至少1000体素且精确众数占比≥50%时标记“源灰度需复核”。阈值只筛查，不作为医学诊断或自动排除规则。
7. 作者表SHA与冻结描述一致时引用其报告spacing；没有重新认证数组轴/扫描坐标，也未改头。author_volume_ml仅为按报告间距计算的暂定量。
8. 6邻域连通区域默认只检查指定样本及缺标注/源灰度标记样本。其他样本显示未检查，不能当成正常。多连通域不直接判断错误。
9. 预览来自原生数组三平面，在参考结构最多的位置选切片；显示窗为p01-p99原灰度单位。没有恢复、插值、归一化或修复源数据。
10. 每例完整JSON原子提交，恢复核对相同分析合同与当前源SHA。出错项单独保存错误栈，其余独立项继续。

读取并发与计算并发分开，有界资源估算是准入策略，不是系统硬内存限制。RSS为周期采样的进程组求和，可能重复计算共享页并漏过瞬时峰值。报告未做串行对照，因此不声称速度提升比例。
