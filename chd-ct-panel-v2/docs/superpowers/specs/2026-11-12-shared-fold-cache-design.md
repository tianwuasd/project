# STU-Net 三折共享缓存

用户已确认保留三折训练并共用一份数据缓存。保留每折原训练集拟合的灰度、spacing、划分和模型；采用一个缓存目录按折顺序复用的结构。换折按对应参数重新生成数组，训练模型及恢复状态各自保存。

## 采用方式

共享目录同时只表示一个活动折。各折的计划和完成记录保留，数据数组只保存活动折的一套。该方式沿用当前全部数值处理和训练取块流程，换折增加计算时间，不同时训练不同折。共享原始数组并在每个随机取块时反复执行完整重采样会增加供数计算与内存压力；本次采用顺序复用的完整活动折缓存。

## 数据与恢复

- 新预处理默认使用共享存储，可显式选择原分折独立存储。旧运行通过自身冻结代码恢复。
- 共享存储模式进入预处理签名。活动折与构建状态另行记录，不进入数值参数。
- 准备全部折时拟合所有请求折的独立计划，只生成所选活动折数组。
- 切换开始标记 building，全部目标病例验证后标记 ready。中断后的 building 状态禁止训练，可显式恢复构建。
- 写入只替换已登记的病例文件，清理旧缓存中当前不再选中的病例，不处理未知文件。
- 训练和构建使用同一缓存锁，训练期间禁止切换。训练 rank、供数任务和预处理子进程分别登记系统文件锁，主进程异常退出后仍可识别存活子进程的占用。训练读取前核对活动折、计划合同和病例范围；供数任务同时检查构建编号，禁止已失去归属的旧任务继续读取或写入。
- 同一折重新生成后，其数组及合同必须保持可核验，恢复科学身份不引用临时生成编号。
- 旧的独立折缓存和已有半程模型保持原样；本次不自动迁移或删除旧数据。
- MedSAM2 继续读取三折计划与原始病例清单，保持自己的共享轴位缓存。

## CLI

`prepare --storage shared --cache-fold 0 --fold all` 保存三折计划与一套第0折数据。共享存储采用稳定默认目录。通过同一输出目录 `--resume --cache-fold 1` 切换到第1折。`--storage independent` 保留原布局。

`train --fold N` 要求共享缓存已经完成且活动折为 N；错误折给出明确的切换指令。三折的模型输出目录保持独立。

## 验收

文件管理测试验证锁冲突、building 拒绝读取、错误折拒绝、未知文件保护和恢复。真实病例短测仅在获准后处理一个明确指定的病例，用两组技术测试参数对照共享与独立存储的完整数组和属性，验证物理存储是否只保留一套常驻数据。不训练模型，不处理整个队列，不运行全部交叉验证折。病例验收结果只保存到调用者指定的本机日志目录。
