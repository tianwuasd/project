## 速度测量

在同一真实CT的128³区域、同一旧模型64³ patch、27个窗口、步长0.5、TTA关闭条件下，预热两种批量后交替测量3轮。计时只覆盖滑窗及融合，数值比较在计时结束后进行。

| 配置 | 三轮中位数 |
| --- | ---: |
| 每次1个滑窗 | 0.727484秒 |
| 容量探测选择4个滑窗 | 0.307528秒 |
| 吞吐比值 | 2.365584倍 |

CUDA两种批量的标签一致率为99.998331%；最大logit绝对差为0.046875。混合精度运算与卷积实现随批量有数值变化，不能宣称逐位一致。CPU FP32滑窗批量测试通过严格数值容差检查。

ct_1002 一次恢复后的GPU完整计算记录：图像准备10.95秒；576个滑窗6.43秒；原图还原、文件写出和七结构评价47.47秒。进程启动、依赖导入、容量探测和资源等待另外记录。局部滑窗加速比不能直接当作整例总耗时加速比。

## 验收入口与证据

`scripts/validate_prediction.py` 实际启动后台预测，检查重复启动拒绝、主动停止、恢复、空间几何、来源签名和完成结果复用。参数必须指向真实来源训练及预处理；不创建虚假权重或完成标记。

`scripts/validate_prediction_recovery.py` 在真实工作进程开始后，终止本任务的监督进程，检查工作进程释放、重新启动、输出几何和完成结果复用。进程身份验证只针对本验收任务。

`scripts/benchmark_prediction.py` 使用已冻结预测模型和实际预处理CT区域，记录三轮吞吐、显存和数值差异。运行前应确保没有其他计算任务影响测量。

本机证据根目录：`D:/projects/back/t17/chd-prediction-20261108/`。

- `cpu-background-final/acceptance.json`：CPU真实生命周期验收。
- `cuda-acceptance/acceptance.json`：CUDA真实生命周期验收。
- `benchmark-warm.json`：预热后的三轮性能与数值记录。
- `cache-equivalence/report.json`：旧缓存与图像独立重算一致性。
- `new-ct-acceptance/summary.json`：真实无标签整例入口。
- `prefetch-acceptance/acceptance.json`：真实CT区域预取验收。
- `supervisor-recovery/acceptance.json`：监督进程异常终止及真实预测恢复。
- `runtime-reviewed.log`、`suite-final-reviewed.log`：运行边界及最终完整回归日志。
