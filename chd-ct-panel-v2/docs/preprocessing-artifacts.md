# 预处理产物精简

正式预处理成功结束后自动清理已完成任务的描述 JSON、结果副本、最新进度 JSON 和已确认归属的遗留暂存。STU-Net-S 与 MedSAM2 共用文件管理入口。处理算法、三折拟合与数据格式保持原合同。

保留训练数据、完成标记、审计记录及统计样本、方法与折划分、冻结代码、完整日志、详细阶段计时和资源记录。STU-Net 新运行默认保存三折独立计划和一套活动折数组，换折时在同一目录重新生成；原独立存储模式与旧缓存继续可读。MedSAM2 数组按病例保存，供各折共享。见[三折共享缓存](preprocessing-shared-cache.md)。

已完成的旧结果可以通过下列命令先查看拟清理清单与实际逻辑容量，再应用。

```bash
python -B run.py compact --prepared /path/to/prepared
python -B run.py compact --prepared /path/to/prepared --apply
```

只读检查不生成报告文件。应用后保存 cleanup.json，记录规则、候选清单、实际移除文件数、移除的逻辑字节数及清理前后占用。统计排除 cleanup.json 自身和操作期间的临时写入归属记录 `.cache-writer.json`；文件系统压缩、硬链接与分配块可能让逻辑字节数和实际释放的磁盘空间不同。

活动运行、未完成运行、缺失数据、来源不匹配、链接路径以及含有未知文件的暂存目录会停止清理。清理过程中断时，训练数据与完成记录保持完整，下一次应用重新核对现存文件。

新输出默认位于 `{workspace_root}/chd_ct_v2_stunet_results`。Linux 从本机 `workspace_root`、环境变量 `CHD_WORKSPACE_ROOT` 或项目路径中最近的 `*_workspace` 目录确定工作根，数据集默认使用当前登录用户名对应的数据根。公开配置只保存通用模板，生效路径保存在本机运行记录中。预处理显式输出及本机配置也拒绝写入 `/data_nas`。已有 NAS 结果继续作为只读输入；需要在原目录写出的恢复或清理须先完成到 workspace 的独立迁移及验收。

旧 STU-Net 预处理的 `--resume` 校验原签名及冻结文件摘要，并由冻结生产者执行恢复，使用原数据合同。恢复进程在运行目录的父目录临时复制一份已核验生产者，退出时清理；复制内容仅为该运行保存的代码与配置，避免源码复制时源文件与目标相同。文件精简保留恢复需要的审计样本。训练中的检查点与训练冻结代码保持原状，已有训练可以继续读取精简后的数据文件。

本轮文件管理短测使用两份实际配置文件作为内容样本，执行真实 Blosc2、NumPy、JSON 和文件锁操作；测试数据不作为医学数组或模型效果证据。没有启动病例预处理、模型训练或全量数据处理。
