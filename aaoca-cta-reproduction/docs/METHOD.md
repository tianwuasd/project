# 方法与可行性边界

## 原文与作者代码

论文PDF共11页，主要方法见第8—10页。作者分割主动脉、左室腔和心肌，用定位点裁出约80×80×60毫米区域，再使用三维MONAI SENet154。三个独立二分类任务分别是AAOCA有无、右/左异常冠脉、论文定义的低/高解剖风险。起源与风险模型使用异常检测网络初始化。高风险包含inter-arterial和sub-pulmonic；不得擅自替换成其他风险定义。

按已审核的论文任务口径，文书明确诊断的冠脉高位异常起源可登记为AAOCA研究阳性，保留具体异常血管、high_takeoff及原文/页码。含糊“高位”或单个高度数值不自动归类。high_takeoff本身不充分决定high_risk=0；风险类别仍需整体走行依据并处理冲突。这是论文解剖分类，不代表患者临床事件风险。intramural（壁内）、intraseptal（室间隔内）、肺动脉起源和歧义“壁间”分别保存，不因词义相近替代论文的inter-arterial/sub-pulmonic终点。定义依据见[论文Methods任务段及Fig.6](https://www.nature.com/articles/s41467-025-58362-9)。

作者分类将患者按90:10划分。论文所称五个分类fold是同一患者划分下五个随机初始化，预测平均；分割部分才使用五折交叉验证。此次小规模本地队列不能称为复现原论文的外部性能。

作者发布代码：`b134e621943f60f20caf6a9272aa85ceeeb441f8`。裁剪采用LV=2、主动脉=3，分别进行默认六邻域一体素膨胀，取相交区域坐标均值并四舍五入；无相交时在膨胀LV区域中寻找离膨胀主动脉最近的点。随后按源数组三个索引轴施加 `(-10,+10,+10)` 毫米偏移，尺寸为 `(80,80,60)` 毫米，各轴按 `int(mm/spacing)` 取整并限制在源范围。

上述偏移来自代码的索引轴约定，不自动等价于任意方向影像上的“向右、向上”。本地输出同时记录索引偏移及其实际RAS位移，保留来源方向；不默认把AAOCA的LPS和ImageCHD的RAS视为相同约定。

作者分类预处理输出215×215×85，B-spline重采样后裁剪范围，再进行 `clip(HU,-1024,1024)`、`floor((HU+1024)/2048*255)/255` 离散化。作者代码使用TorchIO在数组输入上重采样。r2两例已通过真实TorchIO0.19.6与固定作者裸数组流程的直接比较，float32归一化数组完全一致；验收范围见`PREPROCESSING_ACCEPTANCE_20261121.md`。

论文初始学习率0.001；发布版 `train.py --lr` 默认0.0001。后续配置必须明确选择并记录。代码采用AdamW、BCEWithLogitsLoss、余弦调度、dropout 0.3、最多300轮。不能套用现有STU的200轮、三折或标签定义。

## 本地数据

AAOCA来源为私有CT及定位分割对应清单。既有 `.seg.nrrd` 来源为TotalSegmentator 2.18.0的自动粗分割，结构值与层号逐例从Slicer元数据读取；不充当医生诊断或人工分割。

ImageCHD采用已保存的私有配对清单。LV=1、主动脉=6。其NIfTI头间距为默认值，裁剪使用该病例作者Excel提供的spacing_xyz。方向依据为保留该NIfTI头的数组轴方向，作者Excel间距没有提供独立DICOM方向验证。本地配置和每例记录明确保留此限制，原件不改写。CHD1282方向推断不用于此数据。

候选队列按登记主编号及别名进行患者隔离，每名患者选一例，其他期相不进入其他组。分组及真实病例清单仅保存在私有配置中。分类真值默认未知；ImageCHD不默认正常，未知标签不计为正常，不计算诊断准确率。

监督支持原confirmed策略，以及用户允许的document_explicit文书来源研究策略；均保留真实来源和当前CT对应状态。研究策略逐任务采用确定原文，不将待复核状态改成医生确认。高位开口、狭窄、壁内段不能单独映射为论文的inter-arterial/sub-pulmonic高风险；“可能”“不能除外”保持未知。具体字段及采用条件见`CLASSIFICATION.md`。

## 当前可执行范围

分类预处理配方`author_native_index`复用同一内存裁剪，真实TorchIO0.19.6以单位仿射和shape/target比例重采样，量化后分别保存float32推理影像及float16训练数组。真实世界仿射由裁剪仿射乘实际TorchIO单位采样格计算，记录原头/有效源/裁剪/目标/网络仿射、八角体素中心、世界位移与非对称点。r2已验收两例预处理，作者参考方向仍待确认，正式混合分类尚未验收。
