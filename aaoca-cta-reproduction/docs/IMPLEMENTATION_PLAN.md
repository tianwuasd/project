# AAOCA论文复现实施计划

目标：在独立工程中复现作者公开的定位、裁剪、分类训练和预测流程，保留患者隔离、真实监督与作者代码版本证据。秘书已审核本轮两例、零训练更新范围。

## 模块与接口

- `audit.py`：`build_manifest(config)`，消费既有CT/标签登记、患者别名和ImageCHD清单，产生私有候选病例及隔离核对。
- `prepare.py`：`prepare_case(case, config, directory)`，消费一例真实影像和已声明的定位分割，输出裁剪图像和几何、时序、资源记录。
- `run.py`：当前提供 `audit`、`prepare` 和 `check-training`，只连接已有实现。
- `smoke.py`：两套数据各一例，病例来自私有配置，零训练更新；记录验收后自动清理本轮副产物。
- 后续 `classification.py`：取得模型和真实监督后接入MONAI SENet154；`train`保存完整恢复状态和best，`predict`强制实际权重且注明初始化来源，未知标签保留为空。
