## 模块与接口

- `audit.py`：`build_manifest(config)`，消费既有CT/标签登记、患者别名和ImageCHD清单，产生私有候选病例及隔离核对。
- `prepare.py`：`prepare_case(case, config, directory)`，消费一例真实影像和已声明的定位分割，输出裁剪图像和几何、时序、资源记录。
- `run.py`：登记/裁剪/迁移之外，接入`prepare-classification`、`export-confirmed-labels`、`train`、`predict`。新增数值入口未验收，运行前须具备真实依赖、方向、监督或权重及具体授权。
- `smoke.py`：两套数据各一例，病例来自私有配置，零训练更新；记录验收后自动清理本轮副产物。
- `classification.py`、`training.py`、`prediction.py`：真实网络、完整恢复和五成员预测代码已接入，接口及未验条件见`docs/CLASSIFICATION.md`；未知标签保持为空。
