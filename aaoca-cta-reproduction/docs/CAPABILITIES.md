# 实现与验收边界

| 要求 | 当前实现 | 缺口 |
|---|---|---|
| 隔离 | 主编号/别名、每人一个体积、角色冻结 | 跨数据集真实身份无独立映射 |
| 必要检查 | audit显式重建；其他入口读取冻结清单，只查所选病例 | 不做启动逐例全扫描 |
| 预处理 | 既有标签定位、物理裁剪、原子保存及复用 | 作者215×215×85与TorchIO/ITK完整重采样未接入 |
| 方向 | 保留源轴并记录物理偏移 | 未验证统一输入方向，不能直接混合分类 |
| CPU/大块 | 串行、整例标签、局部距离计算、按ROI读CT | 无扩容或超限分块 |
| 内存 | 字段上限100GB、比例≤0.8，估计加50%准入等待 | 仅启动检查，RSS只采样；无运行中保护或硬隔离 |
| GPU | 无计算 | 分配、供数和加速均未实现 |
| 预处理指定 | 本工程同输入/方法/状态裁剪复用 | 无任意外部预处理接入，不能直接用STU/Q结果 |
| 训练/恢复 | 检查监督条件 | 训练、best/latest、优化器/RNG恢复未实现 |
| 预测 | 候选输入引用 | 无权重、分类预测、集成或准确率验收 |
| 日志/产物 | 开始、完成、等待及阶段耗时；work裁剪与记录 | 无训练/预测日志，长期data统一预处理未实现 |

两例真实定位裁剪短流程14.13秒，已清理4文件约16.1MiB；中心比较限实际64³标签区域。新增两例真实元数据跨根重绑定约0.021秒，角色/别名保持，零训练、零测试文件；绑定仅检查路径、大小和stat，不检查内容哈希。

复用既有Windows仿真接口核对源码及两例影像/标签5条路径，0.291秒，零测试文件；历史profile标记live_verified=false。本轮未运行旧STU场景、创建虚拟机、使用GPU或登录服务器。没有Linux/cgroup、CUDA/NCCL、运行中内存保护或服务器I/O证据。尚未实现的训练/预测不能由静态检查替代，也没有相应速度结论。
