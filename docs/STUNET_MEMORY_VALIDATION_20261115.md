# STU-Net 内存与分块验收

验证对象为 ImageCHD 的 ct_1003 和 ct_1141，各取真实 32³ 区域。训练使用两个 CPU/Gloo 进程、全局 batch 4，共两次优化器更新；第二次从完整检查点恢复。验证未读取正式 ct_1126 的整例体素，也未进行 GPU 训练。

| 检查 | 实际结果 |
| --- | --- |
| 常规与分轴插值，各两例 | 四项图像逐位一致，最大绝对差 0；标签、裁剪几何、类别采样位置一致 |
| 离线保存与独立读回 | 两例通过；再次运行复用数组，文件修改时间保持 |
| 训练及恢复 | 更新次数从 1 恢复到 2，`restored_exact=true`，全局 batch 为 4 |
| 两卡与200轮配置 | 只改 GPU 数量及训练轮数，离线配方身份保持一致；此检查不执行正式训练 |
| 协调进程结束 | 真实子进程停止新准入，主机等候检查拒绝失效 owner |
| 检查点保留额度 | 真实进程新增 8 MiB 常驻内容后，4 MiB 保留额度仍完整计入待用预算 |
| 日志 | 实际阶段事件转换为中文，病例与块进度同时可读 |

主流程总耗时 1,913.86 秒：计划 37.44 秒，离线构建 460.41 秒，训练与恢复共 72.25 秒。四项数值比较耗时分别为 132.16、120.44、461.86、494.54 秒。离线构建速度为 0.261 个技术 ROI/分钟；含启动、验证和保存的训练速度为 1.661 次更新/分钟。Windows 本地的映射页、文件与进程测量开销包含在这些数字中，不能据此推算 Linux 正式病例吞吐。

主流程测得父进程峰值 RSS 964,030,464 字节，进程组峰值 RSS 3,355,275,264 字节。Windows PSS 不可得，RSS 共享页可能重复计入。显存峰值未测量。结束前28个文件、118,506,251字节已全部自动清理；磁盘峰值未连续测量。

进程生命周期补充检查耗时12.11秒，进程组峰值 RSS 1,683,742,720字节，未执行优化器更新；5个文件、11,820字节已全部自动清理。仅保留验收JSON和必要日志，报告位于本地既有 `back/sync-reports/chd-segmentation-stunet/offline-preprocess-20261115/memory-blocks`，不作为服务器输入上传。

完整验收前的数值比较曾通过，但受限执行环境的 TCPStore 初始化失败；在已获准的实际双进程执行中，Gloo初始化、两次更新及恢复均成功。正式Linux的cgroup、POSIX页缓存回收、CUDA/NCCL以及完整ct_1126尚待服务器实际运行；本记录仅证明上述有界范围。

本次保留 main 的 Q/MedSAM2 源码与入口；这些模型的整例处理和历史检查点相容性不在本次 STU-Net 验收范围内。
