# 1282的Q组合与MedSAM2标签框评测

**Goal:** 复用1282冻结角色生成可迁移的Q分组，并接入MedSAM2从标签自动生成框的正式提示式评测。

**Architecture:** Q使用独立私有迁移包，原训练患者按r2原提案50:25的相对比例分成A/B，即2:1；C沿用原验证，D保留内部测试与两个外部子组。MedSAM2在显式label-box模式读取标签，仅将生成的二维框及提示层送入官方传播模型，并记录标签摘要和有提示评价结果。

**Tech Stack:** 既有Python、JSON/YAML、NIfTI、PyTorch和官方MedSAM2；不增加依赖。

**Spec:** 用户要求按照原1282划分调整Q组合，更新MedSAM2标签框模式；研究编号A-A → Q → Q-20261108-路线一，版本q-route1-20261111-r2。
