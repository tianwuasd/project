## 文件夹结构

```text
whole_heart/
├── README.md
├── .gitignore
├── 参考资料/                  # 学习资料、来源标注与索引
└── 数据探索工具/              # 中文注释代码、测试、说明和完整示例结果
```

原始数据集 `Wholeheart_Train_Dataset/` 因体积较大不上传。复现时，将自行获得的数据集放在本文件夹内，与“数据探索工具”并列，或使用 `--input` 指定它在本机的位置。

示例结果来自本地 106 组病例记录；统计、空间异常和重复影像情况见验证记录。仓库中的代码不会自动修改原始影像或标签。

参考资料的来源及使用说明以各资料标注为准。本次上传不改变第三方资料原有权利。
