# 本数据集实验记录清单

> 以下是结合资料与本地检查整理的实践清单，不是 CARE 官方新增要求，也不是 CLAIM 原文逐项翻译。

## 数据质量

- [ ] 保存原始数据，只在独立副本上转换。
- [ ] 记录影像与标签配对、尺寸、spacing、origin、direction / affine。
- [ ] 核实 Case3010 的 421 标签；保留处理依据，不按数值接近擅自改为 420。
- [ ] 核实 Case2009、Case2017 的空间定位，不盲目覆盖文件头。
- [ ] 查看多个病例及多个平面的标签叠加图。

## 划分与预处理

- [ ] 保存病例级划分清单；若同一患者有多例扫描，按患者合并分组。
- [ ] 记录 CT/MRI 和中心分布；分别定义内部划分与中心留出实验。
- [ ] 明确哪些数据用于拟合归一化等统计；严格外部留出数据不参与拟合或调参。
- [ ] 记录标签 0～7 与原始标签编号的双向映射。
- [ ] 记录方向统一、目标体素间距、裁剪和重采样方案。
- [ ] 对标签使用类别安全的重采样方式，避免对数字类别编号直接连续插值。
- [ ] 分别记录 CT 和 MRI 的强度归一化；说明任何附加校正是否经过验证。

## 训练与评价

- [ ] 固定基线模型、数据划分、随机种子和依赖版本。
- [ ] 记录 patch 大小、训练批量、轮数、损失和增强配置。
- [ ] 每次改进尽量只改变一个因素，保留比较结果。
- [ ] 验证完整三维病例；不把训练过程的小块近似指标当最终成绩。
- [ ] 将预测恢复到原始影像空间，检查方向、尺寸、间距和标签编号。
- [ ] 逐类、逐模态记录 Dice 和距离指标；HD 使用毫米。
- [ ] 明确 HD 与 HD95，使用 CARE 官方约定和血管截断规则。
- [ ] 记录空预测、缺失类别、加权汇总和后处理的具体计算规则。
- [ ] 保存失败病例可视化，不只报告总体平均值。
