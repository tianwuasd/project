# whole-heart 任务面板适配

2026-10-24；依据 server-engineering 当日模板。用户要求更新旧入口，训练和预测可多选，目前模型为 B0、B1。

保留现有七类、数据划分、训练预算、同初始化比较、来源开发选模、目标评价口径。模型注册表供表单、命令行、队列、冻结和报告共同使用；选择 B0、B1 或两者。单模型不生成两组配对统计；预测只要求预先选定的实验完成。没有选择文件的旧完整实验仍要求全部十组，不能借本改造绕过原冻结范围。

保留两个 shell 入口，均用系统 Python 打开中文面板。独立环境安装由后台步骤触发。菜单默认查看状态；支持命名新建、步骤多选、历史输入、续跑、独立重跑、状态/GPU/模型/日志/进程/结果查询、明确目标中断、多线路程序更新。表单 b 返回、q 退出，退出查看不停止计算。

任务目录唯一，显示名称不用于路径；配置、源码快照、状态、逐步日志、来源与回执分别保存。新任务在独立 workspace 运行，模型清单冻结在执行前。续跑使用原快照和原选择；旧工作区可只读查看或在新任务中引用，不能重写旧训练签名。

来源缓存独立复制到新工作区后验证，不用可能被原地恢复改写的硬链接；旧缓存不被后续写入。复用失败只在识别为缓存不兼容时回退新缓存，原始数据错误不回退。CPU准备在GPU等待前完成。GPU候选必须在明确分配及继承可见范围内；并发上限独立，真正执行前再查空闲。只停止身份匹配的本任务进程。

结果中心按分割摘要、逐病例/结构、训练与数据、文件与来源分页，缺失显示未知；不添加本项目不存在的诊断页。模型/训练/预测查询读取实际日志，不将心跳当进度。默认仅本地改造和合成验收，不启动正式训练或部署服务器；上传产物不是本次所需功能，不新增上传渠道。

验收重点：B0-only/B1-only/both贯通；空/未知选择拒绝；旧全量默认保持；单模态和单模型汇总可用；查询不导入训练依赖或写历史；取消无提交；同名不覆盖；历史选择不改最近指针；CPU不等GPU；可见范围不越界；Linux锁/停止身份和后台退出语义；旧结果保持可读。
