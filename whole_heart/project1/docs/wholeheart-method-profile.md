# 面板升级的方法适配记录

2026-10-25。工程模板基于 server-engineering 2026-10-24 版；本次调整任务管理和模型选择，不新增文献候选算法。

| 部分 | 本项目实际约定 |
|---|---|
| 数据 | CARE whole-heart CT/MRI分开；沿用原病例清单、五例隔离和中心留出；患者唯一性仍需核实 |
| 标签 | 原始BG0/Myo205/LA420/LV500/RA550/RV600/AO820/PA850，训练映射为0–7；没有借用CHD其它工程标签 |
| 几何与强度 | 来源训练指纹交给nnU-Net规划；物理间距、图像和标签转换继续使用原实现，没有新增resize或通用归一化 |
| 模型 | B0原nnU-Net；B1仅额外BiasField与单调Bezier。注册表集中控制菜单和训练器选择 |
| 预算 | seed0；CT250轮、MRI300轮；每轮250训练/50来源开发验证步，保持原训练器 |
| 初始化/划分 | B0/B1同初始化核对；训练和指纹拟合只用既定来源训练集，开发与目标不加入拟合 |
| 模型选择 | 原训练器使用来源开发EMA Dice选best，final证明训练结束；不按目标成绩选模型 |
| 推理 | 关闭镜像；滑窗与Gaussian融合、原网格恢复、raw/LCC后处理保持 |
| 指标 | 七类Dice、HD(max)、HD95毫米；空预测保留失败，双空标未定义；单模型无两组配对差值 |
| 新实验范围 | 新任务提交前记录folds/methods；所选组合全部完成才冻结；原无选择清单的全量实验仍要求十组 |
| 工程变化 | 命名任务/独立目录、后台和源码快照、输入复制/恢复、只读查询、CPU前置、GPU范围与并发、多选贯通、隔离版本更新 |
| 兼容 | 缓存按原预处理签名验证；训练恢复必须原快照；旧完成模型仅精确白名单可评价；旧结果直接只读 |

备份位于本地私有工程记录目录。新任务的代码/来源/环境/选择与产物记录分别落盘，公开代码不包含新影像、权重或运行数据。未运行真实训练/CT预测，未改变研究假设或宣称模型效果提升。
