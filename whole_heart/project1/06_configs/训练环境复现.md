# 训练环境复现

基础环境由根目录 `environment.yml` 创建。它使用 OpenBLAS，避免本机 Conda MKL 与 PyTorch 的 OpenMP 运行库冲突。没有设置 `KMP_DUPLICATE_LIB_OK` 来忽略冲突。

在 `whole_heart_project1` 中先安装配套的 CUDA 轮子，再安装 nnU-Net，并对后续安装施加约束：

```powershell
conda activate whole_heart_project1
python -m pip install torch==2.8.0+cu128 torchvision==0.23.0+cu128 --index-url https://download.pytorch.org/whl/cu128
python -m pip install nnunetv2==2.8.1 --index-url https://pypi.org/simple -c 06_configs/training_constraints.txt
python -m pip check
python -B -X utf8 -m unittest discover -s tests -v
```

这些包来自国外服务，本次使用命令级本地 7897 代理；没有修改全局代理配置。不要将本机代理地址当作其他电脑的必备参数。官方来源：[PyTorch 安装说明](https://pytorch.org/get-started/locally/)、[nnU-Net 安装说明](https://github.com/MIC-DKFZ/nnUNet/blob/master/documentation/installation_instructions.md)。实际版本以本项目锁定记录为准，不以网页默认推荐版本替代。

`conda_explicit_training.txt` 记录 Windows Conda 包构建；`pip_freeze_training.txt` 记录 Python 包版本。后者主要作为审计记录，不能直接当作从零安装 CUDA 的唯一命令。跨系统复现需另做兼容测试。

代码使用官方 nnU-Net 的规划、预处理、损失与训练步骤，增加来源隔离和研究增强。没有修改环境中的 nnU-Net 包源码。nnU-Net 2.8 直接实例化训练器时须补充 `continue_training` 字段，项目子类通过复制配置后补齐，避免破坏共享计划。

固定随机种子保证两组初始化可核对；相同采样策略不意味着每个训练批次完全相同。新增增强会消耗随机数，GPU 运算也不承诺逐位确定性。恢复检查验证权重、优化器及后续一步可运行，不声称数据加载器和随机数流逐位回放。
