# 所选模型的多卡预测与评价

2026-10-25更新。新面板预测读取任务中预先冻结的模型与留出方向，支持B0、B1或两者。默认单模型不会等待未选择模型，单CT范围也不会等待MRI。旧无选择清单的完整实验仍要求十组全部完成。

```bash
bash run_zmic44.sh --tasks predict --input-job /完成任务目录 \
  --models B0,B1 --scope ct-first --gpus 0,1 --gpu-count 2 --non-interactive
```

`--input-job`可为同runtime的命名任务或已完成的旧whole-heart工作区；新任务复制所需数据与权重到独立目录，原结果不覆盖。准备和训练尚未完成时，选择同一任务的`prepare,train,predict`。

每个GPU评价一个模型，预测沿用来源开发选best、关闭镜像、原图网格恢复与raw/LCC两套结果。评价并发不超过本次`--gpu-count`和原配置的3卡上限；只在本次候选与继承可见范围的交集中找空闲卡。

结果在任务workspace的`09_reports/final_evaluation`。只有B0/B1都选中且病例完整配对时才计算差值和区间；单模型保留每类、逐病例、逐中心指标，配对字段为不适用。缺失/空预测不能删掉，HD与HD95不混写。

状态：`--query status`；各模型进度：`--query models`；预测详细日志：`--query logs --follow`；结果：`--query results --job /任务目录`。查看旧结果不要求重跑或安装训练依赖。

只有列入精确代码版本白名单的旧已完成模型可使用当前评价调度；这个入口不放宽训练续跑签名。软件测试不代表已在服务器实际部署，见 [验收记录](docs/server-panel-validation.md)。
