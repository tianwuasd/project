# 服务器启动脚本验证

日期：2026-09-19。目的：交付 Linux/Ubuntu + NVIDIA + Conda 的可交互启动入口。本次未启动正式研究长训练。

## 本次改动

- 增加 `start_server.sh` 和中文菜单，支持检查、CT/MRI 短测、选择正式训练范围、继续上次队列、查看状态。
- 独立 Conda 环境使用 Python 3.11、PyTorch 2.8.0+cu128、torchvision 0.23.0+cu128、nnunetv2 2.8.1；不直接套用 Windows 专用环境锁。
- 只迁移病例路径，保留已经冻结的病例划分及 5 例排除规则；逐文件校验原始发布文件 SHA256。
- 工作区与代码、原始数据分离。来源训练子集拟合指纹及规划，来源开发集只预处理和验证，外层目标组不进入训练目录。
- 分病例准备支持继续，正式训练每轮保存检查点，检查点与状态文件原子替换；代码/依赖/划分不一致时拒绝混用旧实验。
- 本地不设置 `WHOLE_HEART_WORKSPACE` 时沿用原来目录；设置后所有运行输出进入服务器工作区，代码从代码目录读取。

2. 新增测试覆盖：含中文/空格路径的病例迁移；来源文件不变；缺失、重名、内容变化时停止；保留划分与隔离；拒绝覆盖未知目录；损坏派生影像副本的恢复；不导出目标中心；检查点优先级；中断写入不覆盖旧检查点；非有限损失停止。
3. 使用模拟训练器测试正式任务的中断记录、显式续训、恢复检查点、完成后跳过、依赖变化时拒绝续训。此项只验证调度逻辑，没有运行真实 250/300 轮优化。
