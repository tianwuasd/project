## 目录约定

| 目录 | 存放内容 |
|---|---|
| 00_admin | 已确认决策、阶段状态、成本与变更记录 |
| 01_protocol | 研究问题、方法方案、实验矩阵、分析约定 |
| 02_materials | 本轮核心文献原件、阅读记录、检索与材料请求 |
| 03_workflow | skill 来源与哈希、角色提示词存档、实际使用边界 |
| 04_data/manifests | 病例清单、隔离清单、以后冻结的病例划分 |
| 04_data/derived | 后续派生数据；不放原件，默认不入 Git |
| 05_src | 数据转换、来源专用规划、受控训练器、增强、指标及短测入口 |
| 06_configs | 环境状态、后续冻结的模型与实验配置 |
| 07_experiments | 每次实验的独立目录、配置、日志与检查点 |
| 08_results | 预测结果和统计表；没有结果时不填示例分数 |
| 09_reports | 阶段总结、失败记录、最终研究报告 |
| tests | 后续数据转换、划分与评价的测试 |

原始数据通过 `../Wholeheart_Train_Dataset/` 引用；既有探索工具仍在 `../数据探索工具/`。本项目复用先前完整审计生成病例清单，不再重复扫描全量数据。Conda 环境由环境管理器放在本机 envs 目录，环境描述与锁定记录保存在本项目。

后续每次实验使用 `模态_留出组_方法_随机种子_时间` 命名，例如 `ct_holdG_B0_seed0_YYYYMMDD`。失败实验保留状态和原因；不覆盖旧结果。任何公式、模型效果和文件引用都需能回到来源或运行记录。
