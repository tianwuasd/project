# Whole Heart 数据探索设计

依据用户已批准的五步方案：整体构成、单例解释、标签分布、组间比较、问题检查。

- 输入为现有 Wholeheart_Train_Dataset，按文件夹及 *_image.nii.gz / *_label.nii.gz 配对。
- Python 命令行程序，原始文件只读；输出必须位于输入目录之外，默认创建带时间的独立结果目录。
- NiBabel 负责 NIfTI 解析与缩放，NumPy 统计，Matplotlib 绘图；不手写 NIfTI 解析器。
- 所有标签完整扫描；所有影像完整解压并检查非有限值。强度分位数采用有上限的确定性抽样。
- 区分空间文件头错误和正常编码差异；奇异 sform 不自动修复。可视化回退到有效 qform 时明确告知。
- 中文注释、中文 Markdown 报告与独立 HTML 报告、UTF-8 BOM CSV、JSON、PNG。
- 每组一例三方向预览；非预期标签和空间异常病例额外生成预览。图像按毫米等比例显示。
- 单病例失败不终止全批扫描；记录问题和跳过原因。输出完整扫描数和失败数。
- 校验标签计数、实际缩放、单位、空间矩阵、文件配对和输入只读保证。

范围之外：修复标签或文件头、训练模型、推断患者疾病、推断重复患者身份。
