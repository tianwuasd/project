# 研究方向与来源配置

默认方向：低空运输、无人机与骑手协同配送、网络选址、路径与调度；从运筹优化文献寻找可迁移算法结构。用户未确认哪些论文为本人所写，不推断作者身份。

本机来源写入项目 config/sources.json（不进入公共仓库）。支持JSON论文记录、WoS导出、PDF和Markdown笔记目录。导入后运行stats获得真实规模。PDF仅建清单，不代表读取正文。

设计参考了academic_tools中的academic-research-suite、operations-research-guide、citation-verification、hypothesis-generation和scientific-critical-thinking技能的阶段路由、证据分层、结构匹配、反例与公平实验理念；未复制其代码，也不将技能当学术证据。

固定站点接力、卡车携带无人机、骑手携带无人机属于不同系统，起降、回收和同步不能直接互换。战略选址与分钟级派单应分层，不能通过堆叠算法名制造贡献。
