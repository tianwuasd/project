# 路线 A：先检验动作排序和后决策 TD，再考虑扩大网络

检索日：2026-10-22。任务范围：针对单基地无人机订单接受/出发预约，寻找可证伪的方法改动；未改实验、manuscript 或 Academic Agent 源码，未训练模型。

## 结论与优先级

优先做 **共同外生轨迹下的固定策略 rollout 标签审计**，随后比较 **同一特征的 Monte Carlo 回报回归与现有 TD**。这能区分“后决策 TD 自举不稳”“特征不能区分关键容量状态”“价值数字误差大但动作顺序其实正确”。若固定策略 rollout 明显改进动作排序，再决定在线 rollout 或将标签蒸馏到现有价值网。

诊断标签必须写明续行策略：对每个冻结网络，定义其诱导的同一可行性筛选/动作选择策略π，使用π续行的完整MC回报估计V^π或Q^π，再与该网络打分比较，称为“相对冻结策略的价值校准差”。训练时是移动的Bellman最优性目标，冻结后的偏差仍不能单独证明实现错误。使用LP续行得到的是V^LP/Q^LP，属于独立教师或策略改进信号；它与当前网络的差异不直接叫TD估计误差。两个标签组必须分表，禁止混合回归目标。

第二优先是 **共享资源时间剖面与未来需求预测的状态补足**。CEVD 原文直接指出，忽略其他车辆动作会损伤联合决策；它还区分了估值校准和最终策略收益。但我方是单基地共享起降/机队/充电，不能直接复制“每辆车独立价值 + 空间邻车”的分解。应先证实模板插入特征存在混叠，再换表示。

当前80.03、79.99与公平LP82.17，以及1 seed/200 episodes和后期退步，只是诊断线索。现有证据不能证明TD必然失效，也不能证明新增风险特征无效。所有建议均为迁移假设，不是创新性结论。

## 1. NeurADP：核对现有方法，不把已有组件当作新改进

- **标题/年份**：Shah, Lowalekar, Varakantham, *Neural Approximate Dynamic Programming for On-Demand Ride-Pooling*，AAAI 2020（arXiv初版2019）。[DOI](https://doi.org/10.1609/aaai.v34i01.5388)；[官方PDF](https://ojs.aaai.org/index.php/AAAI/article/download/5388/5244)。`work_2790efb64c2e4f6c`。
- **已读范围**：已取得完整9页PDF；定向阅读PDF第4–5页/印刷页511–512，重点是价值分解、Bellman更新、经验回放及实用表示；不是全文逐页精读。
- **具体支持**：论文使用后决策价值、保存状态与可行动作集、离线重算匹配，再做一步Bellman目标；原文已包含target network、Double Q和prioritized replay。其他车辆的后决策状态被其决策前状态近似，实用实现进一步聚合为附近车辆数。这说明后决策分解与表示近似是设计选择，并不由Double结构自动修复。
- **适配改动**：先审计我方 replay 是否保存了足够的订单集合、时刻及容量占用，能在同一状态重新计算完整可行动作；把预测后决策价值与冻结策略的终局回报对齐，按时段、利用率、剩余期限分层。已有target/Double组件保持固定，避免把重复加入组件作为研究贡献。
- **不能迁移**：乘客分配ILP、可加车辆奖励与附近车辆计数不能替代共享资源时间重叠；其路网需求/旅行时间假设不保证全预约集合1%联合风险；不存在我方收敛或性能保证。
- **最小证伪实验**：抽取同一批128个历史后决策状态，以冻结早期和晚期checkpoint各算当前价值，并分别按该checkpoint诱导的策略π续行32条共同后续外生轨迹，得到对应V^π的实际回报。若晚期排序、估值校准和策略回报都无系统退化，则“后期退步由价值漂移导致”假设缺乏支持；若排序正常但收益仍退步，应检查状态分布及执行/可行性环节。
- **实现成本**：低，约0.5–1天建立诊断；估计基于已有状态快照与可重复仿真，不含重训练。

## 2. Hindsight Learning：先利用Exo-MDP的策略评估结构，再决定是否用预知未来的标签

- **标题/年份**：Sinclair等，*Hindsight Learning for MDPs with Exogenous Inputs*，2022预印本；本次下载v3，封面日期2023-10-24。[官方记录](https://arxiv.org/abs/2207.06272v3)；[PDF](https://arxiv.org/pdf/2207.06272v3)；通用标识10.48550/arXiv.2207.06272。`work_77d6df4d3b0048af`。
- **已读范围**：完整52页PDF已保存；定向阅读第1、6–7、9–12页：Exo-MDP定义、固定外生轨迹评估、Algorithm 1、Q-distillation及hindsight bias。未逐项复核附录证明。
- **具体支持**：外生输入分布不受动作影响、内生转移/奖励已知时，可用历史输入轨迹模拟不同策略；不需要把行为策略动作直接当作唯一可评动作。算法离线聚合访问状态和每动作hindsight价值标签，再蒸馏；对于时间相关输入，原文要求抽整条轨迹而非按时点独立重采样。原文同时明确hindsight bias可能很大、存在随时域增长的反例，故不能把预知未来求解值当在线策略价值。
- **适配改动**：将订单到达、共同天气/服务扰动写成按日/时刻索引的外生轨迹，保持跨订单相关性；动作只影响接受、预约及资源状态。对每个候选“拒绝/接受并预约”先做**固定非预知策略**的全程rollout，得到MC策略价值标签；这是借用文中Exo-MDP策略评估结构，不等于已经实现HL。第二阶段才考虑离线hindsight规划标签与Q-distillation，并以在线MC排序验证其偏差。
- **不能迁移**：若接受订单会改变未来到达率、延误分布或未建模的充电拥堵，则必须将这些依赖置于已知内生转移中，否则不满足结构。不同动作下逐次消耗同一随机数流不一定对应相同外生场，应采用订单/时间/设备索引的固定随机场。不能给实时策略输入实际未来订单或扰动；不能声称hindsight标签无偏；有限场景也不能认证1%联合机会约束。
- **最小证伪实验**：选128个决策状态、至多8个可行动作、32条共同后续轨迹。冻结LP策略及当前RL策略分别作为后续策略，记录每动作的MC回报、TD打分、置信区间和动作后悔值。先以当前冻结网络诱导策略π续行所得Q^π标签，以同一特征训练非自举MC回归，与该网络比较动作排序；LP续行的Q^LP单列为教师消融，不用于指认TD估计错误。若MC仍无法区分稳定存在的价值差，则优先否定“只换TD目标就够”的假设、检查表示混叠。若hindsight标签排序在MC下反而更差，停止hindsight蒸馏路线。
- **实现成本**：MC审计中，约1–2天；完整hindsight求解器/交互式聚合与蒸馏中高，约3–7天，取决于现有规划器。共同随机数降低成对差值的方差不保证每个场景都有效。

## 3. CEVD：直接研究估值误差与耦合动作评价，不只加风险摘要

- **标题/年份**：Bose, Varakantham，*Conditional Expectation based Value Decomposition for Scalable On-Demand Ride Pooling*，2021预印本。[官方记录](https://arxiv.org/abs/2112.00579)；[PDF](https://arxiv.org/pdf/2112.00579)；DOI 10.48550/arXiv.2112.00579。`work_6f570f9753f547e3`。本次未核验正式出版版本。
- **已读范围**：完整15页PDF已保存；定向阅读第1、4–8页，涵盖联合价值近似、条件动作概率、§3.3估值偏差和训练方法；第7页公式及Figure 3另渲染核验。
- **具体支持**：论文指出NeurADP忽略其他车辆当前动作造成的价值影响，借条件动作概率反馈修正邻车影响。§3.3以预测价值和实际折扣奖励对比展示估值误差，并增加期望折扣未来需求及正值输出。原文特别区分：NeurADP+改善数值估计，CEVD的耦合评价贡献主要性能提升。故不能仅依据MSE降低认定策略变好。
- **适配改动**：用我方起降、机队、充电的完整未来占用/余量时间剖面、瓶颈时段位置、已承诺订单截止时刻与预计后续需求替换仅靠模板插入统计的状态摘要；候选动作需形成“执行该动作后的联合资源状态”。如真有多机分解，再尝试基于共享时段的动作冲突/条件反馈。未来需求只能来自训练数据预测或已知生成模型的条件期望。
- **不能迁移**：空间近邻聚类、以接客地距离参数化条件概率，并不适合单基地时间容量竞争。SoftPlus仅在价值定义非负时成立；若含违约罚、成本、中心化奖励或机会成本则不可直接使用。论文没有我方联合机会约束保证，也未证明额外特征必然消除所有状态混叠。
- **最小证伪实验**：先找现有特征向量相近但三资源占用剖面不同的状态对；在共同轨迹MC下检验最优动作或动作价值是否明显不同。之后只改变表示，保持训练数据、TD/MC标签及优化预算一致，报告排序准确率、MC动作后悔值与在线收益。若状态对价值无稳定差异或新表示不提升排序，应停止扩大特征维度。
- **实现成本**：资源时间剖面诊断/补足低中，约1–2天；完整CEVD式条件评价中高，约3–5天。先做前者。

## 4. Offline–Online ADP：将当前LP或VFA作为rollout后续策略

- **标题/年份**：Ulmer, Goodson, Mattfeld, Hennig，*Offline–Online Approximate Dynamic Programming for Dynamic Vehicle Routing with Stochastic Requests*，2018在线，Transportation Science 53(1):185–202（2019期次）。[官方出版页](https://pubsonline.informs.org/doi/10.1287/trsc.2017.0767)；DOI 10.1287/trsc.2017.0767。`work_c48477b7fb364264`。
- **已读范围**：Academic Agent书目/摘要 + web打开官方出版页摘要与出版信息；**未取得或阅读全文**。无OA地址，未绕过访问限制。
- **具体支持**：官方摘要明确组合离线VFA与在线rollout，并给出在其条件下的策略改进性质；具体证明前提尚未全文核验。
- **适配改动（我方建议）**：用现有公平LP或冻结VFA作为后续基准策略，在线对少量可行动作作有限情景rollout，保留基准动作在候选集中。先离线审计，再决定是否承担在线延迟。
- **不能迁移**：有限采样、截断时域、候选动作裁剪及我方风险约束均可能破坏原文性质，不能承诺“不差于LP”。
- **最小证伪实验**：同一状态与共同轨迹上比较基准、1步/短时域/全时域rollout的收益与耗时；若可接受时延下收益无稳定改进，停止在线化。
- **实现成本**：已有可克隆仿真器时中，约1–3天；未取得全文前不做“复现原文”表述。

## 最小实施顺序与停止规则

1. 冻结现有早/晚checkpoint、LP、生成器及1%风险筛选器；冻结训练/验证/最终确认集。先检查状态能被精确重建，不启动确认集选超参。
2. 用训练/诊断数据的完整外生轨迹执行上述小规模动作评估。分别报告价值校准、top-1排序、动作后悔值、时延；不要仅看TD loss。
3. 做一个2×2诊断：现有特征/联合时间剖面 × 固定策略TD^π/固定策略MC^π；TD^π的下一动作也由同一冻结π选取，避免把最优性TD与策略评价MC混作同一目标。原有控制型TD保留为独立参考。固定π在该组实验内不随候选训练变化，LP标签另作教师消融。同一状态池、预算和动作集，使“目标问题”和“表示问题”可区分。
4. 只有排序与验证收益均改善，才扩大训练并做至少5个独立训练seed的配对比较。训练seed和场景轨迹分开记录；方差置信区间按独立天/整条轨迹计算，不能把同一天相关订单当独立样本。
5. 联合容量风险判断始终是**全预约集合任一容量约束违反事件**；候选方法不得通过放宽风险门槛换收益。最终收益与违规概率都用未参与选择的独立确认轨迹评估并给不确定区间；当前尚未启用的确认集保持封存直到方法固定。

以上均为下一步实验设计，本次没有运行训练或声称已有改进。
