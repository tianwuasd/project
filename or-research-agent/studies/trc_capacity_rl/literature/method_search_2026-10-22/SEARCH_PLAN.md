# 方法难点的分路线检索计划

日期：2026-10-22。用户要求调用项目内 Academic Agent 的搜索功能，并将找到的文献保存到当前研究项目。本轮是有边界的方法检索与筛选，不是系统综述，也不启动新的训练或确认实验。

## 问题与判断边界

当前风险插入特征 TD 的验证均值为79.99，原资源组合 TD 为80.03，同约束条件 LP 前瞻为82.17。第三轮只有一个训练种子，验证集用于选型。现有证据尚不能区分 TD 自举误差、特征信息损失、模板竞争重复计价或其他训练因素。

待检验的三个机制：

1. 后续价值或候选动作排序失准：寻找可在固定后状态和相同外生样本上诊断或替代 TD 的办法。
2. 资源模板与风险插入特征压缩过强：区分联合概率检查器本身与仅用于学习的并集上界特征，寻找更准确的机会成本表示。
3. 学习策略落后在线 LP：寻找可利用优化方法提供训练信号、再由可实施的滚动策略改进的方法，并检查其是否只是复制教师。

## 工具与分工

- 主检索工具：本机 `testing_tools/academic_agent` 的 Academic Agent 0.4.0，实际调用 `Runner.search`，其搜索原始响应、查询身份、去重书目和来源失败保存在独立项目数据库。
- 跨来源：OpenAlex、Semantic Scholar、Crossref、arXiv；各路线记录实际启用和失败的来源，不能把接口限流视为无相关文献。
- 三个通用研究 agent 各负责一个独立目录；最多约三条主要查询，每来源每查询六条返回，允许为核验具体近邻作少量精确题名补检。扩展与改词应记录理由。
- 补充入口：现有运筹学论文库的关键词检索，及候选论文的出版商、作者或开放预印本页面。补充发现不冒充主检索工具的返回。

## 筛选及保存

纳入优先级：直接解释现有失败机制；可迁移到未知订单下不可撤销接单；保持当前动作的同一可行域及信息条件；能够设计小规模证伪实验。纯静态路径最短化、无方法细节的应用描述或依赖不可用未来信息者降低优先级，并写明原因。

每个重点候选记录：题名、作者、年份、DOI/官方链接、发现路线、读取范围、原文支持的方法机制、迁移条件、反对理由、最小实验与成本。论文发现、全文下载、实际阅读全文、独立复核是不同状态。

开放全文保存在本研究的 `literature/fulltexts/method_search_2026-10-22/`，附来源与 SHA256；不绕过付费墙。暂不可获取者保留书目信息及原因。私人索引、原始搜索数据库和下载全文不自动上传公共 GitHub；公开范围以筛选报告、引用目录和检索覆盖说明为限。

## 完成标准

实际执行三条检索路线，保存来源错误及有效记录；形成少量可追溯候选，优先核验3—5个方法；给出最多三个建议实验及各自能证伪的主张。结果只支持下一步选择，不承诺效果提高，不宣称全球首次，也不将搜索记录数解释为领域覆盖率。
