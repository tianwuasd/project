# 资源互补性的最小反例

用途：为新方法的结构选择提供可检验依据，不作为全球首次的创新主张，也不是新实验结果。

考虑一个确定到达的未来任务，执行需同时占用一个起降位置和一个可用机队位置，收益为R>0，无法执行则选择收益0的后备。令两项剩余容量分别为p,f∈{0,1}，则最优后续价值为：

| p | f | W(p,f) |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 0 | 0 |
| 0 | 1 | 0 |
| 1 | 1 | R |

其混合差分 W(1,1)−W(1,0)−W(0,1)+W(0,0)=R。任意可加分离近似 g(p)+h(f)+b 的同一混合差分为0，因此无法精确表示该价值。

更进一步，若四个角点的近似绝对误差均不超过ε，则由三角不等式，R≤4ε，因此最大角点误差至少R/4。首版网络在固定时间上下文下是这种可加分离形式，增加隐藏层宽度但仍保持分离，不能消除这一表达障碍。

这个反例只说明需要表达互补性，不证明新算法优于价格基线，也不证明实际数据中该障碍一定主导。后续需要：多时段精确小例、同信息训练预算消融、在真正保留数据上的性能检验。候选交互网络或优化定义价值近似还须与已有结构化价值学习文献比较。
