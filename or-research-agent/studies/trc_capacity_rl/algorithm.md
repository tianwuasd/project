# 求解算法入口

完整算法与超参数见 [manuscript.tex](manuscript.tex) 第4–5节；实现为 `src/learning.py` 和 `src/run_experiment.py`。

1. 枚举地面和满足资源预约的候选动作。
2. 用当前节省/20加后决策价值评估动作；单调版本保证固定时间下容量偏导非负。
3. 后决策TD目标从下一订单奖励开始，终止目标为0；用回放缓冲、在线选择/目标网络评价更新。
4. 各参数化训练5种子×400个抽样训练日，只用验证集选检查点。固定后在同17日测试。
5. 同信息基线含贪心、验证调参资源价格、训练日抽样前瞻。知道全天订单的MILP只作为先知比较界。

停止条件是固定训练预算；任何时刻可选地面后备。结果和统计见 `results/experiment.json` 与 `results/summary.json`。单调RL日均69.05，资源价格74.93；尚无优越性证据，不用测试反馈继续调参。
