# 查看分割与决策的详细结果

适用版本：0.19.0。打开服务器面板，按 `o` 选择原任务即可；旧任务不必重跑，原报告和最近任务指针不变。命令入口：

```bash
python3 start_server.py --query results --job-dir /原任务_workflow
python3 start_server.py --query results --job-dir /原任务_workflow --step test
python3 start_server.py --query results --job-dir /原任务_workflow --step evaluate
python3 start_server.py --query results --job-dir /原任务_workflow --step diagnose
python3 start_server.py --query results --job-dir /原任务_workflow --step diagnosis-evaluate
```

## 先看结果来自哪一步

| 菜单功能 | 本栏内容 |
|---|---|
| 4 正式训练 | 训练进度、划分数量、权重位置；训练 loss 不是 Dice |
| 5 测试集预测和评估 | 选定集合的分割预测与 Dice |
| 6 独立预测 | 默认当前缓存全部病例的分割文件，不计算 Dice |
| 7 独立分割评估 | 读取所指定已有预测，与对应真值比较后的指标 |
| 10 训练诊断树 | 各疾病能否训练、样本数、树深度、选模结果 |
| 11 诊断与解释 | 每病例每疾病的实际判断路径与规则证据 |
| 12 诊断评估 | 决策树/规则整体及逐疾病指标 |
| 13/14 合成测试 | 程序生成数据的软件验证，不代表真实 CT 或诊断效果 |

菜单编号不等于输出目录的步骤前缀。例如只选两步时，`02_test` 仍对应菜单 5。查看结果不会重新计算菜单 5/7，也不会把历史单次划分结果变成三折。

## 分割页如何读

结果按“来源 → 整体汇总 → 每折结构分数 → 病例明细”显示：

- 来源包括历史参数中的缓存/真值、模型和预测清单；可读时显示缓存记录数量与原始影像来源目录。缓存包含多少病例，不代表本报告评估了多少病例。
- `cv` 表示开发集的留出折评估。`out_of_fold` 表示每例使用它对应的留出测试折模型；具体以保存的划分记录为准。`threefold_ensemble` 是一次集成结果，不是三个独立折分数。`train/val/test` 是原记录的集合名，不自动证明患者隔离或外部验证。
- 整体平均前景 Dice 是有效病例的前景均值再平均，不对折均值等权平均；七结构不包含背景，当前算法排除 ignore=255。每结构的有效分母仅在完整逐病例字段可用时显示。
- 每折显示病例数、前景均值、LV/RV/LA/RA/MYO/AO/PA 分数和有效病例数，再列病例标识与保存的逐病例指标。缺失折显示未记录，不能据此认定没有运行。
- 汇总字段缺失而明细完整时，从保存的数值补算并标注。已保存摘要和显式空值保留；明细不足不推算完整分母。空值不等于 0，也不证明患者没有该结构。

例如以下为**虚构的界面示例**，不是实验结果：

```text
fold_0：2 例；平均前景 Dice 0.6500
左心室 (LV)：0.7000 | 有效病例 2/2
心肌 (MYO)：0.4000 | 有效病例 1/2
病例名单：example_a、example_b
```

分数通常在预处理网格计算，最终 NIfTI 还原到原图网格；结果页说明实际记录的网格。查询不加载影像/权重，不重新验证摘要或真实患者身份。不能仅因项目通常使用 ImageCHD，就把未知旧结果解释为 97 例或另一个 1282 例队列。

## 决策页如何读

训练栏按疾病列阳性、阴性、未知数量，能否训练及原因，深度与验证选模指标。判断栏按病例分别列决策树和候选规则：

- 每个实际树分支显示特征、观测值、实际比较值、运算符和阈值。观测值与比较值可能因数值精度有细微差别。
- 叶节点显示训练阳性数/总数与比例；这个比例未经临床风险校准。记录明确标为训练先验时会说明；旧报告缺少路径时只显示未记录，不能据此认定树没有分支。
- 缺少必需特征时显示证据不足，不把它视为阴性。规则另列人工证据来源、条件满足/不满足/未知，保存的冲突原因照实展示。
- 结构相邻只是代理特征，不等于已验证的解剖交通；疾病代码沿用标签表，不能把诊断的 PA 与分割肺动脉 PA 混为一类。

诊断评估按方法给整体及每疾病的已知/未知真值数、已判定/弃判数、TP/TN/FP/FN、准确率、敏感度、特异度、精确率、F1、AUROC、覆盖率和全部已知真值中的正确比例。统计单位是患者-疾病对：准确率排除弃判与未知真值，必须配合覆盖率阅读。空白标签按阴性或未知的历史约定会同时显示。

诊断使用自身保存的集合与样本数，不能由上游分割的三折结果推断它也是三折。没有真值的病例可以产生预测和解释，但不能据此产生评估分数。只保留汇总的旧记录无法补出不存在的病例判断路径。
