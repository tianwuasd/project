# 病例证据分级与筛选协议草案

状态：空白研究协议，尚未填入患者资料。用途：使用临床/手术证据确认病型；模型仅使用术前CT。

## 每个病例、每个病型分别填写

| 字段 | 记录规则 |
|---|---|
| 脱敏患者键 / 就诊键 | 身份对应有依据；重复记录归并留痕 |
| CT序列与时间 | 记录选择依据、原始/衍生关系及术前状态 |
| 病型标准名 / 亚型 | 保留多病共存，父子分类不能猜测 |
| 标签 | 明确阳性、明确阴性、未知 |
| 证据层 | A手术证据确认；B专家临床确认；U待定 |
| 证据文书 | 类型、日期、页码/原句，仅在私有资料内保存 |
| 手术事实 | 建议手术/已完成手术分开，核对实际时间 |
| 术中支持范围 | 记录究竟确认了哪一项结构/病型 |
| 阴性依据 | 未提及不是阴性；记录适用的检查和明确排除依据 |
| CT可见性 | 可评价、受限、未覆盖及原因 |
| 审核 | 提取者、复核者、冲突裁定及版本 |
| 划分 | 同患者全部资料遵从同一训练/验证/测试分组 |

## 进入队列的规则

- 诊断主队列使用相应矫治前的CT，避免术后改变成为标签捷径。
- A层可先形成高可信种子；B层用于合理扩展和代表性评价；U层相应病型不计确定监督损失。
- 标签的手术证据必须指向该病型，而非只看是否做过手术。
- 病历/手术资料只用于参考标准与监督，不输入CT模型。
- 最终测试独立裁定，不参考模型结论。
- 病例筛选流程记录纳入、排除、待核及原因，不能只保留好看的结果。

## 先做的可行性审核

建议12–18例覆盖三个来源，每来源约4–6例，检验身份/时间、病型标签、CT质量和CHD字典。此数目仅为规程试行，不用于声明模型性能或正式样本量。
