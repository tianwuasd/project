# 先心诊断与图像特征

本文件是研究任务和标注字典的起点，不是患者个体诊断或完整临床诊疗指南。分型须由具有先心经验的医生结合完整资料确认。下述特征设计是基于所读指南和论文的研究推导，尚未验证其在本队列的可测量性。

## 1. 本质问题：识别结构，还是识别关系

先心病常表现为结构和连接异常，而不只是某片组织的灰度或纹理异常。两个分割结果可以有接近的 Dice，却因为一条细血管接错、一个间隔交通漏掉而支持不同诊断。局部图像纹理、全心分割、疾病诊断是三个不同任务；分割需要服务于后续的关键解剖判断。[本地 Xu 2023 第3–4、6页；Yao 2023 第3、7页]

临床检查宜按顺序确认：内脏及心房位、心室形态、房室连接、心室大动脉连接，再检查静脉回流、间隔、瓣膜、流出道、主动脉弓和冠脉；不能只凭结构位于图像左边或右边给其命名。BSE 的顺序分段分析主要面向成人先心，适合借用解剖推理框架；儿童扫描和定量应采用儿童规范。[BSE 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9578224/)、[ASE 2024](https://www.asecho.org/guideline/comprehensive-pediatric-tte/)

**拟议证据链**：图像质量及切面 → 结构掩码/关键点 → 连接图与形态测量 → 可核实临床概念 → 多标签诊断与不确定性 → 专家复核。每个概念保存支持它的 CT 切片、三维局部或超声片段。

## 2. 分型需要并行的多个轴

| 分类轴 | 用途 | 建模影响 |
|---|---|---|
| 解剖缺陷/连接类型 | 描述缺损在哪里、哪两结构相连 | 采用多标签和关系标签，允许合并畸形 |
| 血流动力学 | 分流、梗阻、混合、容量或压力负荷 | 独立于病名，使用可靠超声/血流资料 |
| 临床复杂程度与治疗状态 | 反映整体管理难度、术前或术后解剖 | 不能从一个病名或一幅掩码直接决定 |
| 发育阶段和体型 | 胎儿、新生儿、儿童、成人的正常参考不同 | 不混用正常阈值；尺寸需体型相关参考 |

“青紫/非青紫”“左右分流”可用于理解生理，但不足以作为全部影像分型标签。疾病共存很常见；不能强制每个患者只能属于一个类别，也不能把并存标签的数量相加当患者数。[本地 ImageCHD 第3–4页；Xu 2023 第3–4页]

## 3. 病型—依据—可观测量

以下是标注内容的概括，不以表内单个征象代替诊断。多切面、完整结构覆盖及参考标准不可省略。

| 病型/组别 | 诊断时要证实的核心关系 | 拟收集的图像概念 | 关键限制 |
|---|---|---|---|
| ASD | 房间隔交通及位置/类型 | 缺损位置、边缘、分流证据、右心负荷 | 声学脱落不等于缺损；PFO 不自动等同 ASD |
| VSD | 室间隔交通及与瓣膜、流出道关系 | 缺损位置、数目、边缘、可重复测得的大小、流束 | 很小缺损可漏检；单纯血池相连可能是分割粘连 |
| AVSD | 房室交界及瓣膜结构异常，结合间隔缺损 | 共同房室交界、瓣叶关系、房/室间隔组成 | 不简化为“ASD+VSD”布尔相加 |
| PDA | 出生后仍有主动脉与肺动脉的导管交通 | 两端连接、通路长度/最窄处、血流方向 | 区分胎儿正常导管、导管依赖循环及治疗后状态 |
| TOF | VSD、主动脉骑跨、右室流出道梗阻及相关右室改变 | 骑跨关系、梗阻层级、肺动脉形态、冠脉伴随异常 | 四个征象不必在单幅图同时清晰；负荷表现随年龄变化 |
| TGA / ccTGA | 心室与大动脉连接；ccTGA 还涉及房室连接不一致 | 形态心室身份、AV/VA 边、动脉相互关系 | 动脉“前后位置交换”不足以定义连接不一致 |
| DORV | 两条大动脉主要起源于形态右室 | 两动脉起源比例、VSD 与动脉关系、流出道梗阻 | 需按同一临床定义标注边界病例，不凭位置单独判型 |
| 共同动脉干、肺动脉闭锁 | 动脉出口构型与肺循环供血途径 | 共同出口、肺动脉起源、连续性、导管/侧支 | 无显影、真闭锁与分割断裂需要区分 |
| CoA / IAA / 弓发育不良 | 弓的狭窄、连续性和各段发育 | 最窄段、近远端参照、长度、分支、侧支 | 形态狭窄不等于压力梯度；局灶与长段分开 |
| TAPVC / PAPVC | 每支肺静脉最终接入哪里，是否全部异常 | 静脉列表、汇合部、引流终点、通路狭窄 | TAPVC 分心上、心内、心下、混合；不要由“未见入左房”直接判阳性 |
| AAOCA | 冠脉异常主动脉起源及近端走行 | 开口窦、开口形态、起始角、近端狭窄、壁内/动脉间走行 | “动脉间”不等于“壁内”；解剖高风险征象不等于已证明缺血 |
| 单心室谱系、异位综合征 | 形态、连接、心室发育和静脉异常的组合 | 优势心室、AV连接、内脏位、系统/肺静脉回流 | 不能只用腔室数判型，也不强迫其符合正常四腔拓扑 |

本表基本病型线索来自本地 ImageCHD、Xu 2023 与 Yao 2023；连接判读采用 BSE 顺序分析。CT 对肺静脉、弓、房室/心室动脉关系的作用参考 [ASCI 儿童心胸 CT 指南](https://kjronline.org/DOIx.php?id=10.3348/kjr.2020.1332)。AAOCA 特征依据 [ASE 冠脉异常多模态指南，第7–9页](https://www.asecho.org/wp-content/uploads/2020/03/ConCoronary_March2020.pdf)。实际标注协议须进一步逐病型核对具体术语和测量方法，不把论文简化表当临床标准。

## 4. CT 与超声的分工

CT 优先提供三维空间、血管起止、走行、狭窄和心外结构；超声优先提供切面下的瓣膜、分流、运动及多普勒信息。增强时相、心动期相、运动伪影、声窗和操作者都会改变可见性。两种模态是对同一解剖/生理状态的不同观测，不是天然逐像素配准的两张图片。[ASE 2024；ASCI 2021]

现有超声混合静态与多帧。只有完整周期且时间轴可信的视频，才支持相应动态特征；只有灰阶或彩色截图，不能直接获得准确流速和压差。CT 单期相也不能直接当作射血分数。检查间隔或手术会让两次影像反映不同状态，必须先判断是否允许融合。

## 5. 首批特征字典

所有特征都附：值、可观测状态、来源、观察时间、单位、测量规程、标注者/版本和原图证据位置。状态至少区分 present、absent、uncertain、not_visible；未知不填成阴性。拟合型处理只在训练折内完成；本轮没有计算任何患者特征。

| 字段 | 定义/获取方式 | 单位与 QC | 缺失和泄漏注意 |
|---|---|---|---|
| image_quality / view | CT 覆盖与伪影；US 切面和类型 | 分类；人工一致性 | 质量和设备可能泄露疾病来源 |
| morphologic_ventricle | 依形态判断左右心室身份 | 分类+支持切面 | 不能以屏幕坐标命名 |
| AV_connections | 心房到心室的连接边 | 离散关系；可多条 | 缺瓣膜显示时记不确定 |
| VA_connections | 心室到主动脉/肺动脉的连接边 | 关系及起源占比 | 分割边界接触不自动等于真实连通 |
| septal_communication | 缺损位置、数目、边界证据 | 分类；大小需尺度可信 | 人工病名不得直接写成图像预测输入 |
| defect_size | 固定相位/平面的缺损径和面积 | mm、mm²；跨读者重复性 | CHD 未知尺度时不输出物理值 |
| aortic_override | 主动脉根部与室间隔/两心室关系 | 比例；固定切面定义 | 阈值按预先协议，不能按测试集调 |
| vessel_centerline | 指定血管起点至终点路径 | 三维坐标及分支 ID | 不跨真闭锁自动补连 |
| lumen_min_area | 中心线正交截面最小管腔面积 | mm²；部分容积与相位 QC | 不拿任意轴位最小像素团替代 |
| narrowing_ratio | 1−A_min/A_reference，参照段预先定义 | 无量纲研究量 | 无量纲也受方向、畸形及插值影响；不是通用诊断阈值 |
| arch_continuity | 弓各段连续性与分支关系 | 图边及人工确认 | 低强化不等于中断 |
| PV_destination | 每支肺静脉最终引流结构 | 类别/关系图 | 漏显示必须区别真缺如 |
| venous_bottleneck | 汇合部/垂直静脉/入口处狭窄证据 | 形态+可用时的血流证据 | 形态与血流证据分列，不互相伪造 |
| coronary_ostium | 起源窦、开口位置和形态 | 分类；局部高分辨率复核 | 全心粗分割通常不够 |
| proximal_CA_course | 近端冠脉与主动脉、肺动脉关系 | 走行类别、关键点 | 壁内需独立证据；不以动脉间替代 |
| takeoff_angle | 开口处冠脉切线与规定参考方向夹角 | 度；固定重建/量法 | 临床阈值另核，不由本表指定 |
| chamber_volume | 掩码体素数×可信体素体积 | mL；相位一致 | 不能跨未知 mm 数据直接比较 |
| body_size_adjusted | 年龄/体表面积参考下的尺寸评价 | 指定参考公式/参考集 | 不混用儿童和成人参考；不以全数据拟合 |
| shunt_direction | 彩色/频谱多普勒支持的分流方向 | 方向及采集条件 | 颜色正负受显示设置影响 |
| peak_velocity | 校准频谱、合适声束方向的速度测量 | m/s；时间/速度标定 | 无频谱或无标定时不从 RGB 猜测 |
| motion_summary | 可靠周期中轮廓/尺寸变化 | 相位归一；重复周期 QC | 多帧可能仅2帧，不保证周期完整 |
| modality_agreement | 对同一个概念两模态是否一致 | 一致/冲突/无法比较 | 同就诊、同手术状态才比较 |
| concept_uncertainty | 标注分歧、模型概率、不可见性 | 三者分别保存 | 模型置信度不当成临床证据强度 |
| intervention_state | 术前、术后及对应解剖改建状态 | 分层/排除条件 | 预测时点后信息只用于参考标准，不能混入输入 |

## 6. 先做哪些标注

共有层：四腔、心肌、主动脉、肺动脉，目标可见时再加肺静脉和腔静脉。任务层：AAOCA 的开口/近端中心线/走行；TAPVC 的肺静脉分支、汇合部、异常引流及狭窄；复杂 CHD 的 AV/VA 连接及间隔交通。US 先标切面和质量，再标相应结构与概念，视频选少数关键帧开展试标。

**参考标准分三种**：结构掩码由专家分割并复核；图像概念由对应可见证据标注；疾病分型由独立临床资料综合裁定。三者不能互相复制。采用理想概念标签测试下游模型可估计上限，但必须另报真实预测概念的结果。
