# 可解释医学模型：我们需要什么

## 可解释性与初始化方式是两个轴

“在基础模型上微调”和“训练自己的可解释模型”并非互斥。前者决定表征从哪里来，后者决定最终判断经过什么证据和计算。可以使用预训练编码器，但让诊断必须通过经验证的解剖概念；也可以从随机初始化训练一个完全不透明的模型。应把初始化、监督方式、结构约束、诊断头和解释评价分别比较，避免把大模型与可解释性直接绑定。

## 六种需要区分的输出

| 层次 | 能回答的问题 | 不能自动证明的事情 |
|---|---|---|
| 显著图 / Grad-CAM | 模型输出对哪些区域敏感 | 区域就是病因；模型理由与医生相同 |
| 分割与几何测量 | 哪个结构、范围和形状支持该观察 | 整个诊断网络真的使用了这些量 |
| 概念瓶颈 | 哪些临床概念参与最终判断 | 概念命名正确、数值不夹带隐含标签信息 |
| 原型/相似病例 | 当前局部与哪些已知模式相像 | 检索到的病例是因果证据；相似性不是设备或文字 |
| 关系图/规则/GAM | 哪些连接和测量组合产生结果 | GNN 或复杂规则天然透明；关系边一定真实 |
| 反事实、校准与转交复核 | 修改哪个模型概念会改变结论；何时证据不足 | 修改人体结构的治疗效果；域外个体必然满足校准保证 |

[概念瓶颈原始论文](https://proceedings.mlr.press/v119/koh20a.html)提供了“先概念、后预测、可干预概念”的方法起点。[Saliency 随机化检验](https://proceedings.neurips.cc/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html)说明只看热图外观不充分。两者都没有替本项目证明临床有效性。

## 从未分类文献得到的具体启发

- **CLEAR**（本地 PDF 1–2 页；[出版社核对](https://www.nature.com/articles/s41551-026-01741-4)）：把影像预测分解到临床观察，并可审核混杂概念。可借鉴“概念及其贡献可追踪”；其验证对象是胸片，不能直接把权重当先心 CT/超声模型。
- **CoPA**（2、7 页）：多层特征与概念提示结合，而不是只读最后一层；支持低成本适配的候选。论文的概念干预不是先心诊断验证。
- **Concept-induced Graph Perception**（3、6 页）：局部概念与概念关系共同参与判断；实验含皮肤和乳腺超声，不是心超。本项目的血管连接图属于物理解剖关系，不能直接等同该文统计概念图。
- **Interactive Medical Image Analysis with Concept-based Similarity Reasoning**（1、5 页）：把概念定位到局部原型，允许审核原型和干预。可借鉴“指出病变在哪里、参照来自哪里”，同时防止用设备、标尺和文字作原型。
- **Counterfactual CBM**（2、6 页）明确把反事实用于模型自身决策，区别于真实因果推断；适合报告“若该连接概念被纠正，模型结论是否改变”。不输出手术疗效推断。
- **Causally Reliable CBM**（2、10 页）强调概念依赖结构；其因果结构和假设必须有依据。现有回顾影像不能靠画 DAG、使用因果损失或让 LLM 给图就获得因果识别。
- **F-Fidelity**（2 页）指出遮挡/删除会制造分布外样本，甚至改变解释排名；本项目需加入匹配随机遮挡、真实人工概念纠正、结构保持扰动，不能只用一次删像素实验。
- **Mechanistic CBM**（2 页）提醒软概念可以夹带超出概念语义的信息；不把“隐层起了临床名字”当解释完成。SAE/自动命名概念可做探索，但须医生验证是否可见和可标注。
- **DeferredSeg**（1、2、4 页）提供把困难区域交给人的研究思路；PDF 页眉卷期为 2027，当前保存版本和在线发表状态未核实，作为方法候选而非已验证的先心临床证据。

## 本项目拟采用的解释契约

每个诊断输出携带：

1. 病型或连接异常的候选及概率，不强迫单标签。
2. 有名字、可定义、可观察的概念值及“不可见/不确定”状态。
3. 每个关键概念对应的图像位置、分割结构、测量方法或超声片段。
4. 决策头实际使用的贡献或规则；如果有隐藏残差分支，单独披露并设无残差对照，不宣称完全概念解释。
5. 模态冲突、结构缺失、可能域外和需人工复核的原因。
6. 专家纠正一个概念后，结论如何变化，以及变化是否符合预定逻辑。

可用的最简结构是 `图像 → 分割/关键点 → 连接与测量概念 → 稀疏线性或加性模型 → 多标签输出`。图像到概念部分仍可能复杂，因此可解释性首先成立在证据与决策层；不能宣称每个神经元都已解释。

## 五个本质检验

**可观测性**：这个概念在当前输入是否能看到？没有频谱就不能要求模型测准流速；没有冠脉分辨率就不要求可靠壁内段判断。先判断观测条件，再决定标签和模型。

**概念充分性**：给模型专家确认的概念，它能否完成目标？若理想概念也无法区分，应补充概念或缩小任务，不继续换编码器。

**误差传递**：分别测试人工概念、人工分割导出概念、模型分割导出概念和直接图像预测。这样可区分缺的是分割精度、连接推断、概念定义还是诊断规则。

**拓扑正确性**：先心本身就可能是异常拓扑。不能把所有病例“修复”成正常心脏。断裂、孔洞、额外连接既可能是算法错误，也可能是真实病变。SDF4CHD 的病型/形状分离以及图匹配工作提示按病型或证据约束，而非固定正常模板。[本地 SDF4CHD 第2、12、15页；Yao 2023 第3、7页]

**目标是否有临床增量**：如果终点由几个定义性概念直接确定，任务价值在于准确、快速地从图像抽取这些概念，并保留复核证据。不能把定义性规则的重现包装成发现新病理机制。若要做预后或治疗决策，需要另建随访终点和研究设计。

## 评价契约

| 目标 | 主要检查 | 对照/失败表现 |
|---|---|---|
| 结构正确 | 逐结构 Dice、边界误差、小结构漏检 | 整心平均好但关键血管漏掉，判失败 |
| 关系正确 | AV/VA、肺静脉、冠脉目标边的漏检/错接 | 固定正常图先验、无图约束对照 |
| 概念正确 | 每概念敏感度、特异度、可见状态识别、连续量误差 | 只报告疾病 AUC 不足 |
| 忠实性 | 概念纠正曲线、模型/标签随机化、匹配扰动 | 热图不变、概念改了预测无合理变化 |
| 语义与防泄漏 | 硬/离散概念对照、无残差模型、随机概念对照 | “命名概念”携带额外隐含诊断信息 |
| 不确定性 | 校准、拒判率与被接受病例错误率、亚组表现 | 以拒绝大多数难例换高准确率却不报覆盖率 |
| 使用价值 | 医生改正时间、重要错误、意见一致性 | 仅主观觉得解释好看 |

共形预测需要独立校准集及适用的交换性等条件；分布变化、少见病或亚组不保证同样覆盖。它补充风险表达，不能替代解释或外部验证。使用 CLAIM/TRIPOD+AI 组织透明报告，不把清单完成当作模型通过临床验证。
