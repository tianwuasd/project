# 纯CT模型中的可靠性：位置、训练目标与验证

日期：2026-10-30。补充第11稿。当前仅为研究设计，尚无训练或可靠性实测结果。

## 可靠性放在哪里

此前纯CT方案已有可见性、质量调整和校准，但可靠性没有被充分写成独立可验证的中间机制。现明确为：

CT → 区域/概念提取 → 证据可靠性评估 → 知识约束诊断 → 校准与选择性输出。

可靠性分支读取可解释的CT质量、覆盖、定位稳定性及概念预测信息；它影响概念进入诊断时的贡献，并向最终输出提供证据不足原因。最终校准负责概率表达，不能替代上游证据正确性。

## 三类量必须分开

- 概念值/概率 c：某个影像征象或连接状态是否存在。
- 诊断重要性 a：该概念对某个病型有多大作用，来自医学先验与受约束学习。
- 证据可靠性 r：在当前图像条件下，这项概念及其支持区域是否值得依赖。

概念为阴性也可以很可靠；概念概率很高也可以是稳定的错误。a、c、r不可互相替代。注意力或特征权重不自动等于r。

## 1. 观测和区域层

先定义明确目标：目标是否被扫描覆盖；当前图像是否足以评价；预测支持区域是否与概念对应。运动影响、增强不足、裁剪漏取与小结构无法分辨属于不同原因，分别记录。

输入信号包括原图/局部质量特征、空间覆盖、预测区域与相邻切面/多平面的一致性等。用少量医生的可见性标签和点/框审核训练或核验。关系概念还要检查多个端点和通路证据；只检查一个点可能漏掉错误连接。

没有精细掩码时，可以验证点/框/通路层面的证据；不能据此声称像素级边界可靠。无参考定位标签时，模型只能输出待验证的候选稳定性分数。

## 2. 概念层：可靠性分数如何训练

首版采用可审核的两阶段流程：

1. 训练CT概念模型，在开发集的患者分组交叉验证中产生折外预测，或在未用于训练概念模型的开发子集上预测。
2. 专家参考标签给出该概念是否预测正确、是否可评价、证据定位是否达到协议要求。不确定参考不强制转成对/错。
3. 用可见性、候选定位质量、概念预测分布、少量独立模型的分歧等信号，拟合简单的错误风险预测器，例如受约束逻辑模型。先限制为有限命名信号，便于审计。
4. 在另外的校准部分或嵌套交叉拟合中检查分数与实际错误的对应，最终在未碰过的测试患者上评价。

“可靠”必须预先定义。二值概念可按预测与参考是否一致；连续量需预先规定可接受误差；关系概念按端点/连接与证据位置正确性裁定。不能把“最终疾病猜对”当作所有中间概念都可靠。

少量标签不足以支持逐概念校准时，可以先使用共享的简单风险模型并分组审查，或只展示可见性、分歧、定位是否核验等分量。此时不能将任意组合分数标成“该特征正确率95%”。

可靠性分支首先根据观测/错误监督训练并冻结，不让诊断损失任意改写它。如果之后联合训练，需与冻结分支对照并重新验证r的含义。否则r可能只是为了分类损失服务的门控。

多个模型一致、扰动后稳定、概率接近1都只是候选信号；模型可能共同犯错，不能把一致性直接当作真值。

## 3. 如何参与诊断

一项拟议实现为：

```text
病型d的得分 = 基础项
            + Σk [可靠性调整(r_k) × 概念对d的有符号贡献(c_k)]
            + 明确列出的必要组合贡献
```

医学重要性包含在概念贡献函数和先验约束中，r负责依据当前观测条件折减。该式是模型设计，不是已验证的临床概率公式；各个可靠性信号也不能未经验证就直接相乘当联合概率。

r低时可减少该证据影响，但有两个附加规则：
- 缺失/不可靠不能直接当作阴性。若某概念是区分病型的关键证据，提示该病型证据不足。
- 不把剩余弱证据简单归一化到更大权重。证据变少时，应允许判断不确定或转交复核。

可靠性也影响诊断的不确定性：将合理的候选概念值/整组预测传入同一决策头，看病型结果是否敏感。可用集成模型产生的整组概念保留部分相关性，不默认所有概念独立随机采样。概念不稳定而结果极确定时，检查决策头是否过度依赖先验或走了捷径。

## 4. 最终输出层

最终分别输出：
- 概念预测及支持区域；
- 观测/定位/概念可靠性的状态或经验证分数；
- 病型校准概率；
- 关键缺证、冲突、可能不适用及需要复核的原因。

先以温度或逻辑校准等简单方法建立概率基线；可靠性图、Brier/NLL和分组校准用于检查。模型没有超出训练分布的万能探测器；分布偏移、罕见病和不同CT协议需单独评价。

选择性输出关注接受病例的错误和覆盖率，不能只用一个概率阈值宣称安全；不同疾病漏诊代价及关键结构错误需在协议中明确。区域、概念和诊断可靠性分别评价，任何一层都不能由最终分类准确率代替。

## 必须做的验证

| 问题 | 对照/指标 |
|---|---|
| r是否有意义 | 用未训练该病例的概念预测产生错误标签，检查r与真实错误的对应及校准 |
| r是否改善诊断 | 同一模型无r、固定质量规则、学习r；控制编码器、患者和标签预算 |
| r是否只是装饰 | 打乱r、遮去部分分量、概念纠正和权重敏感性 |
| 复核是否找对难例 | 同覆盖率比较关键错误，画风险—覆盖曲线，保留全部病例结果 |
| 是否对困难亚组失效 | 不同CT质量、设备/协议、少见形态与病型共存分层 |
| 是否有高置信严重错误 | 单列错接、漏关键结构与漏病，不被平均指标掩盖 |

正式门槛须在查看最终测试结果前设定，依据临床重要错误和区间精度，而非事后挑一个好看阈值。原有少量概念/区域试标只够流程探索，不提供可靠的临床概率保证。

## 直观示例（流程示例，不是真实病例）

某条异常回流路径在CT中部分可见，但引流终点存在明显运动影响：
- 候选概念可提示异常路径；
- 终点对应证据的可靠性应下降，明确标为尚不能确认；
- 依赖终点的细分型输出证据不足；
- 已清楚可见的其他结构仍保留；
- 不能把“看不清终点”解释成“没有异常连接”。

模型应能表达“哪一项不可靠、为何影响这一病型”，而不只是整体显示一个分数。
