# 联合研究的数据与文献核查

本页记录可复用的核查办法。逐文件审计和原始提取记录保存在本地归档。

| 对象 | 入组或使用前需确认的内容 |
|---|---|
| AAOCA 与 TAPVC | 同一患者、同次就诊和相应矫治前 CT 的对应关系。逐病型记录文书证据、支持范围和审核结果。 |
| 诊断表 | 明确阳性、明确阴性和未知分别记录。保留合并畸形。同病型需有合适的同来源对照。 |
| CHD 小集 | 核实数据版本、标签字典、患者重叠和图像与掩码的空间关系。ImageCHD 的诊断资料曾更新，需按对应发布版本核对。 |
| 分割与衍生影像 | 核实每一结构的定义、视野、几何、强度语义和衍生关系。将冠脉开口、肺静脉引流通路等专病结构单列。 |
| 训练与留出 | 先按患者划分，再开展训练及依赖训练集的处理。最终测试患者独立，记录标签证据等级和适用人群。 |
| 文献 | 记录题名、版本、阅读页段、支持的具体结论及适用条件。区分原始论文结果和本项目的拟议实验。 |
