# Independent ImageCHD diagnosis design

Approved scope: independently runnable label import, predicted-mask feature extraction, one interpretable shallow tree per native disease, separate candidate rules, prediction explanations, evaluation and a synthetic demo. Reuse the existing server bootstrap and fixed patient splits; publish code to the existing GitHub project. No implicit segmentation work.

The user's explicit convention is authoritative: blank cells in existing disease columns default to negative. Record each assumed negative, retain the source workbook unchanged, and permit explicit unknown-policy sensitivity analysis. Missing columns and explicit unknown tokens remain unknown. Keep all 16 original disease codes; do not infer ambiguous clinical aliases.

Only predicted seven-label masks produce descriptors. Use 56 grid-normalized presence/shape/fragmentation/contact descriptors with missing values and source hashes. No millimetre or laterality claims. Voxel adjacency is a proxy; independently reviewed, source-attributed clinical evidence is required to populate candidate rule inputs. Unknown rule evidence remains indeterminate. Rules are illustrative, not the authors' complete unpublished system.

Fit one shallow decision tree per disease using known training labels. Require at least two positive and two negative training cases. Fit missing-value medians on that disease's training subset only. Select among depths 2/3/4 bounded by requested max_depth using validation balanced correct fraction with abstentions counted as failures; fixed shallow default if validation lacks both classes. min_leaf is fixed by the user, at least two. Never select on test. Actual deployment paths stop at a missing required feature, returning indeterminate. Explain observed values, actual branches and leaf counts. Positive leaf fraction is uncalibrated; ties at 0.5 predict negative. Stumps must be identified as training priors.

Formal diagnosis training must use the same prepared manifest/patient split as segmentation training. Store development case and patient IDs and reject overlap in test evaluation. New-case inference can use a different prepared manifest with the same segmentation model. Report per-disease/micro metrics, missing truth, abstentions, coverage and all-known-denominator correct fraction. Undefined metrics are null. This learned classifier is a research extension to the paper's anatomical-rule diagnosis, without claims of clinical validation, nested cross-validation or paper-exact performance.

New tasks: diagnosis-labels, diagnosis-features, diagnosis-train, diagnose, diagnosis-evaluate, diagnosis-demo. CPU only; preserve segmentation GPU settings, existing checkpoints and preprocessing caches. Fresh output directories, distinct successful-output settings. No real tables, patient-level data, predictions or weights in GitHub.
