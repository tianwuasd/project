# 续跑校验优化

用户已授权优化续跑／追加步骤前的慢校验，自动选择合适的多线程并显示读取进度。保留原来的全内容 SHA256、历史任务兼容、成功步骤不可重跑和训练调优规则。

设计：将全部成功步骤的快照组成一次校验会话，按规范路径合并文件及预期摘要，冲突立即失败；共享目录合并清单扫描。读取前依据进程 CPU 配额、空闲比例、内存、实际挂载类型及数据量选择有上限的线程池。每文件分块哈希、读取前后检查状态，末尾再次检查目录集合和文件状态，不使用跨会话缓存。每秒心跳覆盖扫描、读取及最终复核，读取量只计唯一文件，ETA 仅指读取阶段。异常或 Ctrl+C 设置取消标志并回收所有读取线程。

验证：重复来源实际读取次数、真实并行与上限、同大小/同 mtime 内容变化、校验期间变化、新旧快照、线程中断清理和进度；既有追加任务/面板/恢复回归；Linux 实际 SIGINT；大 project 独立 48 MiB 合成验收。仅优化恢复入口，未改训练器与步骤结束快照生成。
