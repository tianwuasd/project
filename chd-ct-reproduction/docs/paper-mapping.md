# 原论文方法与当前 ImageCHD 主流程

原文：Xu 等，Medical Image Analysis 90 (2023), 102953，DOI https://doi.org/10.1016/j.media.2023.102953。

论文使用广东省人民医院/广东省心血管病研究所自建3750例回顾性队列，1282例开发、2468例临床测试。开发集具有十结构人工分割；本文完整队列按申请提供。当前本机110例ImageCHD不能代替它，二者是否存在病例重叠未从原文确认。

| 组成 | 当前主流程 | 差异与边界 |
|---|---|---|
| 两路全图3D网络 | crop64 / crop128 | 8类含背景；保留空间概率门控实现 |
| 两路区域3D网络 | all64 / all128 | 训练真值ROI；预测由crop结果确定ROI |
| 两路初始血管网络 | 停用并记录 unavailable | 没有对应初始血管标注；不将整段AO/PA伪造成初始段 |
| 2D血池网络 | blood2d | 三类；血池由现有标注派生，未知区域及邻域忽略 |
| 冻结特征 + 双向ConvLSTM | blood_lstm | 七切片序列、两层循环网络，编码器随权重保存 |
| 多尺度融合 | 四路1:1:2:2投票 | 原六路中的init两路缺失；不声称与论文融合完全一致 |
| 血池边界细化 | 六邻域区域扩张 | 复用既有实现；边界宽度等仍为工程假设 |
| 解剖图优化、临床诊断规则 | 旧实现保存在back；主流程不输出诊断 | 缺PV/SVC/IVC、初始血管、可验证物理尺度和已验证规则 |
| 加权Dice + CE | 实现，255不参与任何一项损失 | 适配七结构；血池权重沿用1/2/16 |
| 学习率分段 | 初始lr、0.1lr、0.01lr，50%/25%/25% | 复用已有训练策略 |
| 数据增强 | 复用旋转/缩放/形变，序列一致翻转 | 具体幅度为既有工程选择 |
| 网络规模 | 默认单卡实用配置；另有paper-scale | 默认base/深度和血池尺寸更小；paper-scale也不保证逐层参数精确一致 |
| 数据划分 | 固定train/val/test，支持显式患者CSV | 默认文件名患者假设；未完成论文三折和独立临床队列评价 |
| 评估 | 分割Dice，单独执行 | 缩小缓存的分数对应缩小网格；不输出未经校准的毫米指标 |

因此当前交付是**可运行的多阶段方法适配和研究实验主路径**，不是论文3750例队列、全部八阶段或临床准确率的完整再现。已知的原文矛盾和旧实现细节可查 back/paper-v1/docs/paper-mapping.md。
