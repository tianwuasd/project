## 论文没有给全的细节

以下为公开记录的实现选择，不应视为已从论文证实的原作者设置：

- 表 3 输入输出空间尺寸一致，因此使用 padding=1 的同尺寸卷积。每次上采样通道减半后与对应编码特征拼接；图中未把所有中间通道逐一标注。奇数网格的镜像扩展/中心裁剪属于工程适配。
- InstanceNorm 使用 affine=True、默认逐实例统计，LeakyReLU 斜率 0.01；卷积 bias 与初始化沿用 PyTorch 默认。论文未列出这些值。
- 位置分支输入为 U-Net softmax 概率，输出经 sigmoid 后作为先验。对数域相加等价于概率逐点乘积再归一化；论文未指定这些概率激活。
- Dice 按类别加权后除以权重和，与 CE 等系数相加。原文给出的是 weighted Dice 类别权重，没有明确要求 CE 复用这些权重，因此本次移除了 CE 的重复类别加权。
- BiConvLSTM 保留 3×3 门控卷积、每方向 32 隐藏通道、方向拼接、中心切片监督。图 4 显示时序输出，而表 3 给出单张输出；方向合并、卷积核与监督聚合未写清，不能据图确认其具体循环实现。
- 增强幅度仍为工程设置：轴向旋转 ±15°，3D 各轴同倍缩放 0.9–1.1，4³ 低分辨率随机位移插值至输入网格、标准差 0.015，2D 水平翻转概率 0.5。新露出的无标注边缘记为 255。未验证与 Seg-CNN 的完整增强配置相同。
- Adam、ROI 边距、百分位强度归一化、血池边界宽度继续沿用工程设置；Excel 间距重采样是用户指定的数据准备规则，不能归为已证实的论文预处理。
- 论文未给出具体患者名单、分折随机种子、取整方式或三模型集成公式。本项目固定种子、患者分组，验证数为 `max(1, round(开发患者数 × 0.1))`；独立患者逐阶段平均类别概率后取最大类。三折顺序执行，折内沿用独立阶段多 GPU 调度。OOF 评分不使用见过该患者的模型。

## 参数量核对

以当前 ImageCHD 输出类别和默认位置分支计算可训练参数，使用 meta 张量验证完整规模的输出尺寸：

| 网络 | 当前参数数目 | 论文报告 |
|---|---:|---:|
| 3D，base64 | 90,447,656 | 84.9 M |
| 3D，base48 | 50,943,176 | 51.2 M |
| 2D | 497,780,707 | 452.9 M |
| 两层 BiConvLSTM | 369,347 | 0.2 M |

**参数总量尚不一致。** 输出类数不同仅能解释部分差异，不能解释二维和循环网络的全部差距。当前对齐的是论文明确写出的结构和超参数；不声称已获得原作者网络的逐层一致性，需原作者源码/补充结构说明才能进一步核实。没有为了凑参数数目擅自删层或缩减通道。

正文第 4.2 节把 64/48 写作 batch sizes，但图 4 和表 3 明确它们是 initial channels，实际 batch 为 4，当前以表和图为准。图中输出 7/10、图注 7/11、表 3 的 init 输出 11 也有不一致；当前始终按现有标注使用背景加七结构。

## 训练内存适配

正式配置默认开启 `activation_checkpoint: true`，使用非重入激活重算，只在训练且启用梯度时作用于编码/解码块及位置关联分支。保持实际 batch4，不改成 microbatch，因此 Dice 的批次聚合也不变。缩小二维/三维模型已验证开启前后的输出、损失和全部参数梯度一致。这是工程内存优化，不是论文声明的训练技巧。

在 meta 张量上按唯一底层存储统计，默认 batch4 前向为反向保存的张量：

| 网络 | 关闭重算 | 开启重算 |
|---|---:|---:|
| 3D base64 / 64³ | 5.271 GiB | 1.510 GiB |
| 3D base48 / 128³ | 30.105 GiB | 9.015 GiB |
| 2D base32 / 512² | 5.524 GiB | 1.350 GiB |

这不是峰值显存：还需计入未包含的常驻参数、梯度、Adam 状态、重算临时张量及卷积工作空间。实际 GPU 是否能完成完整规模训练，仍以 CUDA preflight 为准；没有把这个统计当成 3090 可运行保证。

## 数据和流程仍有的边界

| 模块 | 当前流程 | 与完整论文的差异 |
|---|---|---|
| 全图和 ROI 分割 | crop64/crop128/all64/all128 | 标签只有 LV/RV/LA/RA/MYO/AO/PA |
| 初始血管两路网络 | unavailable，未运行 | 缺少 initial-vessel 标注；不以整段 AO/PA 伪造 |
| 血池 | 四心腔 + AO + PA，排除 MYO | 论文还有 PV/SVC/IVC |
| ROI 融合 | 两路前景并集，无前景时用全图 | 两路多数投票平票规则原文未说明 |
| 多尺度投票 | 四路权重 1:1:2:2 | 原文六路 1:1:2:2:2:2，缺少 init 两路 |
| 血池细化 | 六邻域种子区域扩张 | 边界及平票细节为工程选择；未实现完整小岛重分配和 AO/PA 图优化 |
| 数据划分 | 已实现三折约 56.7/10/33.3 和每阶段三模型集成；显式 CSV 的原 test 默认保留为外部集 | 当前患者队列与论文不同；分折名单和集成公式为公开工程选择 |
| 临床诊断 | 独立七结构描述、候选规则和浅树研究扩展 | 缺少原论文全部结构、初始段及经验证的规则；不能再现其临床准确率 |

论文使用 3750 例自建队列（1282 开发、2468 临床测试），当前使用 110 例 ImageCHD，其中 97 例满足七结构标注要求，13 例缺少 MYO 标注。二者病例重叠未知。本次只验证缩小网络三折软件流程，没有重新做全量预处理、正式训练或临床评价。

每折模型版本为 `imagechd7-chd-paper-v3`，根三折集合版本为 `imagechd7-threefold-v1`。同主干的独立六阶段模型仍可读取；旧主干模型与不一致的续训契约会被拒绝。三折训练须另建输出目录。Excel 重采样、旧缓存读取、原始网格恢复与服务器流程继续使用。
