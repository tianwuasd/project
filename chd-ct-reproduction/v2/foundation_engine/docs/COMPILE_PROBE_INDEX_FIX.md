# 编译预检抽样索引修复（0.6.2，2026-10-30）

## 原因与修复

服务器容量短测在 epoch 0 开始时触发 CUDA IndexKernel 的 index out of bounds，rank 0 最终以 SIGABRT/-6 退出。CUDA 异步错误在清理输入缓冲时再次暴露，因此清理栈不代表最初的越界位置。

0.6.1 的网络编译兼容性探针用默认浮点 `torch.linspace(0, numel-1, ...).long()` 选取最多1024个输出位置。在本次输出形状 `(2, 8, 128, 224, 192)` 下，元素数为88080384，合法末尾为88080383；float32将末尾舍入为88080384，构成越界。相同尺寸CPU回归在旧实现上实际复现该 IndexError。

`training_execution._projection_indices` 改用显式int64网格及整数商/余数计算，包含首尾位置，避免浮点端点舍入。每输出最多1024项的均值投影、完整输出与梯度有限性/误差比较、RNG和缓冲恢复、实际训练loss及训练预算保持原有合同。没有通过关闭编译或忽略越界来绕过问题。
