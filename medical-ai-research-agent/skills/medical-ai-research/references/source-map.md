# 方法来源与复用

本项目依据个人academic技能库重新编写医疗研究契约，未整体复制上游代码或自动研究循环。

| 方法资料 | 采用内容 |
|---|---|
| AI-Research-SKILLs / brainstorming-research-ideas | 问题驱动选题、反例与可证伪假设 |
| AI-Research-SKILLs / autoresearch | 假设—实验—综合、持久研究状态，不继承无限后台循环 |
| AI-Research-SKILLs / ml-paper-writing | 贡献与实验对应、引用核实、结果驱动写作 |
| scientific-agent-skills / scikit-learn | 特征变换、pipeline与基线 |
| scientific-agent-skills / experimental-design | 统计单位、重复测量与分组设计 |
| academic-research-skills-codex / academic-research-suite | 文献、实验、写作分阶段管理 |

有这些技能时只读当前阶段需要的入口；没有时使用本项目流程。框架与API细节按需核对官方文档。不把上游历史文档的版本描述当作当前已验证事实。

相关资料：[AI-Research-SKILLs](https://github.com/Orchestra-Research/AI-Research-SKILLs)、[scikit-learn](https://scikit-learn.org/stable/)、[TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378)、[CLAIM 2024](https://pubs.rsna.org/doi/10.1148/ryai.240300)。
