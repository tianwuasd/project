# 从文献到研究问题

## 1. 证据先行

第一次记录主题、任务、数据模态、临床使用者和决策时点。检索原始库，用近义词补充英文词；记录查询、时间、文档版本 ID。检索按词汇匹配，不是语义搜索；零命中后试英文、任务与方法名，不能直接宣告研究空白。

每篇相关论文提取：研究对象/队列、样本单位、数据集、任务和标签、输入及可用时点、方法、特征/表征、训练划分、预处理拟合范围、基线、指标、是否有外部测试、可复现条件、局限。没有读到的填 `not_verified`。原文、摘要、作者自述、笔记和本 agent 推断分列。

证据条目格式：`claim_id, claim, claim_type, document_id, sha256, page, section, excerpt, reading_scope, support_status`。短摘录用于定位，长原文保留本地页片段，不将全文粘进研究报告。原文表格/公式需要精确解释时渲染该页目视核查。

## 2. 找场景

通常给 3 个可区分候选，已有明确课题时围绕该课题补最近邻比较即可。每张卡包含：

| 字段 | 内容 |
|---|---|
| 临床/研究场景 | 谁在什么时点用输出解决什么问题；误差的实际后果 |
| 任务 | 人群、输入、预测单位、输出、目标域、排除条件 |
| 证据 | 2–4 个最相关来源及读取范围；没有足够来源则标明 |
| 最近邻差异 | 相同点、确切改变、为什么值得做、最可能否定该想法的已有工作 |
| 假设 | 可证伪的定性/定量预测、主评价指标、失败判据 |
| 数据条件 | 现有/待申请/尚未确认；患者数、事件数、标注与算力缺口 |
| 最小实验 | 最便宜的检验、简单基线、继续/停止条件 |

按临床相关性、证据支撑、数据可得性、可检验性、工作量、增量贡献分别作 0–2 的粗评分，每格附理由；评分是主观排序，不是成功概率。关键数据缺失可先降为候选，不补造条件。先复现最近邻强基线，再谈新模块优势。

## 3. 场景—特征—实验一致性

每项拟议贡献都要连接一个特征或算法改变和一个区分性实验。例如“缺失模态鲁棒”必须测试真实缺失与模拟缺失、不同缺失模式、完整病例偏差；仅提高总体 Dice 不足。“解释性改善”需要概念标注、忠实性或随机化检验，热力图好看不构成证明。

研究结论按三类写：原文支持的事实；本次实际计算支持的事实；待验证假设。失败与无效结果保留，计划内容不进入论文结果段。

## 4. 接续契约

state.json 保存 topic、mode、stage、status、artifacts、decisions、gaps、next_action。状态建议：planned、running、completed、failed、awaiting_data。每阶段更新研究包与状态；完成方案和完成实验是两个里程碑。新数据或协议修改后建立新实验目录并记录父版本。
