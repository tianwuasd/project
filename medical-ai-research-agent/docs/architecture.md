# 实现结构

首版目标：用现有学术技能方法与本地论文，生成医疗AI的场景、特征工程、算法实验研究包。

| 模块 | 文件 | 职责 |
|---|---|---|
| 技能入口 | skills/medical-ai-research/SKILL.md | 选择场景、特征、实验或恢复模式 |
| 文献索引 | scripts/corpus.py（技能内） | 只读原件、SHA256文档版本、SQLite页片段、检索与定位 |
| 研究工作区 | scripts/new_study.py | 模板、文献/特征/实验目录和state.json |
| 基线与消融 | scripts/experiment.py | 显式数值特征、患者隔离、验证选参、测试与溯源 |
| 工程演示 | scripts/make_demo.py | 完全合成数据，无患者信息 |

研究流程：检索原文证据 → 比较候选场景与最近邻 → 明确可证伪假设 → 特征来源/时点/拟合范围 → 冻结划分和实验矩阵 → 基线与消融 → 实际结果/负结果 → 保存状态。

初始实现顺序：证据数据库与定位测试、三阶段技能与模板、受控实验与泄漏测试、独立行为试用和代码审查、回归修复、安装与发布。可选后续扩展包括三维分割项目接入、其他AI任务与新文献源；不是首版已执行功能。

原始论文、真实研究数据与来源配置保留本地。公开仓库提供通用配置示例和合成运行记录。不会自动建立后台研究循环、下载模型或发起真实医疗训练。
