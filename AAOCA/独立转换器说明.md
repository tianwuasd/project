# CT 与超声独立转换器

## 两个独立入口

| 脚本 | 输入 | 输出 |
|---|---|---|
| `convert_ct.py` | 一个或多个目录中的常规 CT 切片 | 每个完整序列一个三维 `image.nii.gz`，以及参数、来源和预览 |
| `convert_us.py` | 一个或多个目录中的 US 文件 | 静态图 `image.png`；视频 `frames.npz`；另附时间、尺度和预览 |

脚本递归寻找后缀 `.dcm`（不区分大小写），自动过滤影像类型。目录中 CT 和超声混在一起也可以，但它们会被各自脚本分开处理。无后缀 DICOM 当前不扫描。**输出目录必须不存在，而且必须位于输入目录之外**；不能覆盖已有转换结果。

## 独立转换器运行示例

先按 README 安装依赖。下列路径和患者编号均为虚构示例，请换成自己的路径。PowerShell 中进入本目录：

```powershell
Set-Location -LiteralPath 'D:/project/AAOCA'
```

转换一个样本中的 CT：

```powershell
& './.venv/Scripts/python.exe' './convert_ct.py' --input 'D:/AAOCA_input/000456' --output 'D:/AAOCA_results/ct_run_01'
```

转换两个样本中的超声：

```powershell
& './.venv/Scripts/python.exe' './convert_us.py' --input 'D:/AAOCA_input/000123' 'D:/AAOCA_input/000456' --output 'D:/AAOCA_results/us_run_01'
```

再次运行需更换输出目录，例如 `ct_run_02`。换电脑后先创建环境并安装 `requirements.txt`；压缩 DICOM 若缺少解码器，脚本会报告失败，需要另外安装对应 pydicom 像素解码插件。测试使用临时生成的未压缩模拟影像。

## 怎样看结果

输出根目录中的 **`manifest.json` 是结果清单**：列出成功/失败项目、源文件及失败原因。文件夹使用检查/序列标识的摘要命名；可通过清单找到原来的文件。

每个成功 CT 序列：

```text
study_.../series_.../
  image.nii.gz      三维 CT，float32 HU 数值，毫米空间坐标
  metadata.json     原始文件顺序、校验值、空间矩阵、缩放参数
  preview.png       三张切片预览，仅供快速检查
```

每个成功超声文件：

```text
study_.../item_.../
  image.png        静态图（无损保留像素数值）
  或 frames.npz    视频的全部帧（无损压缩，不改变播放时间）
  metadata.json    帧时间、成像方式、物理标定、压缩历史和来源
  preview.png      静态图或视频中间帧的缩略图
```

静态图若为 PNG 无法无损保存的类型，例如有符号灰度，也使用 `frames.npz`，保留长度为 1 的时间维。多帧对象即使只有一帧，也保持这一形式。

NPZ 是数值数据包，不是可双击播放的 MP4。Python 读取方法：

```python
import numpy as np
with np.load('实际输出路径/frames.npz', allow_pickle=False) as data:
    frames = data['frames']             # 灰度 T×H×W，彩色 T×H×W×3
    timestamps = data['timestamps_ms']  # 从第一帧起算的毫秒时间
```

不知道采集时间时，`timestamps_ms` 是空数组，metadata 中为 unknown，不臆造帧率。`FrameTimeVector` 和 `FrameTime` 优先，只有 CineRate 时记录为名义时间；建议播放帧率不冒充真实采集时间。FrameDelay 单独保存，可据此恢复与 ContentTime 的相对偏移。无时间重采样，不截取单个心动周期。

## 关键检查规则

- CT 按真实空间位置排序，不按文件名；保持不同检查/序列分开。
- CT 保留空间方向（DICOM LPS 转 NIfTI RAS）和实际层间隔；不把层厚当层间距，不改变像素间距。
- 常量倾斜位移保存在 NIfTI 的 sform 中；方向不一致、重复位置、异常间距、混合期相标记拒绝。
- CT 缺失/空像素时整序列失败，不会删除坏片后把其余切片假装连续地拼起来。
- 有无法读取的 DICOM 文件头时，由于不能可靠判断属于哪个序列，CT 本次运行全部阻断；应先修复文件或明确缩小输入目录。明确的 SpacingBetweenSlices 与真实位置间隔不符也会拒绝。
- 序列均匀不等于导出完整：连续末端缺失或等间隔抽片无法仅凭现有文件可靠判断。仍需核对扫描覆盖范围。
- CT 只支持常规单帧 CT Image Storage；增强多帧 CT、定位图等不能满足三维几何要求的输入明确报告，不猜测空间信息。
- CT 根据 DICOM slope/intercept 转成 HU，验证转成 float32 后误差不超过 0.001 HU；不进行窗截断、降噪或图像增强。
- 超声 RGB/灰度数值保留；YBR 自动转换 RGB，调色板颜色显式展开并记录。MONOCHROME1 数值不反转，仅预览反转显示。
- 超声保留区域标定及其单位，不能把频谱图上的时间/速度刻度当作组织的毫米尺度。
- 每份输出写回后重新读取，与内存中的数值及几何/时间比较。源文件和输出均记录 SHA256。

**转换不等于脱敏。**像素中原有的姓名、编号、测量文字、彩色叠加均保留；清单包含本地源路径，也可能含可识别编号。不要把输出当作可直接公开的数据。元数据仅摘录处理所需字段，不导出姓名、出生日期等字段；如需正式共享，另做像素文字和路径等信息的去标识处理。

**转换不等于有了标注。**CT 的 `image.nii.gz` 可供下一步分割使用，本步骤不会生成空白或虚构的 `label.nii.gz`。
