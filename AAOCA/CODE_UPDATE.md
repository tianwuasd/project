# 仅更新 AAOCA 代码

`update_aaoca_code.py` 为独立标准库程序，需要 Python 3.10+ 和已有 Git，不安装依赖、不运行分割。采用 v2 的 blob:none 提交/目录元信息、精确文件清单、显式代码 blob 下载、禁隐式联网的本地读取和先验证后应用顺序。目标是已有的 AAOCA 代码目录，运行目录通过 --work-root 指定在源码之外。

```bash
python3 update_aaoca_code.py --target /srv/project/AAOCA --work-root /srv/private/results --mirror gh-proxy
```

默认通过用户选择的公开仓库镜像读取 main，确认 Git 服务支持对象过滤，浅层获取 blob:none 元信息后仅枚举 AAOCA 子树。完整提交 SHA 可通过 --commit 指定。--mirror official 显式选择 GitHub 官方 HTTPS；程序沿用当前进程的代理环境，不切换线路，不修改全局 Git、代理或 shell 设置。临时 Git 子进程屏蔽全局 URL 重写和认证头。公共镜像仅用于本公开代码仓库，不发送认证信息，不依赖公共镜像的 GitHub API 配额。

只下载 AAOCA 普通源码文件；不获取其他项目内容、仓库完整归档、历史 blob、模型或环境。临时对象库存若出现 AAOCA 清单之外的 blob 会拒绝应用。下载后的每个文件最多512 KiB，源码总量最多8 MiB、文件数最多512，对象分批下载、本地四路读取、总时限900秒。每份内容核对 Git blob SHA1 与长度，所有 Python 文件编译检查而不执行。

全部文件核验后，先在目标磁盘准备所有候选代码，再将原文件同盘改名备份并逐文件原子替换。应用过程中出现错误则通过改名恢复本次已修改文件，恢复无需再分配旧代码内容的空间。完成提交后删除自有备份。更新过程中请勿启动新的前台源码操作；旧冻结分割任务保持原代码。更新后从原入口新建或接续任务，新版不会热改旧任务。

来源回执为代码目录中的 `.aaoca-code-receipt.json`，记录版本与受管理代码清单，供下一次更新识别退役源码。仅删除旧回执明确管理且当前内容仍匹配旧哈希的退役文件；未知本地文件、用户资料、模型、环境、结果和 Git 元信息保留。本地修改过的退役文件会阻止更新并给出具体路径。

临时下载目录为 work-root 下随机且独占的 `.aaoca-code-update-*`，普通完成、失败或可处理的中断都会清理。代码文件旁的原子写入临时文件也在完成或失败时删除。代码目录中的 `.aaoca-code-update.lock` 在退出时删除；未知的既存锁不会被自动删除。

此前使用 curl 管道连接 tar 时，压缩归档没有保存到磁盘；中断解压已写入的 AAOCA 源文件由本次完整清单覆盖并逐文件核验。程序不会通配删除来源不明的压缩包或目录。SIGKILL、断电及介质损坏可能中断清理，此时需要核实残留归属后处理。

更新不合并父项目的 Git 工作树，其他子项目保持原状。服务器实际线路、文件权限与运行状态仍以现场输出为准。
