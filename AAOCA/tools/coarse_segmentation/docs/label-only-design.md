# 原始 CT 到医生可编辑标签

采用已确认的三个 TotalSegmentator 2.18.0 任务：total、heartchambers_highres、coronary_arteries。输入为有 HU/mm 来源依据的原始三维 NIfTI。外部不重采样、不保存归一化 CT，模型内部按其原有要求处理。输出严格保持输入网格。

医生使用原始 CT 和 aaoca_11.seg.nrrd。每个结构独立命名和着色，重叠区域完整保留。采用 pynrrd 保存标准 NRRD 和 Slicer 分割元数据；不依赖运行中的 Slicer，不引入交互模型。

新增任务采用该方式。已有冻结任务、显式旧预处理来源及旧格式结果按原合同读取。命令行 run 与终端新任务使用相同推理、导出和完整性校验函数。

三个模型的二值掩膜仅用于推理检查点和最终导出。最终文件原子发布、全体素回读和输入哈希校验完成后，删除已验证的本任务掩膜；仅保留最终标签及小型私人状态、质检和日志。完整结果续跑不再依赖已清理的掩膜；最终文件损坏时明确报错，要求重新推理。禁止删除外部来源任务的文件。

公开提交仅包含程序、几何测试和通用说明，不包含真实输入清单、路径、病例编号、影像、分割结果、许可、权重或私人验收记录。
