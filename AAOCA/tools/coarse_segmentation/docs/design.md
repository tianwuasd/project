# AAOCA 粗分割与独立服务器面板

日期：2026-10-23。范围依据：生成针对 AAOCA 的粗分割项目，代码放入现有 AAOCA 项目，上传 project 仓库，并提供独立的服务器操作面板。

## 数据流

已确认 HU 和毫米几何的原分辨率三维 NIfTI → 输入预检 → TotalSegmentator 2.18.0 三个任务 → 二值掩膜几何核验 → 11 类合并标签及 QC → 3D Slicer 人工复核。项目不重新训练，不提前重采样，不自动判断 AAOCA 疾病或分支名称。

- `heartchambers_highres`：LV、RV、LA、RA、心肌、主动脉、肺动脉。
- `total` 的 ROI 子集：肺静脉、上腔静脉、下腔静脉。
- `coronary_arteries`：冠脉整体。
- 固定标签 1–11 按上述顺序；0 为背景。冠脉合并优先级最高，其次心腔/心肌/动脉，再次静脉。重叠只用于决定合并图，不修改原始二值输出；记录全部重叠和空掩膜。

## 接口及保全

命令行提供 `inventory`（从研究清单筛选 AAOCA）、`plan`（只读预检）、`run`（实际推理）、`panel`（服务器面板）、`doctor`（环境信息）。CSV 仅含研究代号、影像路径及 HU/间距确认字段。研究清单导出不带姓名、原身份字段；CSV、日志、输出仍属于私人数据。

逐例独立执行，结果写入新的 attempt 目录；只在所有模型、几何核验、文件哈希通过后标记完成。复用检查源码版本、输入内容、推理设置、依赖版本及每个产物哈希。失败保留现场，不覆写既有成功结果。每个输出根目录只有一个运行锁。退出或停止清理本进程的锁，异常断电留下的锁不自动删除。

## 服务器面板

独立标准库 HTTP 服务，默认且仅绑定 127.0.0.1，经 SSH 隧道访问。随机访问令牌保护所有 API，不在公开地址提供服务。不提供任意 shell 或任意文件读取接口。启动时固定清单和输出位置；面板可选病例、预检、运行、停止本面板创建的进程、查看状态和日志、读取 GPU 信息。保留继承的 CUDA_VISIBLE_DEVICES，设备参数仅在可见范围内选择。Linux 用独立进程组停止本面板任务；停止后可重新提交，已校验完成病例复用。

本地 Windows 可预检、测试和打开面板；生产目标为 Linux GPU 服务器。页面只显示完成病例数和阶段，不编造模型内进度或预计时间。服务不安装依赖、不启动训练、不上传影像。

## 验收

使用合成非对称体积覆盖：未知间距/不一致空间头拒绝、掩膜几何不一致拒绝、标签重叠策略、失败隔离、损坏产物不复用、输入变化不复用、命令参数含空格、锁、面板鉴权/选择/停止范围。真实模型质量需在配置许可的服务器上另做小样本检查，单元测试不替代模型验证。
