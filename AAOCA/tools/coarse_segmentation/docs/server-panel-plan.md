# 服务器一体化面板升级

需求：在同一个独立面板完成环境适配、许可、输入配置、预检、粗分割和日志；SSH / 浏览器断开后继续运行，重连可接续查看与停止。

实现路径：保留现有模型管线与旧 CLI，在其外增加仅依赖 Python 标准库的启动器。面板进程、安装/检查/推理任务分别脱离终端；状态持久化到外部私有工作目录。操作只调用固定 Python 入口，不接收 shell 命令。安装使用专用 venv，保留服务器已有 CUDA 可见范围，不修改驱动或现有训练环境。

文件与验证：

- [x] `aaoca_seg/service_state.py`：原子私有记录、系统进程身份、跨进程锁、后台子进程；测试 PID 重用、并发启动和父进程退出。
- [x] `aaoca_seg/server.py`、`server.py`：无第三方依赖启动、私有配置导入、后台服务、状态重连；测试冷启动、重复启动、API 令牌。
- [x] `aaoca_seg/operations.py`：固定安装/环境探测/许可任务，独立 venv 与缓存，凭据不进入参数/日志/状态；测试驱动选择、失败状态、敏感信息屏蔽。
- [x] `aaoca_seg/managed.py`：设置、CSV 导入、持久任务、独立 worker 与恢复；测试冻结配置、任务互斥、重建控制器后查询/停止。
- [x] `panel.py` 与 `web/`：统一环境、许可、路径、GPU 选择及现有病例操作；浏览器检查可用性与错误提示。
- [x] 文档、全部合成测试、发布差异检查，推送到既有 GitHub AAOCA 路径。

恢复边界：断开客户端不影响后台进程；机器重启、管理员结束进程或系统清理用户会话会中断任务。已完成病例经哈希核验复用，未完成体积重新计算，不承诺模型内部断点。原运行锁不自动清除，异常子进程需先核查。首次安装和模型下载依赖服务器网络，客户端断线不等同于服务器离线。

重点检查：无依赖也能打开面板；安装与运行不能重叠；重连不得修改活动任务的路径/设备；CPU 模式不要求 GPU 授权；GPU 选择只在继承可见范围内，执行前重新探测；许可不可出现在公开代码、API 返回、进程参数或日志。
