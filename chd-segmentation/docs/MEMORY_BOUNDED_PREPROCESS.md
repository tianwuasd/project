# STU-Net 分块预处理与内存保护

冻结目标间距、训练统计、归一化、数据划分、全局 batch 与 patch 均由原配置和计划决定。`preprocessing.block_threshold_bytes` 默认 100,000,000,000 字节（100 GB 十进制），日志会指出旧整例估算是否超过阈值；所有大小病例均进入受控分块流程。

`preprocessing.block_bytes` 默认为 64 MiB，控制每次读取、归一化、插值坐标、标签分数和写盘的工作块。正式 gzip NIfTI 在目标 data 的病例 `.pending/work` 中顺序解压，使用 Nibabel 解析；技术 ROI 通过 Nibabel 有界切片读取。原件只读。非零区域采用六邻域外部背景连通传播，孔洞填充完成后再裁剪。CT 归一化先于插值；三次样条预滤波沿每条完整轴线执行，分块仅切其他轴；全局半像素坐标与 nearest 边界延拓保留。各向异性分轴路径保留二维插值和轴向插值步骤。标签采用当前 batchgenerators 的类别分数与最近邻精确并列规则。

中间数组映射到 data 的自有病例工作目录，每次处理后 flush 并释放可回收映射页；输出按块写入、读回并计算完整 SHA256，完成后原子提交病例目录。正式完整病例继续核验和复用，未完成病例重新构建；不删除其他配方或原始数据。输出 dtype、几何和病例内容摘要协议保持既有格式；新实现的数值比较范围以验收报告为准，尚未运行过的正式尺寸不能宣称已验收。

公共 `MemoryGuard` 每秒读取物理内存及可见 cgroup/Windows 当前 Job 限制，按各限制分别计算 80% 目标；`resources.ram_fraction` 可以进一步收紧。项目已登记全部任务的实际 PSS（不可得时为保守 RSS）及未兑现承诺合计受 `memory_limit_bytes` 约束，默认且最多 100,000,000,000 字节。共享登记使用同一 `work_root/resources`。USS 仅用于抵扣已实际兑现的承诺，不把 RSS 共享页当作可重复抵扣的私有内存。

明确声明 `scope: technical` 的本地短测可手动将 `ram_fraction` 提高至最多 0.95；默认仍为 0.8。正式任务对配置值强制取不超过 0.8 的上限。本次本地验证按用户许可使用 0.95，保留绝对可用内存余量；它不代表正式服务器的80%策略已在高负载下完成验收。

大分配和任务准入前重读实际余量；默认 `resources.memory_pressure_action: wait`，不足时释放可回收缓存或映射页，暂停新分配并持续等待。恢复要求满足 `memory_resume_fraction` 和 `memory_resume_seconds` 的迟滞窗口，恢复余量按有效内存与项目上限中较小值计算。预处理保留当前分块及已经完整提交的病例，余量稳定后继续；模型在设备通信前通过CPU就绪协调，保留原进程数量、全局batch和随机状态。显式配置 `stop` 时，持续压力达到 `memory_pressure_seconds` 发出安全停止请求；STU训练保留完整检查点及既有资源缩减、重新准入策略。batch、patch、方法和间距不会随内存压力更改。

训练启动时单独保留完整检查点写出额度，其他常驻内存增长不能抵扣该额度。任务 owner 的 PID 与出生身份失效时，仍存活的成员继续计入项目占用并立即停止新准入；rank 的主机等候和内存暂停等候也检查协调进程身份，发现其退出便报告错误并结束。取消信号在等待池关闭前传给本次worker；取消单个供数池不会取消仍存活的协调任务。未知算法、数据或进程池错误直接传播。

`memory.json` 是包含实际测量与缺失信息的有界最新快照；`progress-preprocess.json`、`progress-train.json` 是有界业务进度。终端同时显示已完成病例/总病例、复用与本次新完成、当前病例阶段、阶段块数与剩余块数，以及任务内存、安全余量、写盘空间和耗时。解压总量未知时显示未知，不编造 ETA。目录容量按完成记录和当前自有文件累计，不每步扫描全部数据。

有效主机目标是资源控制策略，预算与每秒采样均不能保证拦住外部任务的瞬时抢占。代码只回收本任务可释放内容，不终止其他用户的进程。Windows 当前 Job 可查询；祖先嵌套 Job 在无其句柄时不能枚举。进程权限或关键测量不可得时拒绝扩大准入，并在快照中记录缺失原因。

配置、清单、划分、冻结计划、日志和检查点继续位于 course；模型权重和正式离线数组位于 data；最终评价/预测输出位于 result；环境使用既有 env。更新代码后独立运行必要检查、预处理和训练，禁止更新命令自动启动正式计算。
