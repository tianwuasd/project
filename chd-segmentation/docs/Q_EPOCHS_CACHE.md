# Q-r2训练计数与缓存

定位器默认5个epoch，局部精修默认20个epoch，每epoch默认250次完整优化器更新。定位器总1250次，精修总5000次；基座40000次保持原预算。一次epoch按随机病例/候选抽样的250次更新定义，不能理解成每例恰好读取一次。ImageCHD启动器支持`--localizer-epochs`、`--local-epochs`、`--updates-per-epoch`；通用`models train`支持`--epochs`、`--updates-per-epoch`及直接指定`--updates`。每次更新保存epoch及轮内位置，默认每250次更新执行独立C组验证并选择最佳权重。

`resume_budget: true`明确允许接续时改变epochs、updates、updates_per_epoch、validate_every。数据、监督语义、模型方法、学习率、累积次数及其他科学配置继续逐项核对。模型、AdamW状态、随机状态及已完成update保留；学习率使用恢复的peak_lr和绝对update，按新的总预算计算余弦位置。缩短总预算会改变后续学习率轨迹，检查点记录budget_migration。已超过新总预算且已有完整summary/best的阶段直接复用；已完成的基座不重复训练。

定位器缓存CPU粗网格影像、有效区、三通道监督热图和监督掩膜，不缓存正在更新的定位器输出。局部精修缓存固定基座概率、固定定位器features和候选；父权重张量在初始化时计算一次摘要。键还包括prepared身份、实际storage/plan、技术区域、输入强度变换、类别语义及病例尺寸/间距。

缓存位于`course/chd-segmentation/q-training-cache/localizer`与`local`。默认总额分别2GiB和16GiB，由全部rank共享；跨rank病例生成互斥，不同病例可以同时计算。完成文件与写入预留共同计入容量，超额时按最近使用时间淘汰完成缓存；单例预估超过阶段额度时直接计算，不写缓存副本。写入前核对实际张量存储大小，原子提交。正常异常退出清理本次写入文件；被强制终止后的写入预留，在下次使用时根据进程出生身份回收。锁等待最多3600秒，可用`training_cache.lock_timeout_seconds`修改。

单例定位缓存约为补齐后粗网格体素数×23字节，加序列化头；粗网格每轴约为原图四分之一。精修缓存约为原图体素数×44字节的11通道float32概率，加粗网格features和候选；准入上界按每体素48字节加1MiB估计。磁盘缓存额度与训练内存保护独立，完整病例计算继续受既有资源规划约束；缓存不能让超大病例自动满足内存要求。

缓存跨重启保留供复用，不属于最终结果。模型阶段结束后可在停止本项目进程的情况下删除对应缓存目录；再次运行会按需重算。配置`training_cache: {enabled: false}`关闭缓存，或设置`localizer_bytes`、`local_bytes`更改额度。原始数据、预处理、best/latest均不由缓存淘汰过程删除。
