# 预训练权重加载与初始化重试

官方 STU-Net-S 文件先按 SHA256 核验，再读取到 CPU。模型可以位于 CPU 或 CUDA；加载后将每一层骨干张量转为 CPU，对 dtype 和全部数值进行严格比较。输出头保持任务所需类别数量，保留其初始化状态。校验失败直接终止。

训练启动先记录输入、模型及训练配置，预训练加载后才保存初始完整检查点。已有运行目录只有 run.json 和日志时，重新启动会核对数据、配置、依赖及精确代码兼容关系；没有 latest.json、state-*.pt、写入中的状态或 summary.json 才允许重新初始化，并记录 initialization_restarted。保留原有日志，不删除病例或预处理计划。

存在任何检查点、写入中的状态或训练摘要时，普通启动会拒绝覆盖。完整检查点使用 --resume；孤立的状态文件需要人工核对。配置、数据或未知代码变更继续拒绝重试。

tests/verify_pretrained_device.py 使用官方真实权重分别进行 CPU、CUDA 加载，重现原跨设备比较错误并核对修复后的全部骨干及输出头。随后使用一例真实 ImageCHD 的 32³ 技术区域生成计划，以真实错误权重路径触发初始化失败，在同一目录重试、保存及恢复零更新状态。测试不执行 GPU 训练、推断或任何优化器更新；独占临时目录结束后自动清理。
