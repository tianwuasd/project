# 离线预处理 Implementation Plan

**Goal:** 将固定整例转换保存一次，训练仅从完成的数据版本读取和随机取块，保留原研究方法与恢复规则。

**Architecture:** prepare 冻结清单、划分及训练统计；preprocess 生成逐例原子数据目录和完整描述；train 仅接收完整离线描述。通用来源/几何/类别检查与 STU-Net 转换分开。输入、配方、依赖、完整计划、统计来源及技术范围共同确定数据版本。

**Tech Stack:** MONAI Dataset/Compose、nnU-Net 预处理、NumPy NPY 内存映射、JSON/NPZ 元数据、现有 CPU/Gloo 与 CUDA/DDP 调度。

- 在线基线本地提交 60d6e5f17c81f1fea78690021fbf403b1ee61f37，公开提交 2269b26a4abc8a4952acacfab0611af4ce375d4f，冻结分支 archive/chd-online-preprocess-20261115。工作区检查无未提交修改。
- 依赖声明 pyproject.toml、两个正式 YAML 及完整恢复代码均随冻结分支保留；服务器真实环境依赖依据既有用户回执。旧任务使用冻结提交和原 prepared/run_dir 恢复。新离线版本使用新的 prepared/run_dir；不伪造跨数据身份兼容。
- 数据目录按数据集-方法-首次生成日期、fold 和配方摘要组织，目录索引与元数据核对完整摘要；数据在 data，日志和任务配置在 course，数据版本记录引用，结果在 result，环境在 env，源码在 code。
- 相同病例输入和同一完整计划/配方产生相同病例键；存储位置和任务目录不改变数据内容身份。统计 namespace 用于区分 Q/A 等统计来源，折数和拟合病例来源保留。配方或统计改变产生独立版本。
- 每例保存 image.npy、label.npy（有标签时）、locations.npz 和 case.json；通过完成目录原子替换发布。重新执行校验并复用已完成病例，归属确定的未完成病例重新生成。
- 训练仅允许完整离线描述，NPY 使用只读 mmap；保持原抽样 RNG、部分标注、空间恢复和全局 batch。旧在线版本留在冻结分支。
- 数据版本记录引用任务；只提供清理范围与仍引用提示，不自动删除正式预处理、其他模型数据或原始数据。
- 测试使用 back 独占目录、最多两例 32³、两次更新并恢复/预测/评价/复用；D:\projects\test 作为只读仿真依赖，工具与其他助手源码不修改。
