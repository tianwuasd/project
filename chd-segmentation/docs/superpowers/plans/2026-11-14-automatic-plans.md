# 自动预处理计划实施计划

目标：prepare 默认从当前训练清单生成计划，短测使用同一实现；保留显式读取已有计划的方式。

1. 在 preprocessing/planning.py 实现训练病例抽样、nnU-Net 间距规划和计划身份复用。身份包含数据集、范围、折数、训练病例、技术区域、采样参数、手动覆盖与依赖版本。已有计划身份不符时停止，使用新路径重新拟合。
2. config.py 提供 planning 配置与按数据集、折数、范围分开的默认输出位置；prepare.py 先检查患者划分，再拟合。训练与预测仅验证并使用已生成计划。
3. transforms.py 共享原件核验、空间规则与读取逻辑，避免计划拟合与执行对病例采取不同规则。拟合顺序读取病例，限制每例与总采样数量，检查 RAM 余量。
4. smoke.py 使用所选 1–2 例及其技术区域自动生成计划，记录计划阶段时间、复用与覆盖检查。计划禁止用作正式任务。
5. 使用已获准的两例真实病例验证预处理、两次更新、恢复、预测和清理；覆盖训练子集选择、身份变化、显式计划与覆盖设置。所有测试产物按本次授权放在 back。
6. 更新公开说明与示例配置，提交并推送本项目；完成后将本地维护代码迁至 D:/projects/project/chd-segmentation，服务器路径保持不变。

实现采用 MONAI 数据流程与已安装 nnU-Net 的裁剪、间距规划、重采样和 CT 归一化。计划只保存紧凑 JSON，不复制原始病例、不生成整套重采样数据，也不决定模型架构、训练 patch 或 batch。
