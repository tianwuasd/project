# 分块预处理与公共内存保护实施计划

目标：保留 STU-Net 的冻结间距、归一化、插值和边界方法，为离线构建与训练增加实际内存保护、可恢复进度和必要快速检查。

1. 保留最新 main 的 Q/MedSAM2 接口及独立目录。源码维护位置不变；过程描述在 course，正式离线数组在 data。
2. `models/stunet/streaming.py` 通过成熟 NIfTI/gzip 库顺序解压、按块读取和归一化；孔洞填充按连通传播处理；样条沿完整轴线分块预滤波；输出使用全局坐标逐块插值写入 `.npy`。图像、标签、裁剪和采样均不建立输出整例副本。
3. `training/memory_guard.py` 根据实时有效主机余量、进程组实际占用与跨任务登记执行准入。默认整机目标 80%，项目合计上限 100,000,000,000 字节，采样每秒。压力停止准入，有迟滞恢复；训练各 rank 协同保存完整检查点。外部瞬时抢占仍可能导致 OOM。
4. `observability/progress.py` 共用有界快照和真实业务计数。预处理显示复用、新完成、待处理、病例阶段及块进度；训练显示恢复进度、剩余工作和阶段计时，未知 ETA 为 null。
5. `preflight.py` 在正式入口检查输入/分组/冻结描述、权重、关键 API、路径和空间；不读取全部体素，不做训练型预检查。
6. 保留已完成病例原有完整摘要与身份验证。块输出先写有归属的 pending 目录，完整校验和提交后才登记完成；崩溃残留只按归属清理，不删除正确病例。
7. 在已授权 back 范围使用两例真实 ImageCHD 的 32³ 区域，核对原实现/分块输出、几何、标签和块边界，最多两次训练更新及恢复。记录时间、实际内存和磁盘；清理自有测试副产物。正式大病例仅在服务器使用原冻结计划和统计处理，禁止用单例重拟合代替。

验收关注：各向异性分轴插值；标签精确并列规则；源文件缩放/轴次序；多个任务同时准入；rank 在数据等待期间的压力协同；Windows/Linux 路径变化不改变内容配方。
