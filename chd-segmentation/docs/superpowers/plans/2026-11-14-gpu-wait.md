# 显卡挑选与持续等待

目标：优先空闲显卡，允许空闲卡与符合共享条件的繁忙卡组成完整训练组；GPU 不足时默认持续等待，保留手动等待时限与停止入口。

- [x] `wait_seconds: null` 表示持续等待，CLI `--wait-seconds forever` 覆盖旧配置。
- [x] 显卡候选按每卡 batch 核对共享记录、连续负载窗口及显存，使用完整分配减少繁忙卡数量，保留手动顺序。
- [x] 选卡遵守继承的可见范围和本项目预留；凑齐前不占用部分设备。
- [x] 等待日志按心跳间隔记录实际可见范围、候选卡和具体原因。
- [x] 使用真实本机显卡样本验证空闲挑选、预留、等待、有限时限、取消和释放；不加载模型或运行 GPU 计算。
- [x] 补充精确源码兼容边，并准备发布内容与服务器命令。

模型、训练样本、优化器、训练预算和检查点结构保持既有行为。CPU/内存准入及驱动、配置错误继续明确报错。多张真实物理卡的混合分配、繁忙卡容量和 CUDA/NCCL 训练需要目标服务器回执。
