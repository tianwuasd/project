# STU-Net 自动分块预测

预测沿用已完成训练的模型、数据划分、预处理配方和类别定义。`prediction.execution` 默认 `auto`：资源规划在当前实际安全额度内，逐病例选择整例或分块。`whole`、`blocks` 可手动指定。分块大小从 `block_bytes` 到 `max_block_bytes`，默认64MiB到512MiB；准入时优先选择额度允许的较大块。它们约束主机处理缓冲，模型窗口仍由训练块、`window_batch`和重叠率决定。

预测与评价取消固定100GB上限，按有效主机、cgroup、进程限制的80%及实时剩余量准入，计入其他任务占用和未兑现预留，仍保留资源预留和默认50%的估算余量。训练、预处理保留原来的100GB限制。没有符合条件的空闲显卡时继续等待，默认关闭显卡共享。

分块模式复用MONAI窗口位置与高斯或常量权重。窗口结果在磁盘数组中累积，再分块归一化和softmax；原图恢复使用全局半体素坐标、原裁剪框、原轴顺序和原来的各向异性策略。标签在概率插值后决定。预测结果仍输出原尺寸NIfTI掩膜；评价分块累计类别计数。

临时数组位于`work_root/prediction-work/<任务身份>/`，正式掩膜位于原结果目录。正常结束或可处理的异常退出后移除临时数组。强制终止留下的目录只能在归属记录一致、只含已知文件时清理并重做当前病例；完整病例沿用提交记录复用。磁盘空间不足时给出需要量并停止。分块处理会增加临时磁盘读写，当前不把未完成窗口保存成永久断点。

`prediction_case_admitted`记录整例估算、实际模式、处理块与工作空间；`prediction_blocks`记录窗口、概率、原图恢复及评价进度。执行方式和块大小不改变结果复用身份。每个预测任务保留一份固定模型快照，避免恢复时改用其他权重。

## 实施和验证

- 配置与预算：自动模式、较大处理块、预测80%额度以及训练额度隔离。
- 预测执行：窗口累积、概率计算、原空间恢复、提交与临时文件清理。
- 评价：压缩NIfTI有界解压，逐块累计相同的监督Dice计数。
- 有界验证：两例真实影像、最多64³原始区域、零训练更新；比较MONAI整例概率、原空间掩膜、评价，检查复用、不同窗口权重和主动取消。实际范围、耗时、资源与清理结果写入独立验收报告。
