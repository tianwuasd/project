# Q-r2 有界验证

验证按完整病例覆盖所有有效体素，维持原边缘交叉熵和逐类别 Dice，以及逐患者或病例的平均方式。基础模型继续使用 MONAI 窗口、原重叠率和 Gaussian 权重；大数组采用磁盘映射，损失按块累计充分统计量。

定位器推理按层分块执行卷积，GroupNorm 使用整个病例的分组统计。监督热图按实际毫米间距扩展邻域后生成。局部模型只读取候选范围的影像、概率和上下文；融合结果与验证损失按块计算。

CPU 预算区分训练病例和 C 组验证病例，分块工作区计入既有 50% 余量、项目 100 GB 和整机 80% 规则。临时数组位于 course 下的独立验证工作目录，每例正常退出或异常退出后清理；已有预处理及检查点保持独立。

- [x] 接入验证、运行时内存保护及阶段预算。

验证优化与训练阶段的容量分别规划；定位器训练保留其原有梯度计算，局部训练保留其原有候选及冻结模型语义。短测仅说明实际执行的小区域范围，正式服务器峰值需要服务器日志确认。

数值检查使用 ct_1003、ct_1012 的64³区域和原始 STU-Net-S 预训练骨干。基础概率最大绝对差0，局部概率最大差5.96e-8，定位器输出最大差3.46e-6，定位器特征最大差4.06e-6。另用同一病例61×57×49区域检查边界填充。单进程CPU完成两次实际优化器更新和中间检查点重载，验证参数、优化器与Torch随机状态恢复及主动取消清理。双进程入口因本机物理内存不足未启动训练，CUDA/NCCL及正式体积未实测。
